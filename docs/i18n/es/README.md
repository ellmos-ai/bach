# BACH - Español

[English](../en/README.md) | [Deutsch](../de/README.md) | [Español](../es/README.md) | [Русский](../ru/README.md) | [日本語](../ja/README.md) | [中文](../zh/README.md)

BACH es un sistema operativo basado en texto para Large Language Models (LLMs): memoria estructurada, gestión de tareas, automatización, agentes, herramientas, workflows y orquestación multi-LLM.

Esta página existe como punto de entrada para usuarios y crawlers. La README española principal es [../../../README.es.md](../../../README.es.md).

## Soporte multilingüe

El release actual activa seis idiomas: `de`, `en`, `es`, `ru`, `ja` y `zh`. Esto está verificado en [../../../system/exports/translations/languages_config.release.json](../../../system/exports/translations/languages_config.release.json) y [../../../system/exports/translations/manifest.release.json](../../../system/exports/translations/manifest.release.json).

## Inicio

```bash
git clone https://github.com/ellmos-ai/bach.git
cd bach
pip install -e .
bach setup preflight
```
