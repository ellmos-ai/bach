# BACH - English

[English](../en/README.md) | [Deutsch](../de/README.md) | [Español](../es/README.md) | [Русский](../ru/README.md) | [日本語](../ja/README.md) | [中文](../zh/README.md)

BACH is a text-based operating system for Large Language Models (LLMs): structured memory, task management, automation, agents, tools, workflows, and multi-LLM orchestration.

This language entry point exists for direct discovery by users and crawlers. The canonical English README is [../../../README.md](../../../README.md).

## Multilingual Status

The current release enables six languages: `de`, `en`, `es`, `ru`, `ja`, and `zh`. This is verified in [../../../system/exports/translations/languages_config.release.json](../../../system/exports/translations/languages_config.release.json) and [../../../system/exports/translations/manifest.release.json](../../../system/exports/translations/manifest.release.json).

## Start

```bash
git clone https://github.com/ellmos-ai/bach.git
cd bach
pip install -e .
bach setup preflight
```
