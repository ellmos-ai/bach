# tools - Standalone Module

Autarker Tool-Manager, Schema-Validator, Sicherheits-Gatekeeper und Execution-Dispatcher für BACH und Ocean.

## Funktionen
- Tool-Registrierung mit Parameter-Typisierung
- Berechtigungsprüfungen vor der Ausführung
- Audit-Trail aller Toolaufrufe
- Standalone-Betrieb ohne DB-Zwang
