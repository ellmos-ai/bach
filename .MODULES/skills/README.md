# skills - Standalone Module

Autarker Skill-Katalog, Frontmatter-Parser, Indexer und Discovery-Engine für BACH und Ocean.

## Funktionen
- Frontmatter-Extraktion aus `SKILL.md` (YAML-Metadaten)
- Verzeichnis-Discovery rekursiv über Skill-Pfade
- Tag- und Kategoriensuche
- Standalone-Betrieb ohne DB-Zwang
