# agents - Standalone Module

Autarker Agenten- und Experten-Manager, Rollen-Taxonomie und Task-Delegation-Router für BACH und Ocean.

## Funktionen
- Registrierung von Boss-Agenten und Fachexperten
- Rollen-Tiering (`thinker_reviewer`, `worker`, `light_worker`)
- Dynamisches Task-Routing nach Domäne, Tags und Fachgebiet
- Standalone-Betrieb ohne DB-Zwang
