# Standalone Hooks Module

Autarkes Event-Hook- und Dispatcher-Framework für BACH und Ocean.

## Features
- Priorisierte Listener-Ausführung (aufsteigend oder absteigend konfigurierbar)
- Once-Listener mit automatischer Entregistrierung nach einmaligem Feuern
- Fehler-Kapselung (Fail-Safe: Ein fehlerhafter Listener stoppt nicht die Kette)
- Ausführungs-Logbuch (Audit-Trail)
- Status und Metriken
