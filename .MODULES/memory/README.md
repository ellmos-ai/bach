# Standalone Memory Module

Autarker Speicher für Notizen, Facts, Lessons, Sessions und Working Memory mit Decay für BACH und Ocean.

## Features
- Notizen (Working Memory) mit Tags und optionalem TTL-Ablauf (Decay)
- Facts (Fakten-Speicher) mit Konfidenzwerten
- Sessions-Protokollierung mit Dauer und Status
- Such- und Kontext-Generierung
- Export/Import und SQLite-Persistenz
