# Standalone Plugins Module

Autarkes Standalone-Modul für Plugin-Verwaltung, Manifest-Prüfung, Trust-Level und Capability-Auditing in BACH und Ocean.

## Features
- Vollständig selfcontained ohne zirkuläre Abhängigkeiten
- Manifest-Validierung (`plugin.json`)
- Lifecycle: Load, Unload, Enable, Disable
- Capability-Profile & Trust-Level Management
- Tool-Registrierung & Inspektion
