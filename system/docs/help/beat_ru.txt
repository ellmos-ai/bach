BEAT - Единое отображение времени
===========================

Централизованное управление всеми функциями времени (часы, таймер, обратный отсчет, между).

КОМАНДЫ CLI
-----------

  bach beat                 Показать всю информацию о времени
  bach beat on              Активировать все отображения времени
  bach beat off             Деактивировать все отображения времени
  bach beat interval <sek>  Установить глобальный интервал

ФОРМАТ ВЫХОДА
--------------

  [ПАУЗА] 14:35
    Таймер: Сеанс 45:12 | Исследования 05:23
    Обратный отсчет: сосредоточьтесь, осталось 19:45.
    Между: Профиль "Алгебра" активен

КОМПОНЕНТЫ
-----------

  1. ЧАСЫ – время
     Показывает текущее время
     -> часы Баха вкл.|выкл.|интервал

  2. ТАЙМЕР – секундомер.
     Показывает работающие таймеры
     -> запуск таймера Баха|стоп|список

  3. COUNTDOWN – обратный отсчет
     Показывает активный обратный отсчет
     -> начало обратного отсчета Баха|стоп|список

  4. МЕЖДУ – промежуточные проверки
     Показывает активный профиль
     -> бах между включением|выключением|использованием

ПРИМЕРЫ
---------

  # Вся информация за все время 
  bach beat
  -> [ПАУЗА] 14:35
  -> Таймер: сеанс 45:12
  -> Обратный отсчет:-
  -> Между: по умолчанию

  # Выключить всё (сосредоточенная работа)
  bach beat off

  # Включайте все с интервалом в 2 минуты 
  bach beat on
  bach beat interval 120

ВЗАИМОДЕЙСТВИЕ С ИНЖЕКТОРАМИ
----------------------------

Отображения времени выводятся через систему инжекторов.
`bach Beat` является универсальным элементом управления для этого.

Старые команды (устаревшие):
  --inject переключить ритм -> ритм Баха вкл.|выкл.
  --inject переключение между -> bach между включением|выключением

Новая структура:
  TimeManager управляет часами, таймером и обратным отсчетом
  BetweenManager управляет профилями и проверяет
