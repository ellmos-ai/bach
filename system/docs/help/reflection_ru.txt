ОБРАБОТЧИК ОТРАЖЕНИЯ
------------------

ОПИСАНИЕ
------------

Обработчик отражений анализирует саморефлексию и производительность системы BACH.
Оценивает информацию из таблиц памяти (работа, занятия, уроки, факты)
и отображает подробные отчеты о производительности, анализ тенденций и выявленные
Уязвимости.


ОПЕРАЦИИ
-----------

статус
  Посмотреть отчет о производительности. Предоставляет актуальный обзор системных показателей.
  и общие показатели эффективности.

обзор [дней]
  Анализируйте производительность за последние N дней (по умолчанию: 7 дней).
  Пример: обзор 14 показывает последние две недели.

пробелы
  Выявить слабые места и пробелы. Анализирует содержимое памяти и отображает
  Области с низким покрытием или проблемами с производительностью.

log
  Просмотр показателей отражения из базы данных. Показывает последние 20 записей
  типа 'REFLECTION:*' из таблицы Memory_working.


ПРИМЕРЫ
---------

  bach reflection status
    -> Показывает текущий отчет о производительности со всеми показателями

  bach reflection review 30
    -> Анализирует производительность за последние 30 дней с подробными тенденциями

  bach reflection gaps
    -> Перечисляет все выявленные уязвимости

  bach reflection log
    -> Показывает последние 20 записей метрик отражения


ФАЙЛЫ
-------

hub/reflection.py
  Реализация обработчика с определениями операций и запросами к базе данных.

agents/reflection/reflection_analyzer.py
  Класс SelfReflection для логики анализа и создания отчетов.

data/bach.db
  Центральная база данных SQLite с таблицами памяти:
  - Memory_working: текущая рабочая память (введите «note» с помощью REFLECTION:*)
  - Memory_sessions: история сеансов
  - Memory_lessons: извлеченные уроки
  - Memory_facts: Сохраненные факты
