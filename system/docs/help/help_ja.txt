ヘルプ - BACH ヘルプ システム
=============================

説明
ヘルプ システムは、すべての BACH コンポーネントのコンテキスト関連のドキュメントを提供します。
各トピックは docs/help/ ディレクトリに独自の .txt ファイルがあります。

CLI コマンド
-----------
bach --help                 利用可能なすべてのトピックを表示
bach --help [thema]         特定のトピックに関するヘルプ
bach --help tasks           例: タスク システムのヘルプ
bach --help steuer          例: 税務担当者に関するヘルプ
bach --help tools/name      例: サブフォルダーからのヘルプ
bach --help tool_name       例: データベースからのツール情報

利用可能なトピック
------------------
システム: 起動、シャットダウン、アーキテクチャ、機能
タスク: タスク、タスク間、計画、ワークフロー
記憶: 記憶、レッスン、ログ、ソース
エージェント: エージェント、アクター、通信、パートナー
ツール: ツール、保守、バックアップ、配布
データ: ディスクスキャン、ゴミ箱
GUI: GUI、メンテナンス、プロンプト ジェネレーター、繰り返し
特別: 税金、コーディング、バグ修正、インジェクター
外部: ベンダー、クックブック
その他: アイデンティティ、命名、実践、形式、絵文字

ヘルプ ファイルの構造
-------------------------
1。 TITLE - 大文字の名前
2. 説明 - このコンポーネントは何をするものですか?
3. CLI コマンド - どのようなコマンドがありますか?
4. その他のセクション - 概念、例、ヒント

新しいヘルプ ファイルを作成
-------------------------
1。 docs/help/[トピック].txt の下にファイルを作成します
2. 既存のファイルからフォーマットを採用する
3. 少なくとも: タイトル、説明、CLI コマンド
4. bach --help への自動登録

ヘルプ ファイルとその他のドキュメント
---------------------------
docs/help/*.txt CLI リファレンス、クイック ルックアップ
skill/*.md エージェント プロファイル、複雑な概念
docs/*.md 開発者向けドキュメント、概念
SKILL.md メイン エントリ ポイント

ベスト プラクティス
--------------
- 短く要点を絞ってください (100 行以内)
- 必ず最初に CLI コマンドを文書化してください
- 理論よりも例の方が役に立つ
- 変更の場合: ヘルプ ファイルを更新します

WIKI と拡張機能
--------------------
wiki/ サブディレクトリには拡張ドキュメントが含まれています。
wiki/*.txt

  bach --help tools/python_cli_editor
  bach --help wiki/antigravity
