演员模型 - 6 类演员系统
==========================================

描述
演员模型描述了 BACH 中的 6 个演员类别
一起工作。它取代了旧的 4 演员模型。

版本：2.0.0

6 个演员
=============

1。用户（一个或多个）
----------------------------
角色：决策者、客户、反馈提供者

界面：
  - 消息框/主要通信
  - 用户/个人区域
  - 工作区/活动工作区

模式：
  - 单用户标准（当前）
  - 未来多用户（管理员、标准、访客）

交互：
  - 直接通过聊天（Claude.ai / API）
  - 通过 MessageBox 异步（.txt/.md 文件）
  - 通过文件系统手动


2。操作人工智能 - “瓶中精灵”
----------------------------------------
角色：中央情报、推理、编排

现任：克劳德（人类）
可互换：是 - 系统设计为与 AI 无关

任务：
  - 推理和决策
  - 任务编排和委派
  - 代码生成和审查
  - 文档和分析
  - 用户沟通

特点：
  - 代币限制：每个会话约 190,000 个
  - 无持久记忆
  - 通过 MCP/Desktop Commander 访问工具


3。其他人工智能/法学硕士
-------------------
角色：专门任务、授权、代币节省

可用：
  - Ollama（本地）llama3.2、mistral、codellama
  - Gemini（外部）深度研究，长文档
  - 副驾驶办公室集成
  - GPT 替代方案（非活动）

委托触发器：
  - 代币短缺（>70%）
  - 批量加工
  - 专门任务
  - 并行处理


4。操作系统
-------------------
角色：基本基础设施和本地执行

包括：
  - Windows/Linux操作系统
  - 安装的软件
  - 奥拉玛运行时
  - Python/Node.js
  - 文件系统

访问方式：
  - 桌面指挥官（MCP）
  - 文件指挥官（MCP）
  - 直接 shell 命令


5。集成工具和脚本
------------------------------
角色：内部开发、自动化、特殊任务

类别：
  - 编码工具c_encoding_fixer、c_json_repair等
  - 税务工具tax_scanner、tax_sync等。
  - 代理脚本agent_framework、developer_agent
  - 备份工具backup_manager
  - 迁移 migrate_connections

管理：
  bach tools list     列出 Python 脚本（文件系统）
  bach tools db       数据库注册工具（CLI + 外部 AI）


6.在线工具（无人工智能）
-------------------------
角色：专业网络服务

类别：
  - 生成 PDF、QR 码等。
  - 数据库 API、注册表
  - 转换器格式转换
  - 研究非 AI 搜索引擎

注意：与 ChatGPT/Midjourney 等 AI 工具的区别！


交互原则
=======================

决策层次结构：
  1. 用户决定关键问题
  2. 克劳德协调和编排
  3. 工具运行
  4. 如果需要，其他 AI 支持代币感知：
  - 克劳德的代币有限
  - 委托保存代币
  - 前往奥拉马的批量行动
  - 双子座研究

沟通渠道：
  - 直接：Claude <-> 用户（聊天）
  - 异步：消息框（文件）
  - API：MCP 服务器、REST
  - 授权：收件箱/发件箱系统

连接矩阵


操作人工智能（克劳德）：
  -> 用户（直接，消息框）
  -> Ollama（API，队列）
  -> 双子座（驱动委派）
  -> 操作系统（桌面指挥官）
  -> 工具（直接执行）
  -> MCP 服务器（PubMed、Canva、Drive）
==================

用户：
  -> 克劳德（聊天、消息框）
  -> 操作系统（直接使用）
  -> 工具（手动执行）

Ollama：
  <- 克劳德（代表团）
  -> 操作系统（本地版本）

Gemini:
  <- 克劳德（驱动代表团）
  -> 云（外部处理）

CLI 访问


显示连接
===========
bach --connections list          列表别名
bach --connections db            AI 合作伙伴
bach --connections db --type ai  显示参与者模型
bach --connections actors        显示合作伙伴资料
bach --connections partners      此帮助
bach --help actors               代理系统


除了 6 个参与者之外，还有一个分层代理系统：
==============

Boss 代理（坐标）：
  - 私人助理（私人）
  - 健康助理（私人）
  - 办公室助理（专业）

专家（专业）：
  - 家务管理
  - 健康管理员、心理咨询师
  - 税务代理、资金规划师

更多信息：bach --help 代理
