# BachForelle (Стрела) – перекрестная ссылка

## ПРЕДУПРЕЖДЕНИЕ: ВНЕШНЯЯ ДОКУМЕНТАЦИЯ
Этот файл описывает **BachForelle**, ОТДЕЛЬНЫЙ проект вне BACH v2 Vanilla.

**Правильные пути:**
- BachForelle: `%ONEDRIVE_AI_ROOT%\BachForelle\`
- BachFliege: `%ONEDRIVE_AI_ROOT%\BachFliege\`

## Что такое BachForelle?
BachForelle — это облегченный вариант программы BACH для LLM-First.
Это АВТОНОМНЫЙ проект с отдельной кодовой базой.

**Философия:**
* LLM — оркестратор (а не просто пользователь)
* Процесс загрузки не требуется
* Модульные навыки вместо маршрутизации концентратора
* Фокус: Память + Multi-LLM

## Для пользователей BACH v2 vanilla
**BachForelle НЕ является частью BACH v2 Vanilla.**

Если вы хотите использовать BachForelle:
1. Перейдите в папку BachForelle.
2. Прочтите `%ONEDRIVE_AI_ROOT%\BachForelle\README.md`
3. Прочтите `%ONEDRIVE_AI_ROOT%\BachForelle\SKILL.md`

## BACH v2 Vanilla НЕ имеет команды «стрелка»
Этот файл справки существует только в качестве перекрестной ссылки для пользователей, использующих обе системы.
