BACH UPGRADE - ОБНОВЛЕНИЕ СИСТЕМЫ
-------------------------------------

Обновляет версии компонентов BACH выборочно по файлу или категории.


ИСПОЛЬЗОВАНИЕ
----------

  # Просмотр статуса обновления
  bach upgrade status

  # Показать доступные версии файла
  bach upgrade list hub/backup.py

  # Проверьте доступные обновления
  bach upgrade check

  # Выборочные обновления категорий
  bach upgrade core
  bach upgrade templates
  bach upgrade agents
  bach upgrade skills
  bach upgrade hub
  bach upgrade tools
  bach upgrade connectors
  bach upgrade partners
  bach upgrade docs
  bach upgrade gui

  # Пробный прогон (только просмотр, не выполнение)
  bach upgrade agents --dry-run


КАТЕГОРИИ
----------

  ядро Ядро системы (dist_type=2)
  шаблоны шаблоны и шаблоны (dist_type=1)
  агенты Боссы-агенты и эксперты
  навыки навыки и протоколы
  хаб Обработчик хаба
  инструменты инструменты
  разъемы система разъемов
  партнерские файлы партнеров
  документы документация
  файлы графического интерфейса пользователя


ВАЖНО
-------

- Обновление перезаписывает только файлы с версиями из дистрибутива/манифеста.
- USER_DATA остается нетронутым.
- Резервное копирование рекомендуется перед крупными обновлениями.
- Версии отслеживаются в `dist_file_versions`.


ПРИМЕРЫ
---------

  # Обновлять только файлы ядра
  bach upgrade core

  # Обновлять только шаблоны
  bach upgrade templates

  # Предварительный просмотр только файлов агента
  bach upgrade agents --dry-run

  # Документация по восстановлению/обновлению
  bach upgrade docs

  # Просмотр доступных версий файла
  bach upgrade list hub/backup.py


ВЕРСИЯ
-------------

- Хэш + система автоинкремента (ENT-09)
- Через `bach update` можно перемещать только файлы дистрибутива с версией.
- USER_DATA исходит от пользователя и не имеет версии


СМОТРИТЕ ТАКЖЕ
----------

  bach --help restore       Восстановление шаблона
  bach --help downgrade     Переход на более старую версию
  bach --help seal          Проверка целостности
