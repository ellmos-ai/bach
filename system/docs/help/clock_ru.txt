ЧАСЫ - Отображение времени
=======================

Отображает текущее время в выходных данных CLI.

КОМАНДЫ CLI
-----------

  bach clock on              Включить отображение времени
  bach clock off             Деактивировать отображение времени
  bach clock status          Показать текущий статус
  bach clock interval <sek>  Установить интервал в секундах

ИНТЕРВАЛ
---------

  интервал 0 для КАЖДОГО выхода
  интервал 60 Время, только если >= 60 секунд с момента последнего отображения
  интервал 300 Время каждые 5 минут

ФОРМАТ ВЫХОДА
--------------

  [ЧАСЫ] 14:35

НАСТОЙЧИВОСТЬ
----------

  Файл: data/.clock_state

  Содержание:
  {
    «включено»: правда,
    «интервал»: 60,
    "last_shown": "2026-01-30T14:35:00"
  }

ПРИМЕРЫ
---------

  # Время каждого вывода
  bach clock on
  bach clock interval 0

  # Время каждые 5 минут
  bach clock interval 300

  # Проверить статус
  bach clock status
  -> Часы: ВКЛ | Интервал: 60с | Последнее: 14:35

INTERPLAY
-------------

Часы являются частью системы времени:
  --help таймер секундомер
  --help обратный отсчет Обратный отсчет с триггером
  --help между проверками
  --help Beat Единое отображение времени

Все функции времени суммируются с помощью `bach Beat`.
