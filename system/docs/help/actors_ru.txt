МОДЕЛЬ АКТОРОВ — 6-категорийная система актеров
==========================================

ОПИСАНИЕ
Модель актеров описывает 6 категорий актеров в BACH.
работать вместе. Он заменяет старую модель с 4 актерами.

Версия: 2.0.0

6 АКТЕРОВ
=============

1. ПОЛЬЗОВАТЕЛЬ (один или несколько)
----------------------------
Роль: лицо, принимающее решения, клиент, поставщик обратной связи

Интерфейсы:
  - MessageBox/Основное общение
  - Пользовательский/личный кабинет
  - Рабочая область/Активная рабочая область

Режимы:
  - Однопользовательский стандарт (текущий)
  - Многопользовательское будущее (админ, стандарт, гость)

Взаимодействие:
  - Непосредственно через чат (Claude.ai/API)
  - Асинхронно через MessageBox (файлы .txt/.md)
  - Вручную через файловую систему


2. ОПЕРАЦИОННЫЙ ИИ — «Джинн в бутылке»
----------------------------------------
Роль: Центральный интеллект, рассуждение, оркестровка

Текущий: Клод (Антропный)
Взаимозаменяемость: Да — система спроектирована так, чтобы быть независимой от искусственного интеллекта

Задачи:
  - Рассуждение и принятие решения.
  - Оркестровка и делегирование задач.
  - Генерация и проверка кода
  - Документация и анализ
  - Общение с пользователем

Особенности:
  - Лимит токенов: ~ 190 000 за сеанс.
  - Нет постоянной памяти.
  - Доступ к инструментам через MCP/Desktop Commander


3. ДРУГИЕ AI/LLM
-------------------
Роль: специализированные задачи, делегирование, экономия токенов

Доступно:
  - Оллама (местный) лама3.2, мистраль, коделлама
  - Близнецы (внешние) Глубокие исследования, длинные документы
  - Интеграция второго пилота с Office
  – Альтернатива GPT (неактивна)

Триггер делегирования:
  - Дефицит токенов (>70%)
  - Массовая обработка
  - Специализированные задачи
  - Параллельная обработка


4. ОПЕРАЦИОННАЯ СИСТЕМА
-------------------
Роль: Базовая инфраструктура и локальное исполнение

Включает:
  - ОС Windows/Linux
  - Установленное программное обеспечение
  - Время выполнения Олламы
  - Питон/Node.js
  - Файловая система

Доступ через:
  - Настольный командир (MCP)
  - Файловый командир (MCP)
  - Прямые команды оболочки 


5. ИНТЕГРИРОВАННЫЕ ИНСТРУМЕНТЫ И СКРИПТЫ
------------------------------
Роль: собственные разработки, автоматизация, специальные задачи

Категории:
  - Инструменты кодирования c_encoding_fixer, c_json_repair и т. д.
  - Налоговые инструменты Tax_scanner, Tax_sync и т. д.
  - Скрипты агента: Agent_framework, Developer_agent.
  - Инструменты резервного копирования backup_manager
  - Миграцияmigrate_connections

Администрирование:
  bach tools list     Список сценариев Python (файловая система)
  bach tools db       Инструменты, зарегистрированные в БД (CLI + внешний AI)


6. ОНЛАЙН-ИНСТРУМЕНТЫ (без ИИ)
-------------------------
Роль: Специализированные веб-сервисы

Категории:
  - Генераторы PDF, QR-кодов и т.д.
  - API баз данных, реестры
  - Преобразование формата конвертера
  - Исследуйте поисковые системы, не связанные с искусственным интеллектом.

Примечание: разница с инструментами искусственного интеллекта, такими как ChatGPT/Midjourney!


ПРИНЦИПЫ ВЗАИМОДЕЙСТВИЯ
=======================

Иерархия решений:
  1. Пользователь решает важные вопросы
  2. Клод координирует и организует
  3. Инструменты запускаются
  4. Другие ИИ поддерживают осведомленность о токенах, если это необходимо:
  - Клод ограничен в токенах
  - Делегирование сохраняет токены
  - Массовые операции с Олламой
  - Исследование каналов связи Близнецов:
  - Прямой: Клод <-> Пользователь (Чат)
  - Асинхронность: MessageBox (файлы)
  - API: MCP-сервер, REST.
  - Делегирование: Система входящих/исходящих сообщений

МАТРИЦА СОЕДИНЕНИЙ

Рабочий ИИ (Клод):
  -> Пользователь (прямой, MessageBox)
  -> Оллама (API, очередь)
  -> Близнецы (Делегирование управления)
  -> ОС (Desktop Commander)
  -> Инструменты (прямое выполнение)
  -> Сервер MCP (PubMed, Canva, Drive)


Пользователь:
  -> Клод (Чат, Окно сообщений)
  -> ОС (прямое использование)
  -> Инструменты (ручное выполнение)
==================

Оллама:
  <- Клод (делегация)
  -> ОС (локальная версия)

Gemini:
  <- Клод (Делегирование управления)
  -> Облако (внешняя обработка)
