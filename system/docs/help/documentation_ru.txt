ДОКУМЕНТАЦИЯ BACH - Обзор
================================

Центральный контактный пункт для всей документации BACH.

ОСНОВНЫЕ ДОКУМЕНТЫ
--------------

Корневой уровень:
  SKILL.md Мастер-контекст, айдентика, правила поведения
  Обзор проекта README.md

система/:
  ARCHITECTURE.md Техническая архитектура, компоненты
  План развития ROADMAP.md, основные этапы
  История версий CHANGELOG.md, изменения

СПРАВОЧНАЯ СИСТЕМА (system/docs/help/)
--------------------------

Вызов: python bach.py --help <topic>

ПОНЯТИЯ:
  --help основная основная концепция (агент/рабочий процесс/навыки/инструменты)
  --Помощь системе памяти (5 когнитивных типов + схема обучения)
  --help инжекторы системы инжекторов (автоматические подсказки)
  --help консолидация консолидации (сжатие, затухание, повышение)
  --help запуск журнала запуска

СИСТЕМА:
  --help задачи Управление задачами
  --help Lessons Система извлеченных уроков
  --help Partner Партнерская система (Multi-LLM)
  --help daemon служба демона

ВРЕМЯ:
  --help clock Отображение времени
  --help таймер секундомер
  --help обратный отсчет Обратный отсчет с триггером
  --help между проверками
  --help победить Единую систему времени

РАЗРАБОТКА:
  --help рабочий процесс разработки
  --help usecase Тесты использования
  --help bugfix Журнал исправлений ошибок
  --help кодирование стандарты кодирования

КАТАЛОГ:
  --help list Все доступные темы

ФУНКЦИИ (начиная с версии 1.1.85):
  --help Agent/<имя> документы агента (например, --help Agent/ati)
  --help workflow/<имя> Документы рабочего процесса
  --help expert/<имя> Экспертные документы
  --help <имя_инструмента> Информация об инструменте из БД

ИЕРАРХИЯ НАВЫКОВ (система/навыки/)
-----------------------------------

  агенты/профили агентов (роли)
  навыки/рабочие процессы/определения рабочих процессов (22 рабочих процесса)
  агенты/_experts/ Конфигурации экспертов
  навыки/_услуги/описания услуг
  навыки/_templates/Шаблоны
  партнеры/партнерские конфигурации LLM
  разъемы/Внешние соединения
  навыки/_os/ Конфигурации для конкретной ОС

ПАПКА ДОКУМЕНТОВ (docs/)
-------------------

  документы/Текущие концепции и анализ
  docs/_archive/ Архивированные/завершенные концепции
  docs/_ideas/ Идеи на будущее
  docs/_test_and_reports/ Результаты тестов и отчеты
  документы/анализ/Аналитические документы
  docs/reference/ Внешние ссылки (поваренные книги и т. д.)

КОДОВАЯ ДОКУМЕНТАЦИЯ
------------------

  основная точка входа system/bach.py (на основе реестра версии 2.0)
  system/bach_api.py API библиотеки (задача, память, резервное копирование и т. д.)
  система/ядро/основные модули (реестр, приложение, база данных, база)
  реализации обработчика system/hub/*.py (автоматическое обнаружение)
  system/tools/*.py Tool-Scripts

СХЕМА БАЗЫ ДАННЫХ
----------------

  system/db/schema.sql Полная схема БД (более 210 таблиц)
  system/data/bach.db База данных SQLite

Доступ через CLI:
  python bach.py --db Schema Показать схему БД
  python bach.py --db table Показать все таблицы

АРХИТЕКТУРА ОБРАБОТЧИКА
-------------------

Обработчик справки: system/hub/help.py
  - Показывает файлы .txt из system/docs/help/.
  - Поддерживает подпапки (tools/, wiki/)
  - Система псевдонимов для агентов, рабочих процессов, _experts
  - Прямой доступ к инструменту из БД (v1.1.38+)

Обработчик документов: system/hub/docs.py
  - Списки/поиск документов/папок
  - Сгруппировано по ПОНЯТИЯМ, АНАЛИЗУ, СХЕМАТИКЕ, ПРОЧЕМУ.
  - Операции: список, показ, поиск
