РОЛИ АГЕНТОВ, БОССЫ И МУЛЬТИПРОВАЙДЕРНОЕ ДЕЛЕГИРОВАНИЕ
======================================================

ОПИСАНИЕ
BACH использует ролевую модель агентов-экспертов и боссов.
Buddha (локальная модель Ollama qwen3.8:27b-mlx) выступает в роли
универсального воркера первой линии (Tier-1), который может автономно брать на
себя все роли в режиме простоя.

BUDDHA КАК УНИВЕРСАЛЬНЫЙ ВОРКЕР
-------------------------------
- Idle Worker в фоне забирает задачи для всех боссов и экспертов из
  очереди задач.
- Изоляция сессий: каждая задача запускается в изолированной сессии
  (idle-<rolle>-<task_id>), без загрязнения контекста.
- Формирование персоны: модель входит в персону соответствующей роли
  (идентичность, тон, профиль задач из system/agents/personas/).

4-УРОВНЕВЫЙ ПРОТОКОЛ ЭСКАЛАЦИИ (Для КАЖДОЙ роли!)
-------------------------------------------------
Каждая роль обязательно работает по следующим четырём приоритетам:

  Уровень 1 - Прямое решение:
    Обозримые задачи сразу реализовать в коде/системе, протестировать и
    закоммитить локально.

  Уровень 2 - Самодекомпозиция:
    Если задача сложная, роль самостоятельно разбивает задачу на 3-5
    атомарных подзадач (task_manage action='decompose').

  Уровень 3 - Неоднозначность:
    Принцип минимальной инвазивности. При открытом вопросе выбора: создать
    точный выбор вариантов [A] / [B] как задачу TO-DECIDE.

  Уровень 4 - Делегирование провайдеру Tier-2:
    Если задача превышает пределы локальной модели (глубокие алгоритмы,
    рефакторинг нескольких репозиториев):
    Чёткая передача в Claude Code или Codex через:
      delegate(target='claude', prompt='...', context='...')
      delegate(target='codex', prompt='...', context='...')
