RESTAURAR BACH - RESTAURAR PLANTILLA
------------------------------------------

Restaura archivos PLANTILLA (dist_type=1) y archivos CORE (dist_type=2)
del manifiesto de distribución.


USE
----------

  # Restaurar un solo archivo
  bach restore <datei-pfad>

  # Recuperar todos los archivos PLANTILLA
  bach restore --all

  # Recuperar archivos CORE (con advertencia)
  bach restore --core

  # Ejecución en seco (solo ver, no ejecutar)
  bach restore --dry-run <datei-pfad>


DIST_TYPE SYSTEM
----------------

  0 = USER_DATA Archivos personales, NO recuperables
  1 = PLANTILLA Plantillas de sistema personalizables, RESTAURABLES
  2 = NÚCLEO Núcleo del sistema, recuperable (con advertencia)


IMPORTANTE
-------

- USER_DATA (dist_type=0) NUNCA se sobrescribe
- CORE-Restore muestra una advertencia porque los cambios se perderán
- Se recomienda realizar una copia de seguridad antes de restaurar el CORE


EJEMPLOS
---------

  # Restaurar SKILL.md (PLANTILLA)
  bach restore SKILL.md

  # Restaurar todas las plantillas de conectores
  bach restore system/connectors/templates/

  # Verifique qué archivos se restaurarán
  bach restore --dry-run --all


VER TAMBIÉN
----------

  bach --help upgrade       Actualizar a una versión más nueva de BACH
  bach --help downgrade     Bajar a una versión anterior
  bach --help seal          Verificación de integridad
