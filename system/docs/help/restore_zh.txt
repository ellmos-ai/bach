BACH RESTORE - TEMPLATE RESTORE
------------------------------------------

恢复 TEMPLATE 文件 (dist_type=1) 和 CORE 文件 (dist_type=2)
来自分发清单。


使用
----------

  # 恢复单个文件
  bach restore <datei-pfad>

  # 恢复所有模板文件
  bach restore --all

  # 恢复 CORE 文件（有警告）
  bach restore --core

  # 空运行（仅查看，不执行）
  bach restore --dry-run <datei-pfad>


DIST_TYPE SYSTEM
----------------

  0 = USER_DATA 个人文件，不可恢复
  1 = 模板 可定制的系统模板，可恢复
  2 = CORE 系统核心，可恢复（有警告）


重要
-------

- USER_DATA (dist_type=0) 永远不会被覆盖
- CORE-Restore 显示警告，因为更改将丢失
- 建议在核心恢复之前进行备份


示例
---------

  # 恢复 SKILL.md（模板）
  bach restore SKILL.md

  # 恢复所有连接器模板
  bach restore system/connectors/templates/

  # 检查哪些文件将被恢复
  bach restore --dry-run --all
