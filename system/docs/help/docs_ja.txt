DOCS - 人間が読めるドキュメント
=====================================

説明
------------
ヘルプ システム (AI 用に最適化) に加えて、人間が読めるドキュメントが 2 つあります
ASCII グラフィックと概要を含むドキュメント。

ドキュメント レベル
--------------------
BACH には 3 つのドキュメント レベルがあります:

  ┌───────────────────────────┐
  │ レベル │ 対象グループ │ 場所 │
  ---------------------------------------------------------------------- --------------------------------------------------------┤
  │ docs/README.txt │ 開発者 │ docs/ │
  │ (開発) │ 貢献者 │ │
  ---------------------------------------------------------------------- --------------------------------------------------------┤
  │ ARCHITECTURE.md │ 開発者 │ system/ │
  │ (建築) │ 深い │ │
  ---------------------------------------------------------------------- --------------------------------------------------------┤
  │ docs/help/*.txt │ AI エージェント │ system/docs/help/ │
  │ (工作員) │ クロード 他 │ │
  ---------------------------------------------------------------------- --------------------------------------------------------┤
  │ wiki/*.txt │ すべて │ system/wiki/ │
  │ (専門知識) │ │ │
  ━━━━━━━━━━━━━━━━━━━━━━┘

書類
---------

  docs/README.txt
  ---------------
  開発ドキュメント - ドキュメント/フォルダー構造の概要。
  - コンセプト (CONCEPT_*.md)
  - 分析とレポート
  - アーカイブされた古い概念 (_archive/)
  - 長期的なアイデア (_ideas/)
  - テストとレポート (_test_and_reports/)

  対象者: 開発者、貢献者
  形式: 参照付きのプレーンテキスト

  システム/アーキテクチャ.md
  ------------------------
  開発者向けのシステム アーキテクチャ。
  - ビジョンとデザイン哲学
  - 高レベルのアーキテクチャ図
  - ハブとハンドラーのパターンの説明
  - データベーススキーマの視覚化
  - データフロー図
  - 拡張手順
  - 規約

  対象読者: 開発者、貢献者、上級ユーザー
  形式: ASCII 図を含むマークダウン

DEPARATION
----------
  docs/help/*.txt 操作リファレンス、機械可読、一貫性のある
  docs/README.txt 開発者の概要、フォルダー構造
  system/ARCHITECTURE.md 技術的理解、アーキテクチャ、設計

  help は主要なドキュメントです。
  詳細については、docs/README.txt および ARCHITECTURE.md のヘルプを参照してください。

更新
--------------
システムの大幅な変更については、すべてのレベルで行う必要があります。
更新予定:

  1. docs/help/*.txt - コマンド、操作 (常に最新の状態に保つ)
  2. docs/README.txt - 概念/フォルダーの変更について
  3. system/ARCHITECTURE.md - アーキテクチャ変更の場合

GITHUB PUBLISHING
------------------------
GitHub で公開する場合:

  - system/ARCHITECTURE.md をメインエントリとしてリンクします
  - 開発者の概要については docs/README.txt
  - 統合ドキュメントとしてヘルプ システムについて言及

ファイル パス
----------
  docs/README.txt 開発者の概要
  system/ARCHITECTURE.md アーキテクチャに関するドキュメント
  system/docs/help/*.txt 操作ヘルプ (これらのファイル)
  system/wiki/*.txt 背景知識

関連項目
----------
  bach --help list         すべてのヘルプ トピック
  bach wiki list           すべての Wiki 記事
  docs/help/practices.txt アーキテクチャの原則
  docs/help/naming.txt 命名規則
