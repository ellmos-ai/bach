CLOUD - 提供商中立的云同步控制
==================
Cloud-Control 服务可防止在写入密集型操作、备份和批量维护运行期间出现文件
锁、同步冲突和 SQLite-WAL 碰撞。

支持的提供商
------
- Microsoft OneDrive (Windows / macOS / Linux)
- Google Drive (Windows / macOS)
- Apple iCloud Drive (macOS bird / CloudDocs, Windows iCloud.exe)
- Dropbox (Windows / macOS / Linux)
- Nextcloud / ownCloud (Windows / macOS / Linux)

核心概念
----
1. AUTO-DETECTION：启动时自动检测已安装和正在运行的客户端。
2. 运行保护：云同步仅在写入密集型作业期间定点暂停，并在之后立即重新激活
   （空闲时不会永久停止）。
3. FAIL-SAFE WATCHDOG：安全计时器保证在超时到期后（默认：300s）重新激活
   已暂停的客户端，即使发生程序崩溃也是如此。
4. 架构与图表：请参阅 docs/ARCHITECTURE_CLOUD_CONTROL.md

CLI 命令（bach cloud）
------------------
  bach cloud status                     所有已检测到的云服务概览
  bach cloud status --json              JSON 格式的状态
  bach cloud pause [provider] [-t SEC]  带安全超时地暂停同步（默认：300s）
  bach cloud resume [provider]          恢复已暂停的服务
  bach cloud toggle [provider]          在暂停和恢复之间切换

PYTHON 上下文管理器
--------------
  from hub._services.cloud import cloud_pause

  with cloud_pause(timeout=180):
      # 写入密集型文件操作
      schreibe_daten()
  # 云同步将在后台自动恢复
