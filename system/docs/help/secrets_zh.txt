# 机密

BACH 仅把机密值存储在操作系统凭据库中。`bach.db` 和
`~/.bach/bach_secrets.json` 只包含元数据和后端标记。缺少元数据索引时，
凭据不会被删除。

操作
----

- `bach secrets list`：仅显示元数据和后端状态。
- `bach secrets get <key>`：检查可用性，但不显示值。
- `bach secrets set <key>`：通过隐藏的交互输入读取值。
- `bach secrets set <key> --stdin`：从 stdin 读取值且不记录日志。
- `bach secrets delete <key>`：删除值及其元数据。
- `bach secrets sync`：验证凭据库后迁移旧的明文值。

作为进程参数传入的机密值会被拒绝。
