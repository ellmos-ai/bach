CLOUD - プロバイダ中立のクラウド同期制御
====================
Cloud-Control サービスは、書き込み集約型の操作、バックアップ、および一括メンテ
ナンス実行時のファイルロック、同期競合、SQLite-WAL 衝突を防止します。

対応プロバイダ
-------
- Microsoft OneDrive (Windows / macOS / Linux)
- Google Drive (Windows / macOS)
- Apple iCloud Drive (macOS bird / CloudDocs, Windows iCloud.exe)
- Dropbox (Windows / macOS / Linux)
- Nextcloud / ownCloud (Windows / macOS / Linux)

コアコンセプト
-------
1. AUTO-DETECTION: 起動時にインストール済みおよび実行中のクライアントを自動検
   出します。
2. 運用保護: クラウド同期は書き込み集約型ジョブの実行中のみ一時停止され、終了後
   すぐに再開されます (アイドル時の恒久的な停止はありません)。
3. FAIL-SAFE WATCHDOG: 安全タイマーにより、プログラムがクラッシュした場合でも
   タイムアウト経過後 (デフォルト: 300s) に一時停止中のクライアントを確実に再開
   します。
4. アーキテクチャ & 図: docs/ARCHITECTURE_CLOUD_CONTROL.md を参照

CLI コマンド (bach cloud)
--------------------
  bach cloud status                     検出されたすべてのクラウドサービスの概要
  bach cloud status --json              JSON 形式のステータス
  bach cloud pause [provider] [-t SEC]  安全タイムアウト付きで同期を一時停止 (デフォルト: 300s)
  bach cloud resume [provider]          一時停止中のサービスを再開
  bach cloud toggle [provider]          一時停止と再開を切り替え

PYTHON コンテキストマネージャ
--------------
  from hub._services.cloud import cloud_pause

  with cloud_pause(timeout=180):
      # 書き込み集約型のファイル操作
      schreibe_daten()
  # クラウド同期はバックグラウンドで自動的に再開されます
