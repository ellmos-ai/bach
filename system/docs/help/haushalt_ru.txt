НАЗВАНИЕ ДИЛЕРА
============
домашнее хозяйство

ОПИСАНИЕ
============
Управление домашним хозяйством с помощью распорядка дня, инвентаризации, списков покупок и планирования затрат.
Управляет ежедневными задачами, управлением запасами с помощью системы светофоров (красный/желтый/зеленый),
Поставщики и постоянные затраты. Интеграция с рутинным обработчиком и единой базой данных BACH.


ОПЕРАЦИИ
===========

статус
  Панель управления домохозяйством: текущий обзор, светофор инвентаря, ежемесячные фиксированные расходы,
  Список покупок, поверхностные распорядки дня. Объединение всех подсистем.
  Синтаксис: статус семьи Баха

срок [ДНИ]
  Задачи со сроком выполнения в ближайшие N дней (по умолчанию: 7 дней).
  Отделяет просроченные (КРАСНЫЙ) от ожидающих (ЖЕЛТЫЙ) процедур.
  Синтаксис: домохозяйство Баха | дом Баха должен родить 14 лет 

сегодня
  Ежедневный обзор: Что происходит сегодня? (Рутина + встречи).
  Загружает службу DailyOverview.
  Синтаксис: домохозяйство Баха сегодня

неделя
  План на неделю (пн-вс): распорядок дня + встречи с указанием времени.
  Отмечает просроченные товары на текущей неделе.
  Синтаксис: неделя домохозяйства Баха

затраты
  Ежемесячный обзор фиксированных затрат.
  Рассчитывает ежемесячные нагрузки по контрактам (fin_contracts):
  - ежемесячно: прямой
  - ежегодно: /12
  - ежеквартально: /3
  Синтаксис: расходы на домохозяйство Баха

затраты в месяц [ФИЛЬТР]
  Ожидаемые нерегулярные расходы в месяц (страхование, техническое обслуживание).
  Необязательно: Фильтровать по категории.
  Синтаксис: расходы на домохозяйство Баха в месяц | расходы на домохозяйство Баха в месяц "авто"

дополнительные расходы НАИМЕНОВАНИЕ КАТЕГОРИЯ СУММА ИНТЕРВАЛ
  Добавьте нерегулярные расходы.
  ИНТЕРВАЛ: ежемесячно|ежеквартально|ежегодно|один раз
  Синтаксис: дополнительные затраты на домохозяйство Баха "TÜV" "авто" 150 "ежегодно"

список затрат [ФИЛЬТР]
  Показать все записи затрат со статусом.
  Синтаксис: список расходов на домохозяйство Баха 

 страховой чек
  Страховой чек: Все действующие полисы со взносами.
  Загружает fin_insurances, рассчитывает ежемесячную сумму.
  Синтаксис: чек семейной страховки 

шопинг
  Список покупок: все товары, которые еще предстоит приобрести, имеют приоритет.
  Синтаксис: бах домашние покупки

добавить-покупки ИМЯ [КАТЕГОРИЯ] [ПРИОРИТЕТ]
  Добавьте товары в список покупок.
  ПРИОРИТЕТ: нормальный|высокий|низкий (по умолчанию: нормальный)
  Синтаксис: баховская домашняя надстройка-покупка "молоко" "еда" "высокий"

ID сделанной покупки [ID2 ID3...]
  Отметить товар как купленный.
  Синтаксис: домохозяйство Баха сделало покупки 5 6 7

инвентарь
  Инвентарь с обзором светофора (красный/желтый/зеленый).
  Использует InventoryEngine со шпалами.
  Синтаксис: домашний инвентарь Баха

добавить элемент НАЗВАНИЕ КАТЕГОРИЯ ПОРОГ ХРАНЕНИЯ [LAGERMAX]
  Добавьте предметы в инвентарь.
  ПОРОГ ХРАНЕНИЯ: Значение, при котором отображается красный цвет.
  Синтаксис: баховская бытовая добавка «оливковое масло» «кулинария» 0,5 2

на складе НАИМЕНОВАНИЕ ТОВАРА КОЛИЧЕСТВО [ДАТА]
  Проводка поступления товара (на склад). Создает транзакцию.
  Синтаксис: бах бытовой запас "Olivenoel" 1.5 2026-03-04

нет в наличии НАИМЕНОВАНИЕ ТОВАРА КОЛИЧЕСТВО [ДАТА]
  Постпотребление (со склада). Создает транзакцию.
  Синтаксис: запас в доме Баха "Olivenoel" 0,3 04.03.2026

pull-check
  Список покупок: какие товары необходимо приобрести?
  Показывает КРАСНЫЙ (ниже порогового значения) и ЖЕЛТЫЙ (ниже максимального) элементы.
  Синтаксис: баховская домашняя проверка

светофор
  Обзор светофора: все предметы инвентаря со статусом (КРАСНЫЙ/ЖЕЛТЫЙ/ЗЕЛЕНЫЙ).
  Синтаксис: бытовой светофор баха

заказать [ПУНКТ] [КОЛИЧЕСТВО]
  Создавайте заказы на товары или просматривайте отложенные заказы.
  Синтаксис: бах бытовой порядок | баха бытовой заказ "Olivenoel" 5

поставщик
  Показать поставщиков с контактами и доступными товарами.
  Синтаксис: поставщик бытовой техники Баха

добавить-поставщика ИМЯ КОНТАКТ [ДНИ ДОСТАВКИ]
  Добавить поставщика.
  ДНИ ДОСТАВКИ: Среднее время доставки (по умолчанию: 5).
  Синтаксис: поставщик бытовых дополнений bach "BioGro GmbH" "info@biogro.de" 3

программа экспорта [ФИЛЬТР]
  Экспорт процедур для внешнего использования/резервного копирования.
  Необязательно: Фильтровать по категории.
  Синтаксис: процедура экспорта домашнего хозяйства Баха | Программа экспорта домашнего хозяйства Баха "Кухня"

помощь
  Просмотрите эту справку.
  Синтаксис: помощь по дому 


 ПРИМЕРЫ 
=========

1. Просмотр панели мониторинга:
   bach haushalt status

2. Просроченные программы на эту неделю:
   bach haushalt due 7

3. Еженедельный план с распорядком дня + встречи:
   bach haushalt week

4. Добавьте товары в список покупок:
   bach haushalt add-shopping "Mehl" "Lebensmittel" "normal"

5. Проводка поступления товара:
   bach haushalt stock-in "Mehl" 2.5

6. Список покупок (чего не хватает?):
   bach haushalt pull-check

7. Ежемесячные постоянные расходы:
   bach haushalt costs

8. Добавьте нерегулярные расходы:
   bach haushalt add-kosten "KFZ-Versicherung" "auto" 80 "monatlich"

ТАБЛИЦЫ БАЗЫ ДАННЫХ
===================
bach.db/Единая база данных (начиная с версии 1.1.84):
- house_routines Ежедневные задачи/рутинное управление
- предметы домашнего_инвентаря с пороговыми значениями
- house_orders Заказы поставщикам
- контакты поставщика house_suppliers
- заказы на вход/выход домохозяйства_stock_transactions (журнал аудита)
- списки покупок house_shopping
- house_costs Нерегулярные расходы
- встречи Assistant_calendar (для еженедельного плана)
- контракты fin_contracts (для фиксированных затрат)
- страхование fin_insurances (для панели статуса)


СМОТРИТЕ ТАКЖЕ
==========
bach routine ...                  Регулярное управление (отдельные штаты)
bach routine done <id>            Отметить план как завершенный
bach fin costs                    Управление финансовыми затратами
bach calendar ...                 Управление назначениями
