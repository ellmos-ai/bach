BACH ハンドラー: シークレット
---------------------

API キー、トークン、アクセス データを安全に管理します。

使用
----------

  bach --secrets list                すべてのシークレットを表示 (キーのみ)
  bach --secrets get <key>           シークレットの値を取得
  bach --secrets set <key> <value>   シークレットの設定/更新
  bach --secrets delete <key>        シークレットの削除

オプション
--------

  --category <cat> カテゴリ (一般、API、電報など)
  --description <text> シークレットの説明

LOCATION
-----------

  ~/.bach/bach_secrets.json (Fernet で暗号化)
  system_config で構成: Secrets_file_path

SECURITY
----------

  - シークレットは Fernet (AES-128-CBC) で暗号化されます。
  - ソルト: 16 バイト固定 (改行区切りではありません!)
  - シークレットを Git にコミットしないでください
  - .gitignore

MODULE
-----

 の Secret ファイル  Hub/secrets_handler.py (SecretsHandler)
