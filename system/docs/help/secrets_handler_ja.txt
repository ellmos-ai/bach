BACH ハンドラー: シークレット
=============================

シークレット値は OS のキーチェーンだけに保存されます。`bach.db` と
`bach_secrets.json` にはメタデータだけが保存されます。

使用方法
--------

  bach secrets list
  bach secrets get <key>
  bach secrets set <key> [--desc=TEXT] [--category=CAT]
  bach secrets set <key> --stdin [--desc=TEXT] [--category=CAT]
  bach secrets delete <key>
  bach secrets sync

セキュリティ
------------

  - `get` はシークレット値を stdout に出力しません。
  - プロセス引数として渡された値は拒否されます。
  - キーチェーンを検証できない場合、移行は中止されます。
