ИМЯ ОБРАБОТЧИКА
============
inject -- Управление инжектором и назначение задач

ОПИСАНИЕ
============
Обработчик инъекций управляет системой инжектора для автоматизированного
Внедрение контекста и назначение задач. Инжекторы — это плагины, которые
автоматически для определенных триггеров (слов, времени, завершения задачи).
предоставлять полезные подсказки или действия.

ОПЕРАЦИИ
===========
статус
  Показывает состояние всех форсунок (активны/неактивны).
  Синтаксис: --inject status

toggle <имя>
  Включает или выключает инжектор.
  Синтаксис: --inject toggle <имя>

  Доступные форсунки:
    стратегия Полезные мысли о словах-триггерах
    контекст Контекстные подсказки для ключевых слов
    time Регулярное обновление времени (timebeat)
    между автоматическим напоминанием после выполнения задачи

задача <минуты>
  Назначает новую задачу с указанной длительностью.
  Синтаксис: --inject Task <минуты>
  По умолчанию: 5 минут

разложение <id>
  Разбивает существующую задачу на подцели.
  Синтаксис: --inject decompose <task-id>

ПРИМЕРЫ
=========
# Проверить состояние всех инжекторов
--inject status

# Включить инжектор стратегии
--inject toggle Strategy

# Назначить задачу на 15 минут
--inject Task 15

# Дизассемблировать задачу с идентификатором 'abc123'
--inject разложить abc123
