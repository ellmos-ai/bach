ОПИСАНИЕ
----------------------------------------
batch_file_ops.py — Пакетные операции с файлами

Собирает и удаляет/перемещает/копирует файлы по шаблону.

Использование:
    python patch_file_ops.py delete <folder> --pattern "*.py"
    python patch_file_ops.py delete <folder> --pattern "TOOLS_*.py"
    python patch_file_ops.py move <источник> <пункт назначения> --pattern "*.txt"
    python patch_file_ops.py copy <источник> <назначение> --pattern "*.md"
    список python patch_file_ops.py <папка> --pattern "*"
    python patch_file_ops.py delete <folder> --pattern "*.py" --dry-run

Автор: Claude

USE
----------------------------------------
