ОПИСАНИЕ
----------------------------------------
german_scanner.py — находит немецкие строки в проектах Python

Сканирует файлы Python на предмет:
  - Строки с умлаутами (ae, oe, ue, ss)
  - Тексты GUI (setText, setWindowTitle, QLabel и т. д.)
  - Ключевые слова на немецком языке (файл, редактирование, сохранение и т. д.)

Полезно для:
  - Подготовьтесь к интернационализации (i18n).
  - Найти жестко закодированные строки
  - Создание списков переводов

Извлечено из: Цикл разработки A3 Advanced/TranslationSystem.py

Использование:
    python german_scanner.py <папка>
    python german_scanner.py <папка> --json
    python german_scanner.py <папка> --export Translations.json

Автор: Клод (адаптировано)
Зависимости: нет (только stdlib)

USE
----------------------------------------
инструменты Python bach.py запускают german_scanner [args]
или напрямую: python Tools/german_scanner.py [args]
