ОПИСАНИЕ
----------------------------------------
file_cleaner.py - Очистка файлов по возрасту/шаблону
------------------------------------------------------

Находит и удаляет старые файлы или файлы по шаблону.
Полезно для резервных копий папок, журналов, временных файлов.

Использование:
    python file_cleaner.py <папка> --age 30 # Старше 30 дней
    python file_cleaner.py <папка> --pattern "*.log" # По шаблону
    python file_cleaner.py <folder> --keep 5 # Сохранить 5 новейших
    python file_cleaner.py <folder> --execute # фактически удалить

Автор: BACH v1.1

USE
----------------------------------------
инструменты python bach.py запускают file_cleaner [args]
или напрямую: инструменты python/file_cleaner.py [args]
