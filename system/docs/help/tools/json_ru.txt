Инструмент BACH: обработка JSON
---------------

JSON, восстановление и очистка реестра.

ДОСТУПНЫЕ ИНСТРУМЕНТЫ
-----------------

  json_config_cli Управление файлами конфигурации JSON
  json_fixer Исправить поврежденные файлы JSON
  json_registry_cleaner Инструмент очистки реестра
  json_repair Автоматически исправлять синтаксис JSON

ИСПОЛЬЗОВАТЬ
----------

  bach --tools json fix <datei.json>      Восстановить поврежденный JSON
  bach --tools json config <key> [value]  Чтение/установка конфигурации
  bach --tools json clean-registry        Очистить реестр

-----
