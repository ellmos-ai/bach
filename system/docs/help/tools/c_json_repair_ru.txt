ОПИСАНИЕ
----------------------------------------
c_json_repair.py — Полностью автоматическая система восстановления JSON

Использует `pip install emoji` для достижения наилучших результатов (многоязычный, текущий).
Возврат к локальному файлу gemoji.json, если пакет emoji не установлен.

Рабочий процесс:
1. Найдены эмодзи -> Поиск через пакет emoji или gemoji.json.
2. Найдено -> Auto-ASCII по имени (например, «гаечный ключ» -> «[Гаечный ключ]»)
3. Не найден -> Quarantaene [Q:XXXX] (очень редко)

Использование:
    python c_json_repair.py <file.json> # Восстановление
    python c_json_repair.py <file.json> --dry-run # Только проверка
    python c_json_repair.py --update-gemoji # Обновить Gemoji
    python c_json_repair.py --stats # Статистика

Автор: Клод
Версия: 3.1.0 — с поддержкой пакета emoji + резервный вариант
