ОПИСАНИЕ
----------------------------------------
encoding_fixer.py — устранение проблем с кодировкой в текстовых файлах

Назначение: исправление ошибок кодировки (Mojibake, неправильное декодирование UTF-8 и т. д.)
       с библиотекой ftfy. Автоматически создает резервные копии.

Автор: Клод (адаптировано из EncodingFixxer.py)
Зависимости: ftfy (pip install ftfy), os, json (stdlib)

Использование:
    python encoding_fixer.py <файл_или_папка> [--no-backup] [--recursive] [--json]

Примеры:
    python encoding_fixer.py script.py # Один файл
    python encoding_fixer.py ./src --recursive # Вся папка
    python encoding_fixer.py file.py --no-backup # Без резервного копирования
    python encoding_fixer.py file.py --json # Вывод JSON

USE
----------------------------------------
инструменты Python bach.py запускают encoding_fixer [args]
или напрямую: python Tools/encoding_fixer.py [args]
