ОПИСАНИЕ
----------------------------------------
tool_scanner.py — Сканирует систему на наличие доступных инструментов CLI
-----------------------------------------------------------

Находит установленные инструменты и сравнивает их с зарегистрированными инструментами.
Полезно для обнаружения инструментов и инвентаризации системы.

Использование:
    pythontool_scanner.py scan # Система сканирования
    pythontool_scanner.py --json # Вывод JSON
    pythontool_scanner.py Compare # Сравнить с реестром

Автор: BACH v1.1 (на основе Partner_scanner.py)

USE
----------------------------------------
Инструменты Python bach.py запускаютtool_scanner [args]
или напрямую: python Tools/tool_scanner.py [args]
