HERRAMIENTAS DE MAPEO - Comparación de características entre sistemas
---------------------------------------------------

A partir de: 2026-01-23
Ruta: docs/help/tools/mapping.txt

DESCRIPCIÓN
------------
Herramientas de mapeo de características para comparar y analizar
de características en diferentes sistemas.
Parte del proyecto BACH_STREAM.

Ruta: herramientas/mapping/

FILES
-------
  query_features.py Consultar y comparar características
  populate_features.py Rellenar base de datos con características
  esquema.sql Esquema de base de datos

BASE DE DATOS
---------
Ubicación: BACH_STREAM/MAPPING/feature_mapping.db

Tablas:
  sistemas Sistemas registrados (CHIAH, BATCH, recludOS, etc.)
  características Definiciones de características
  feature_categories Categorización (Memoria, GUI, Tareas, etc.)
  implementaciones Qué sistema tiene qué característica

FUNCIONES PRINCIPALES
---------------

feature_matrix(categoría=Ninguna):
  Muestra qué sistema tiene qué característica.

  matriz query_features.py de Python
  matriz python query_features.py --categoría "Memoria"

  Símbolos:
    + = implementado (completo)
    ~ = parcial
    ?  = planeado/desconocido
    - = no presente

feature_synopsis(feature_name):
  Compara una única característica en todos los sistemas.
  Muestra caminos, tecnología, notas.

  python query_features.py sinopsis "Memoria de trabajo"

USE
----------

Generar matriz de características:
  python tools/mapping/query_features.py matriz

Filtrado por categoría:
  python tools/mapping/query_features.py matriz --categoría "GUI"

Sinopsis de la característica:
  python tools/mapping/query_features.py sinopsis "Inyectores"

Ingrese nuevas funciones:
  python tools/mapping/populate_features.py

INTEGRACIÓN CON BACH
--------------------
El sistema de mapeo ayuda con:
  - Migración de sistemas anteriores
  - Identificación de características faltantes.
  - Documentación del estado de implementación
