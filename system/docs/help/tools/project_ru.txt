Инструмент BACH: Управление проектами
------------------

Управление проектами и генерация кода.

ДОСТУПНЫЕ ИНСТРУМЕНТЫ
-----------------

  Audit_bundler Экспортировать аудит проекта как пакет
  License_generator Генерировать файлы лицензий
  Pattern_tool Распознавание образов кода
  project_bundler Объединить проект как пакет
  Structure_generator Создать структуру проекта

ИСПОЛЬЗОВАТЬ
----------

  bach --tools project audit <pfad>      Аудит проекта
  bach --tools project license <typ>     Сгенерировать лицензию (MIT, Apache и т. д.)
  bach --tools project bundle <pfad>     Объединить проект
  bach --tools project structure <name>  Создать новую структуру проекта

-----
