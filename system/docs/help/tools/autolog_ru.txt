Инструмент BACH: autolog
--------------------------------------------------
Сгенерировано: 23 января 2026 г., 10:36.
Источник: инструменты/autolog.py

ОПИСАНИЕ
----------------------------------------
Авторегистратор — автоматически регистрирует все действия
-----------------------------------------------------

Двухэтапная система:
1. auto_log.txt - Последние 300 строк (краткосрочная память)
2. auto_log_extended.txt — старые записи, максимум 30 дней (архив)

Через 30 дней записи будут окончательно удалены.

ИСПОЛЬЗОВАНИЕ
----------------------------------------
инструменты Python bach.py запускают autolog [args]
или напрямую: python Tools/autolog.py [args]

ПРИМЕЧАНИЯ
----------------------------------------
- Автоматически генерируется из строки документации.
- Если у вас есть вопросы: инструменты bach показывают автолог.
