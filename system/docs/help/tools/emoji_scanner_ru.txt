ОПИСАНИЕ
----------------------------------------
emoji_scanner.py — сканер Emoji с интеграцией пакетов Gemoji/emoji

Сканирует файлы на наличие смайлов и показывает, какие из них можно разрешить автоматически.
Использует тот же бэкэнд, что и json_repair.py (пакет emoji или резервный вариант gemoji.json).

Использование:
    python emoji_scanner.py <файл_или_папка>
    python emoji_scanner.py --scan-batch # Все файлы _BATCH JSON
    python emoji_scanner.py --status # Статус системы

Автор: Клод
Версия: 3.0 — унифицирована с инструментами json_repair.py

USE
----------------------------------------
python bach.py, запускающими emoji_scanner [args]
или напрямую: инструменты Python/emoji_scanner.py [args]
