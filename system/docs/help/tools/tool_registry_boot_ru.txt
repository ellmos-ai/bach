ОПИСАНИЕ
----------------------------------------
Интеграция загрузки для реестра инструментов
-----------------------------------

Вызывается во время процесса загрузки RecludOS.
Загружает все реестры инструментов в глобальный контекст.

Версия: 1.0.0

USE
----------------------------------------
инструменты Python bach.py запускаютtool_registry_boot [args]
или напрямую: python Tools/tool_registry_boot.py [args]

ПРИМЕЧАНИЯ
----------------------------------------
- Автоматически генерируется из строки документации.
- Если у вас есть вопросы: инструменты bach показываютtool_registry_boot.
