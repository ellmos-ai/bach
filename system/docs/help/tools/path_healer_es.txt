GESTIÓN DE RUTAS EN BACH
======================

IMPORTANTE: ¡Las rutas se administran AUTOMÁTICAMENTE en BACH!
-------------------------------------------------------
bach_paths.py es la "única fuente de verdad" para todas las rutas.
Todas las rutas se calculan dinámicamente: cuando se mueve BACH,
todo funciona automáticamente. Las reparaciones manuales de rutas son
Normalmente NO es necesario.

  from bach_paths import get_path, BACH_ROOT, TOOLS_DIR
  tools = get_path("tools") # Siempre correcto, sin importar dónde se encuentre BACH

Ver: bach --help bach_paths (documentación completa)


¿CUÁNDO ES NECESARIA LA ACTUALIZACIÓN MANUAL DE LA RUTA?
----------------------------------------------
Solo si las rutas están en DOCUMENTACIÓN y COMENTARIOS
(no en el código que usa get_path()). Asunto:
  - Archivos de ayuda (.txt)
  - Artículo Wiki (.txt)
  - Documentación de rebajas (.md)
  - Cadenas de documentos en archivos Python

Existe Doc Path Updater para este propósito:

  bach --maintain docs-paths             # Ejecución en seco (solo vista)
  bach --maintain docs-paths --apply     # Realmente arreglarlo

Herramienta: system/tools/maintenance/doc_path_updater.py


¿QUÉ SE HIZO MAL ANTES?
----------------------------------
El antiguo "path_healer.py" (reliquia de RecludOS) probó TODOS los archivos
para sanar, incluido el código Python. Eso fue:
1. Superfluo (bach_paths.py resuelve esto dinámicamente)
2. Peligroso (las reglas no idempotentes corrompieron 101 archivos)
3. Nunca se integró correctamente (nombre de archivo incorrecto en el controlador CLI)

Desde v2.1.0, la herramienta se limita a actualizaciones de documentación
e idempotente (se puede ejecutar tantas veces como se desee).
