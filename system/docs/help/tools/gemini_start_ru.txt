Инструмент BACH: gemini_start
--------------------------------------------------
Сгенерировано: 24 января 2026 г. (обновлено)
Источник: инструменты/gemini_start.py

ОПИСАНИЕ
----------------------------------------
BACH Gemini Starter — запускает интерфейс командной строки Gemini (без головы) или Antigravity (GUI).

ДВЕ БЭКЕНДЫ
----------------------------------------
  --cli Gemini CLI (безголовый, полностью автоматический с --yolo)
  --gui Антигравитация (подсказка скопирована в буфер обмена)

ВАЖНО: Антигравитация не имеет безголового режима! Для автоматизации
         ДОЛЖЕН использовать интерфейс командной строки Gemini (--cli).

ИСПОЛЬЗОВАТЬ
----------------------------------------
python Tools/gemini_start.py [BACKEND] [ОПЦИИ]

  BACKEND (требуется для неавтоматического режима):
    --cli Gemini CLI (полностью автоматический)
    --gui Антигравитация (подсказка в буфере обмена)

  РЕЖИМЫ:
    (без) автоматический режим (полезно только с --cli)
    --bulk Массовый режим без ограничения задач
    --default Интерактивный (ждёт инструкций)
    --individual Использовать startprompt_gemini.txt
    --mode ИМЯ Использовать приглашения/ИМЯ.txt

  ОПЦИИ:
    --tasks N количество задач в автоматическом режиме (по умолчанию: 2)
    --prompt «ТЕКСТ» Непосредственно указать пользовательское приглашение
    --list Список доступных шаблонов подсказок
    --dry-run Показать только команду, не запускать

ПРИМЕРЫ CLI (полностью автоматически)
----------------------------------------
  инструменты Python/gemini_start.py --cli # Авто (2 задачи)
  инструменты Python/gemini_start.py --cli --tasks 5 # Авто (5 задач)
  инструменты Python/gemini_start.py --cli --bulk # Все задачи (бесконечные)
  инструменты Python/gemini_start.py --cli --mode Analysis # режим анализа

ПРИМЕРЫ ГИП (запрос на буфер обмена)
----------------------------------------
  инструменты Python/gemini_start.py --gui --bulk # Массовое приглашение
  инструменты Python/gemini_start.py --gui --default # Интерактивная подсказка
  инструменты Python/gemini_start.py --gui --individual # Приглашение пользователя
  инструменты Python/gemini_start.py --gui --mode Analysis # подсказка анализа

GUI-WORKFLOW:
  1. Скрипт запускает Антигравитацию.
  2. Быстро копируется в буфер обмена.
  3. Пользователь заходит в чат, нажимает Ctrl+V, Enter

ШАБЛОНЫ ПОДСКАЗОК (партнеры/близнецы/подсказки/)
----------------------------------------
  auto.txt Автоматический режим: обработка задач немедленно (только через интерфейс командной строки)
  Bulk.txt Массовый режим: ВСЕ задачи без ограничений
  default.txt Интерактивный: ждет инструкций.
  Analysis.txt Выполняет все сценарии анализа.
  Research.txt Режим исследования для тематического анализа

ПОЛЬЗОВАТЕЛЬСКОЕ ЗАПРОС
----------------------------------------
Отредактируйте Partners/gemini/startprompt_gemini.txt в соответствии с вашими собственными инструкциями.
Загружается с --individual.

BATCH-STARTER
----------------------------------------
Альтернативно: Partners/gemini/start_gemini.bat
Показывает интерактивное меню с выбором CLI/GUI.

ТРЕБОВАНИЯ
----------------------------------------
  Режим CLI: npm install -g gemini-cli
               вход в систему авторизации Gemini
  Режим графического интерфейса: Антигравитация установлена и находится в PATH
