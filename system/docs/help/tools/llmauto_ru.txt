Инструмент BACH: LLMauto (MarbleRun)
------------------------------

Автоматическое выполнение цепочки LLM с управлением состоянием.

ИСПОЛЬЗОВАНИЕ
----------

  bach --tools llmauto run <chain.yaml>    Запуск цепочки
  bach --tools llmauto list                Показать доступные цепочки
  bach --tools llmauto benchmark           Оценка производительности

ФОРМАТЫ ЦЕПИ
-------------

Цепочки определяются как YAML с шагами, которые
может выполняться последовательно или параллельно.

MODI
----

  последовательные действия один за другим
  параллельные шаги, параллельные
  условный Условное выполнение

STATE
-------

Состояние цепочки сохраняется в state.json для возобновления
после прерываний.
