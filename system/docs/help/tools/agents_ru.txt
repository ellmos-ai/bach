ИНСТРУМЕНТЫ АГЕНТА - Инструменты агента
--------------------------------

ОБЗОР
Агентские инструменты в BACH управляют и контролируют агентов ИИ.
и их взаимодействия.

AGENT FRAMEWORK
---------------
agent_framework.py

Базовая структура для всех агентов BACH.
Особенности:
  - Регистрация агента
  - Соответствие возможностей
  - Управление синергией

Вызов: используется внутри

AGENT CLI
---------
agent_cli.py

Командная строка для взаимодействия с агентом.
Команды:
  - список: Показать всех агентов
  - статус: проверить статус агента.
  - активировать: активировать агента
  - деактивировать: деактивировать агент

Вызов: python Tools/agent_cli.py <команда>

ИНТЕГРАЦИЯ СЕРВИСА АГЕНТА
-------------------------
agent_service_integration.py

Подключает агентов к службам BACH.
Позволяет:
  - Обнаружение услуг
  - Автоматическая маршрутизация
  - Балансировка нагрузки

ДОСТУПНЫЕ АГЕНТЫ
-------------------

Каталог: агенты/

  ati/разработчик программного обеспечения (ATI)
  Tax-agent.txt налоговый помощник
  Research.txt Исследовательский агент (исследования)
  Developer.txt Генеральный разработчик
  Production.txt производственный агент
  планировщик финансирования/помощник по планированию финансирования

AGENT CONVENTION
----------------

См.: навыки/AGENT_KONVENTION.md

Иерархия:
  Агенты BOSS: Полный контроль, долгосрочный
  Эксперты: Специализированные, краткосрочные
  Сервисы: Автоматические фоновые задачи

КОМАНДЫ АГЕНТА В BACH
---------------------

  bach --help agents       Документация агента
  bach --help ati          Помощь агенту ATI
  bach ati bootstrap       Создание проекта (ATI)
  bach ati migrate         Перенос проекта (ATI)

ДЕЛЕГИРОВАНИЕ АГЕНТАМ
---------------------

  bach delegate "task" --to=<agent>

Доступные направления:
  оллама, близнецы, второй пилот, недоумение, человек

РАЗРАБОТЧИК АГЕНТ
----------------
developer_agent.py

Специализированный агент для задач разработки.
Может:
  - Генерировать код
  - Анализировать ошибки
  - Создание тестов

PRODUCTION-AGENT
----------------
production_agent.py

Для производственных развертываний.
Особенности:
  - Строить процессы
  - Проверка развертывания
  - Поддержка отката

RESEARCH AGENT
--------------
research_agent.py

Исследования и сбор информации.
Источники:
  - Веб-поиск
  - Документация
  - Внутренняя база знаний
