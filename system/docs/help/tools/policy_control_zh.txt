policy_control.py - 中央代码片段注入

将标准化代码策略注入Python项目。
支持内联注入（小片段）和外部文件（大片段）。

用法：
    python policy_control.py <file.py> --inject emoji_safe
    python policy_control.py <file.py> --set standardfixer
    python policy_control.py <file.py> --检查 emoji_safe
    python policy_control.py <文件夹> --set standardfixer --recursive
    蟒蛇policy_control.py——列表
    python policy_control.py --list-sets
