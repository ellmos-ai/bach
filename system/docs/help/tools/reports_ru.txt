Инструмент BACH: отчеты
--------------------------------------------------
Создано: 23 января 2026 г., 10:36.
Источник: инструменты/reports.py

ОПИСАНИЕ
----------------------------------------
reports.py — Создает отчеты об изменениях для других подпрограмм управления

Создает читаемые отчеты Markdown на основе изменений каталога.
Сохраняется в: report/<alias>_changes_<date>.md

Использование:
    python report.py <псевдоним>
    навыки python report.py

ИСПОЛЬЗОВАНИЕ
----------------------------------------
инструменты python bach.py запускают отчеты [args]
или напрямую: python Tools/reports.py [args]

ПРИМЕЧАНИЯ
----------------------------------------
- Автоматически генерируется из Docstring
- Если у вас есть вопросы: инструменты bach показывают отчеты.
