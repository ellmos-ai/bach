BACH Tool: Testing
==================

Test-Framework fuer BACH-Systemtests und -Vergleiche.

VERFUEGBARE TOOLS
-----------------

  run_b_tests            BACH-Systemtests ausfuehren
  compare_systems        Systemvergleiche durchfuehren
  run_comparison_custom  Benutzerdefinierte Vergleiche
  populate_tests         Test-Daten generieren
  query_tests            Test-Ergebnisse abfragen

VERWENDUNG
----------

  bach --tools testing run               Alle Tests ausfuehren
  bach --tools testing compare <a> <b>   Systeme vergleichen
  bach --tools testing populate          Testdaten erstellen

MODUL
-----
