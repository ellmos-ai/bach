Инструмент BACH: RAG (Поисковая расширенная генерация)
------------------------------------------------

Векторный поиск документов для BACH.

ИСПОЛЬЗОВАНИЕ
----------

  bach --tools rag ingest <pfad>     Индексные документы
  bach --tools rag search <query>    Семантический поиск

ИНГЕСТ
------

Считывает документы и создает векторы:
  - Поддерживаемые форматы: .txt, .md, .pdf, .py.
  - Хранение в таблице document_vectors

ПОИСК
------

Поиск семантического сходства по индексированным документам.
Возвращает соответствующие разделы текста с оценкой.

МОДУЛЬ
-----

  инструменты/rag/ (ingest.py, search.py)
  Таблица БД: document_vectors (миграция 020)
