encoding_fixer.py - Fix encoding problems in text files

Purpose: Corrects encoding errors (Mojibake, incorrect UTF-8 decoding, etc.)
       with the ftfy library. Automatically creates backups.

Author: Claude (adapted from EncodingFixxer.py)
Dependencies: ftfy (pip install ftfy), os, json (stdlib)

Usage:
    python encoding_fixer.py <file_or_folder> [--no-backup] [--recursive] [--json]

Examples:
    python encoding_fixer.py script.py # Single file
    python encoding_fixer.py ./src --recursive # Entire folder
    python encoding_fixer.py file.py --no-backup # Without backup
    python encoding_fixer.py file.py --json # JSON output
