Инструмент BACH: Операции с файлами
--------------------------

Инструменты файловой системы для анализа и очистки.

ДОСТУПНЫЕ ИНСТРУМЕНТЫ
-----------------

  dirscan сканер каталогов со статистикой
  Dupe_detector Найти дубликаты файлов
  coding_fixer Исправить проблемы с кодировкой (UTF-8)
  file_cleaner Удалить временные/ненужные файлы
  file_manager Операции с файлами (перемещение, переименование)

ИСПОЛЬЗОВАНИЕ
----------

  bach --tools file_ops scan <pfad>        Анализ каталога
  bach --tools file_ops duplicates <pfad>  Найти дубликаты
  bach --tools file_ops encoding <pfad>    Проверить/исправить кодировку
  bach --tools file_ops clean <pfad>       Очистка

-----
