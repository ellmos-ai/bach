ОПИСАНИЕ
----------------------------------------
tool_discovery.py — рекомендации инструментов, основанных на проблемах
-----------------------------------------------------

Анализирует описания проблем и рекомендует подходящие инструменты BACH.

Использование:
    pythontool_discovery.py предлагает «проблему кодирования с умлаутами»
    Шаблоны списка pythontool_discovery.py
    pythontool_discovery.py --json

Автор: BACH v1.1
Версия: 1.0.0
Создано: 21 января 2026 г.

USE
----------------------------------------
инструменты python bach.py запускаютtool_discovery [args]
или напрямую: python Tools/tool_discovery.py [args]
