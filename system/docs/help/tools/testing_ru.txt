Инструмент BACH: тестирование
------------------

Среда тестирования для тестирования и сравнения систем BACH.

ДОСТУПНЫЕ ИНСТРУМЕНТЫ
-----------------

  run_b_tests Запуск системных тестов BACH
  Compare_systems Выполнить сравнение систем
  run_comparison_custom Пользовательские сравнения
  populate_tests Создать тестовые данные
  query_tests Запросить результаты теста

ИСПОЛЬЗОВАТЬ
----------

  bach --tools testing run               Запустить все тесты
  bach --tools testing compare <a> <b>   Сравнить системы
  bach --tools testing populate          Создать тестовые данные

МОДУЛЬ
-----
