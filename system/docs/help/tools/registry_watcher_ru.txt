Создано: 23 января 2026 г., 10:36.

ОПИСАНИЕ
----------------------------------------
BACH Registry Watcher v1.0.0

Автоматический мониторинг и проверка согласованности всех системных реестров.
Перенесено из RecludOS, интегрировано с системой баз данных BACH.

Особенности:
- Проверка существования: зарегистрированные записи и файловая система.
- Проверка синтаксиса: файлы JSON.
- Перекрестная ссылка: записи БД и файлы.
- Создание отчетов о состоянии здоровья
- Уведомление о проблемах

Использование:
  python Registration_watcher.py check # Проверить все реестры
  python Registry_watcher.py report # Создать отчет о работоспособности
  инструменты python Registry_watcher.py # Проверить только инструменты
  python Registry_watcher.py навыки # Проверка только навыков
  агенты python Registry_watcher.py # Проверять только агенты
  python Registration_watcher.py --fix # Автоматическое (безопасное) устранение проблем

ИСПОЛЬЗОВАНИЕ
----------------------------------------
инструменты Python bach.py запускают Registry_watcher [args]
или напрямую: инструменты python/registry_watcher.py [args]
