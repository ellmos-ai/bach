ОПИСАНИЕ
----------------------------------------
c_emoji_scanner.py — сканер Emoji с интеграцией пакетов Gemoji/emoji

Сканирует файлы на наличие смайлов и показывает, какие из них можно разрешить автоматически.
Использует тот же бэкэнд, что и c_json_repair.py (пакет emoji или резервный вариант gemoji.json).

Использование:
    python c_emoji_scanner.py <файл_или_папка>
    python c_emoji_scanner.py --scan-batch # Все файлы _BATCH JSON
    python c_emoji_scanner.py --status # Статус системы

Автор: Клод
Версия: 3.0 — унифицирована с инструментами c_json_repair.py

----------------------------------------
