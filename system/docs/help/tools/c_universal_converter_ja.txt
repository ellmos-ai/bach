Universal Data Converter
------------------------
JSON、YAML、TOML、XML、TOON 形式の間で変換します。

使用法:
  GUI: Python c_universal_converter.py
  CLI: python c_universal_converter.py file1.json file2.yaml --to yaml

サポートされる形式:
  - JSON (.json)
  - YAML (.yaml、.yml)
  - TOML (.toml)
  - XML (.xml)
  - TOON (.toon) - トークン指向オブジェクト表記法 (仕様準拠)

依存関係:
  pip install pyyaml toml xmltodict tkinterdnd2

TOON 仕様: https://github.com/toon-format/toon
