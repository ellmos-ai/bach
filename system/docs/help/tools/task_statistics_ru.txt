Инструмент BACH: Task_statistics
--------------------------------------------------
Создано: 23 января 2026 г., 10:36.
Источник: инструменты/task_statistics.py

ОПИСАНИЕ
----------------------------------------
task_statistics.py — оценка статистики для _done.json

Анализирует выполненные задачи и предоставляет:
- Задачи в неделю
- Распределение усилий
- Сеансов в день
- Инструментальная активность

Версия: 1.0
Создано: 10 января 2026 г.

ИСПОЛЬЗОВАТЬ
----------------------------------------
инструменты Python bach.py запускают Task_statistics [args]
или напрямую: python Tools/task_statistics.py [args]

ПРИМЕЧАНИЯ
----------------------------------------
- Автоматически генерируется из строки документации.
- Если у вас есть вопросы: инструменты bach показывают Task_statistics.
