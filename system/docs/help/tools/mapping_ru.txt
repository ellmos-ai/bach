ИНСТРУМЕНТЫ КАРТИРОВАНИЯ — Сравнение функций между системами
---------------------------------------------------

По состоянию на 23 января 2026 г.
Путь: docs/help/tools/mapping.txt

ОПИСАНИЕ
------------
Инструменты сопоставления объектов для сравнения и анализа
функций в разных системах.
Часть проекта BACH_STREAM.

Путь: инструменты/маппинг/

ФАЙЛЫ
-------
  query_features.py Запрос и сравнение функций
  populate_features.py Заполнить базу данных функциями
  схема.sql Схема базы данных

БАЗА ДАННЫХ
---------
Расположение: BACH_STREAM/MAPPING/feature_mapping.db

Таблицы:
  системы Зарегистрированные системы (CHIAH, BATCH, recludOS и т. д.)
  Определения функций
  Feature_categories Категоризация (Память, графический интерфейс, задачи и т. д.)
  реализации Какая система имеет какую функцию

ОСНОВНЫЕ ФУНКЦИИ
---------------

feature_matrix(category=None):
  Показывает, какая система имеет какую функцию.

  матрица python query_features.py
  python query_features.py матрица --категория «Память»

  Символы:
    + = реализовано (завершено)
    ~ = частичный
    ?  = запланировано/неизвестно
    - = отсутствует

синопсис_функции(имя_функции):
  Сравнивает одну функцию во всех системах.
  Показывает пути, технологии, примечания.

  python query_features.py краткий обзор «Рабочая память»

ИСПОЛЬЗОВАНИЕ
----------

Создать матрицу функций:
  инструменты Python/mapping/query_features.py матрица

Отфильтровано по категории:
  инструменты Python/mapping/query_features.py матрица --category «GUI»

Описание функции:
  python Tools/mapping/query_features.py синопсис «Инжекторы»

Введите новые функции:
  python Tools/mapping/populate_features.py
