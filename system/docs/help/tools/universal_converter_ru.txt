ОПИСАНИЕ
----------------------------------------
Универсальный конвертер данных
------------------------
Преобразует между форматами JSON, YAML, TOML, XML и TOON.

Использование:
  Графический интерфейс: python universal_converter.py
  CLI: python universal_converter.py file1.json file2.yaml --to yaml

Поддерживаемые форматы:
  - JSON (.json)
  - YAML (.yaml, .yml)
  - ТОМЛ (.toml)
  - XML (.xml)
  - TOON (.toon) — нотация объектов, ориентированная на токены (соответствует спецификациям)

Зависимости:
  pip install pyyaml toml xmltodict tkinterdnd2

Спецификация TOON: https://github.com/toon-format/toon

Автор: Клод для системы _BATCH
Версия: 2.0.0
Дата: 06.01.2026

ИСПОЛЬЗОВАНИЕ
----------------------------------------

или напрямую: python Tools/universal_converter.py [args]
