説明
----------------------------------------
c_youtube_extractor.py - URL から YouTube 動画 ID を抽出します

サポートされている形式:
  - https://www.youtube.com/watch?v=VIDEO_ID
  - https://youtu.be/VIDEO_ID
  - https://www.youtube.com/shorts/VIDEO_ID
  - https://www.youtube.com/embed/VIDEO_ID
  - ダイレクト ビデオ ID (11 文字)

抽出元: TOOLS/MEDIA/ForYou-Playlist/YouTubePlaylist.py

使用法:
    python c_youtube_extractor.py <url>
    python c_youtube_extractor.py <url1> <url2> <url3>
    python c_youtube_extractor.py --file urls.txt
    python c_youtube_extractor.py --json <url>
    エコー「https://youtu.be/dQw4w9WgXcQ」 | python c_youtube_extractor.py --stdin
