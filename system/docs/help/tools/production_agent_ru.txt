ОПИСАНИЕ
----------------------------------------
Production Agent v1.0.0

Производство контента: музыка, подкасты, видео, тексты, рассказы, PR.
Интегрирует внешние инструменты искусственного интеллекта и сервисы RecludOS.

Использование:
  список python Production_agent.py
  python Production_agent.py music --prompt «Инструментальный джаз»
  python Production_agent.py video --prompt «Океанские волны»
  python Production_agent.py рекомендует <категория>

USE
----------------------------------------
инструменты Python bach.py запускают Production_agent [args]
или напрямую: python Tools/production_agent.py [args]
