json_fixer.py - 修复 JSON 文件
---------------------------------------

修复损坏的 JSON 文件：
- 删除物料清单
- 尾随逗号
- 个人赔率
- 未转义的字符串

用法：
    python json_fixer.py <file> # 单个文件
    python json_fixer.py <folder> # 文件夹中的所有 JSON
    python json_fixer.py <path> --dry-run # 仅检查
    python json_fixer.py <path> --backup # 带备份
