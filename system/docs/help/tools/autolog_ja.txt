BACH ツール: 自動ログ
--------------------------------------------------
生成: 2026-01-23 10:36

説明
----------------------------------------
自動ロガー - すべてのアクションを自動的に記録します
-----------------------------------------------------

2 段階システム:
1. auto_log.txt - 最後の 300 行 (短期記憶)
2. auto_log_extended.txt - 古いエントリ、最大 30 日 (アーカイブ)

30 日を過ぎると、エントリは完全に削除されます。

使用
----------------------------------------
python bach.py tools run autolog [args]
または直接: python tools/autolog.py [args]
