Инструмент BACH: dirscan
--------------------------------------------------
Создано: 23 января 2026 г., 10:36.
Источник: инструменты/dirscan.py

ОПИСАНИЕ
----------------------------------------
Сканер каталогов – автоматическое управление ФАКТИЧЕСКИМ/ЦЕЛЕВЫМ состоянием
------------------------------------------------------------

- Запуск: захват фактического состояния
- Выключение: изменения = новое состояние ЦЕЛИ.
- Эвристика: требуются изменения Клода

ИСПОЛЬЗОВАНИЕ
----------------------------------------
инструменты Python bach.py запускают dirscan [args]
или напрямую: python Tools/dirscan.py [args]

ПРИМЕЧАНИЯ
----------------------------------------
- Автоматически генерируется из Docstring
- Если у вас есть вопросы: инструменты Баха показывают dirscan.
