ОПИСАНИЕ
----------------------------------------
Регистрация навыков в bach.db
------------------------------
Сканирует папку с навыками/ и регистрирует все файлы навыков в базе данных.

ИСПОЛЬЗОВАНИЕ
----------------------------------------
Инструменты Python bach.py запускают Register_skills [args]
или напрямую: python Tools/register_skills.py [args]
