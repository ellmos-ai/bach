ОПИСАНИЕ
----------------------------------------
Система инжекторов — автоматическая помощь и контекст
------------------------------------------------

Инжекторы, снимающие когнитивную нагрузку Клода:
- StrategyInjector: полезные мысли о словах-триггерах
- ContextInjector: автоматический контекст для ключевых слов.
- TimeInjector: регулярное обновление времени.
- BetweenInjector: автоматические напоминания после выполнения задачи

USE
----------------------------------------
инструменты Python bach.py запускают инжекторы [args]
или напрямую: python Tools/injectors.py [args]

----------------------------------------
