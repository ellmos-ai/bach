emoji_scanner.py - Gemoji/emoji パッケージを統合した絵文字スキャナ

ファイルの絵文字をスキャンし、どの絵文字が自動的に解決できるかを示します。
json_repair.py と同じバックエンドを使用します (絵文字パッケージまたは gemoji.json フォールバック)。

使用法:
    python emoji_scanner.py <ファイルまたはフォルダー>
    python emoji_scanner.py --scan-batch # すべての _BATCH JSON ファイル
    python emoji_scanner.py --status # システム ステータス
