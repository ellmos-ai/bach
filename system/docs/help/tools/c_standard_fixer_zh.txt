c_standard_fixer.py - 常见代码问题的工具链

依次运行多个修复程序：
  1. BOM修复（删除/更正字节顺序标记）
  2.编码修复（确保UTF-8）
  3. Umlaut Fix（修复损坏的德语变音）
  4. 缩进检查（识别缩进问题）

用法：
    python c_standard_fixer.py <文件.py>
    python c_standard_fixer.py <file.py> --dry-run
    python c_standard_fixer.py <文件夹> --recursive
    python c_standard_fixer.py <file.py> --only bom,umlaut
    python c_standard_fixer.py --list-tools

配置：
    活动工具可以在 STANDARD_FIXER_CONFIG 中自定义。
