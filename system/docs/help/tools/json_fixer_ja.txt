json_fixer.py - JSON ファイルを修復
---------------------------------------

壊れた JSON ファイルを修復します:
- BOM の削除
- 末尾のカンマ
- 個人のオッズ
- エスケープされていない文字列

使用法:
    python json_fixer.py <file> # 単一ファイル
    python json_fixer.py <folder> # フォルダー内のすべての JSON
    python json_fixer.py <パス> --dry-run # チェックのみ
    python json_fixer.py <パス> --backup # バックアップあり

作成者: BACH v1.1
