ОПИСАНИЕ
----------------------------------------
c_umlaut_fixer.py — восстанавливает неработающие немецкие умлауты в файлах Python

Исправляет типичные проблемы кодирования, такие как:
  - Удалить -> Удалить
  - открыть -> открыть
  - about -> about

Извлечено из: A1 ProFiler/_Wartung/fix_profiler_complete.py

Использование:
    python c_umlaut_fixer.py <file.py>
    python c_umlaut_fixer.py <file.py> --dry-run
    python c_umlaut_fixer.py <file.py> --json

Автор: Клод (адаптировано)
Зависимости: нет (только stdlib)

USE
----------------------------------------
инструменты Python bach.py запускают c_umlaut_fixer [args]
или напрямую: python Tools/c_umlaut_fixer.py [args]
