ОПИСАНИЕ
----------------------------------------
OLLAMA WORKER — асинхронная обработка заданий
--------------------------------------
Запускается в фоновом режиме, обрабатывает ожидающие задания/через Ollama,
записывает результаты после завершения/.

Использование:
  python ollama_worker.py # Обработка всех ожидающих заданий один раз
  python ollama_worker.py --daemon # Работать постоянно

USE
----------------------------------------
инструменты Python bach.py запускают ollama_worker [args]
или напрямую: python Tools/ollama_worker.py [args]

----------------------------------------
