ИНСТРУМЕНТЫ КОНВЕРСИИ - Инструменты конвертации
-------------------------------------------

ОБЗОР
Инструменты преобразования в BACH конвертируют форматы файлов
и восстанавливать/стандартизировать файлы.

УНИВЕРСАЛЬНЫЙ КОНВЕРТЕР
-------------------
c_universal_converter.py

Универсальный инструмент преобразования для многих форматов.
Поддерживает:
  - Текст -> PDF
  - Уценка -> PDF/HTML
  - JSON -> CSV
  - Excel -> CSV
  - Изображения (изменение размера, формат)

Вызов: python Tools/c_universal_converter.py <input> <output>

MARKDOWN -> PDF
---------------
c_md_to_pdf.py

Преобразует файлы Markdown в PDF со стилем.
Особенности:
  - Подсветка кода
  - Столы
  - Встраивание изображений

Вызов: python Tools/c_md_to_pdf.py <md file> [--output <pdf>]

КОДИРОВАНИЕ И ТЕКСТ
---------------

c_encoding_fixer.py
  Исправляет проблемы с кодировкой (UTF-8, Latin-1 и т. д.)
  Автоматически обнаруживает неправильное кодирование.
  Вызов: инструменты Python/c_encoding_fixer.py <файл>

c_umlaut_fixer.py
  Исправляет немецкие умлауты в файлах.
  Заменяет неработающие символы (ae->ä, ue->ü и т. д.)
  Вызов: инструменты Python/c_umlaut_fixer.py <файл>

c_standard_fixer.py
  Стандартизирует форматирование кода.
  Удаляет конечные пробелы, объединяет окончания строк.
  Вызов: инструменты Python/c_standard_fixer.py <файл>

JSON ИНСТРУМЕНТЫ
----------

c_json_repair.py
  Восстанавливает поврежденные файлы JSON.
  Исправляет пропущенные запятые, кавычки, скобки.
  Вызов: инструменты Python/c_json_repair.py <файл>

json_fixer.py
  Альтернативное восстановление JSON с расширенными параметрами.
  Вызов: инструменты python/json_fixer.py <файл>

ИНСТРУМЕНТЫ КОДА
----------

c_import_organizer.py
  Сортирует и организует импорт Python.
  Сгруппированы: Стандартные, Сторонние, Локальные.
  Вызов: инструменты Python/c_import_organizer.py <файл>

c_indent_checker.py
  Проверяет и исправляет отступы.
  Опции: --tabs, --spaces N
  Вызов: инструменты Python/c_indent_checker.py <файл>

ЭКСПОРТ
------

export_txt.py
  Экспортирует файлы в виде обычного текста.
  Вызов: инструменты Python/export_txt.py <файл>

exporter.py
  Генеральный экспортер различных форматов.
  Вызов: python Tools/exporter.py <file> --format <fmt>

ПАТОЧНЫЕ ОПЕРАЦИИ
-----------------

batch_file_ops.py
  Выполняет файловые операции с несколькими файлами.
  Операции: переименовывать, копировать, перемещать, конвертировать.
  Вызов: python Tools/batch_file_ops.py <операция> <шаблон>
