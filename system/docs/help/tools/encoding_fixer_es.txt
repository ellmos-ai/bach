DESCRIPCIÓN

encoding_fixer.py - Solucionar problemas de codificación en archivos de texto

Propósito: Corrige errores de codificación (Mojibake, decodificación UTF-8 incorrecta, etc.)
       con la biblioteca ftfy. Crea copias de seguridad automáticamente.

Autor: Claude (adaptado de EncodingFixxer.py)
Dependencias: ftfy (pip install ftfy), os, json (stdlib)

Uso:
    python encoding_fixer.py <archivo_o_carpeta> [--no-backup] [--recursive] [--json]

Ejemplos:
    python encoding_fixer.py script.py # Archivo único
    python encoding_fixer.py ./src --recursive # Carpeta completa
    python encoding_fixer.py file.py --no-backup # Sin copia de seguridad
    python encoding_fixer.py file.py --json # salida JSON
