DESCRIPCIÓN
----------------------------------------
standard_fixer.py - Cadena de herramientas para problemas de código comunes

Ejecuta varios reparadores uno tras otro:
  1. Corrección de BOM (marca de orden de bytes eliminada/corregida)
  2. Corrección de codificación (asegúrese de que UTF-8)
  3. Umlaut Fix (reparar diéresis alemanas rotas)
  4. Verificación de sangría (identificar problemas de sangría)

Uso:
    python standard_fixer.py <archivo.py>
    python standard_fixer.py <archivo.py> --ejecución en seco
    python standard_fixer.py <carpeta> --recursivo
    python standard_fixer.py <archivo.py> --solo bom, diéresis
    python standard_fixer.py --list-tools

Configuración:
    Las herramientas activas se pueden personalizar en STANDARD_FIXER_CONFIG.
