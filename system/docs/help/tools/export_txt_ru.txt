Инструмент BACH: Export_txt
--------------------------------------------------
Создано: 23 января 2026 г., 10:36.
Источник: инструменты/export_txt.py

ОПИСАНИЕ
----------------------------------------
Экспорт налоговых статей в файлы TXT — все списки + каталог документов

ИСПОЛЬЗОВАНИЕ
----------------------------------------
Инструменты Python bach.py запускают экспорт_txt [args]
или напрямую: python Tools/export_txt.py [args]

ПРИМЕЧАНИЯ
----------------------------------------
- Автоматически генерируется из Docstring
- Если у вас есть вопросы: инструменты bach показывают экспорт_txt.
