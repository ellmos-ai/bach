ОПИСАНИЕ
----------------------------------------
json_fixer.py - Восстановление файлов JSON
---------------------------------------

Восстанавливает поврежденные файлы JSON:
- Удалить спецификацию
- Завершающие запятые
- Индивидуальные шансы
- Неэкранированные строки

Использование:
    python json_fixer.py <файл> # Один файл
    python json_fixer.py <папка> # Весь JSON в папке
    python json_fixer.py <путь> --dry-run # Только проверка
    python json_fixer.py <path> --backup # С резервной копией

Автор: BACH v1.1

USE
----------------------------------------
инструменты python bach.py запускают json_fixer [args]
или напрямую: python Tools/json_fixer.py [args]
