ОПИСАНИЕ
----------------------------------------
standard_fixer.py — набор инструментов для решения распространенных проблем с кодом

Запускает несколько исправлений один за другим:
  1. Исправление спецификации (удален/исправлен знак порядка байтов)
  2. Исправлена кодировка (обеспечьте UTF-8).
  3. Umlaut Fix (восстановление сломанных немецких умлаутов)
  4. Проверка отступов (выявление проблем с отступами)

Использование:
    python standard_fixer.py <file.py>
    python standard_fixer.py <file.py> --dry-run
    python standard_fixer.py <папка> --recursive
    python standard_fixer.py <file.py> --only bom,умлаут
    python standard_fixer.py --list-tools

Конфигурация:
    Активные инструменты можно настроить в STANDARD_FIXER_CONFIG.

Автор: Клод
Версия: 1.0

USE
----------------------------------------
инструменты Python bach.py запускают standard_fixer [args]
или напрямую: python Tools/standard_fixer.py [args]
