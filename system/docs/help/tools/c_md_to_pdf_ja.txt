Markdown to PDF Converter - BACH System
--------------------------------------------------

Markdown ファイルをプロフェッショナルな PDF に変換します。
BACH システムのユーザー レポートおよびドキュメント用の標準ツール。

使用法:
    # ワークスペース内のすべての .md ファイル
    Python c_md_to_pdf.py

    # 特定のファイル
    python c_md_to_pdf.py レポート.md

    # カスタム出力あり
    python c_md_to_pdf.py report.md --outputcustom.pdf

    # ワークスペースのみに保存
    python c_md_to_pdf.py report.md --workspace-only

バージョン: 1.0.0
日付: 2026-02-04
特徴:
  - 普遍的に適用可能 (すべての .md または特定のファイル)
  - Markdown 解析の改善 (ヘッダー、リスト、コード ブロック、太字/斜体)
  - コマンドライン引数 (--output、--workspace-only)
  - ディレクトリの自動作成
  - ReportLab を使用したプロフェッショナルな PDF レイアウト
  - チェックボックス ([ ] および [x]) をサポート

使用
----------------------------------------
直接実行:
    python tools/c_md_to_pdf.py [args]

または BACH ディレクトリから:
    python system/tools/c_md_to_pdf.py [args]

引数
----------------------------------------
  files 変換するマークダウン ファイル (デフォルト: ワークスペース内のすべての *.md)
  -o、--output カスタム出力パス (ファイルのみ)
  --workspace-only ワークスペースのみに保存

依存関係
----------------------------------------
  - reportlab (pip install reportlab)

注意事項
----------------------------------------
- 質問がある場合: bach tools show c_md_to_pdf
- 出力ディレクトリは自動的に作成されます
