file_cleaner.py - Limpia archivos por edad/patrón
------------------------------------------------------

Busca y elimina archivos antiguos o archivos por patrón.
Útil para copias de seguridad de carpetas, registros y archivos temporales.

Uso:
    python file_cleaner.py <carpeta> --age 30 # Más de 30 días
    python file_cleaner.py <carpeta> --pattern "*.log" # Por patrón
    python file_cleaner.py <carpeta> --keep 5 # Mantener 5 más nuevos
    python file_cleaner.py <carpeta> --ejecutar # en realidad eliminar
