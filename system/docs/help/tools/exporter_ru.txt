ОПИСАНИЕ
----------------------------------------
exporter.py
-----------
Инструмент экспорта навыков, агентов и ОС.

Версия: 1.0.0
Создано: 14 января 2026 г.

КОНЦЕПЦИЯ:
  В ОС навыки/агенты являются легковесными (используют инфраструктуру ОС).
  Для внешнего использования они должны быть «упакованы» в собственную инфраструктуру.

КОМАНДЫ:
  навык Экспортирует навык из ОС как отдельный
  агент Экспортирует агента с его навыками.
  os-fresh Создает новый пакет ОС (без пользовательских данных)
  os-reset Сбрасывает ОС (удаляет пользовательские данные)

Использование:
    python Exporter.py навык <имя> --from-os <путь-os> [--output <zip>]
    агент python Exporter.py <имя> --from-os <путь-os> [--output <zip>]
    python Exporter.py os-fresh <os-path> [--output <zip>] [--version <v>]
    python Exporter.py os-reset <путь-os> [--backup] [--confirm]

Примеры:
    исследование навыков python Exporter.py --from-os ./my-os
    помощник по записи агента python Exporter.py --from-os ./my-os
    python Exporter.py os-fresh ./my-os --output os-v1.0.zip
    python Exporter.py os-reset ./my-os --backup

USE
----------------------------------------
инструменты python bach.py запускают экспортер [args]
или напрямую: python Tools/exporter.py [args]
