ОПИСАНИЕ
----------------------------------------
Инструмент диагностики импорта для проектов Python
-----------------------------------------
Систематический анализ проблем импорта и нарушений доступа.

Выполняет следующие тесты:
1. Импортируйте отдельные модули изолированно.
2. Порядок импорта варьируется
3. Обнаружение циклического импорта
4. Анализ __init__.py
5. Тесты времени с задержками
6. Найдите точку сбоя.

Использование:
    python c_import_diagnose.py <project_src_path> [--json] [--modules модуль1:Класс1,модуль2:Класс2]

Пример:
    python c_import_diagnose.py C:\MyProject\src --json
    python c_import_diagnose.py. --modules core.app:App,gui.main:MainWindow

USE
----------------------------------------
инструменты Python bach.py запускают c_import_diagnose [args]
или напрямую: python Tools/c_import_diagnose.py [args]
