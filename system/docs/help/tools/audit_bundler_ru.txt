ОПИСАНИЕ
----------------------------------------
BACH Audit Bundler v1.0
-----------------------
Создает пакеты аудита для внешних проверок.

Два пакета:
1. Пакет CONCEPT (первый): документация, концепции, идеи.
2. Пакет РЕАЛИЗАЦИЯ (позже): Код, схемы БД, скрипты

Использование:
    python audit_bundler.py --concept # Bundle 1: Концепции
    python audit_bundler.py --implementation # Bundle 2: Код
    python audit_bundler.py --all # Оба пакета
    python audit_bundler.py --help # Help

USE
----------------------------------------
инструменты python bach.py запускают audit_bundler [args]
или напрямую: python Tools/audit_bundler.py [args]

----------------------------------------

- Если у вас есть вопросы: инструменты bach показывают audit_bundler.
