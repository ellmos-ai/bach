BACH Tool: RAG (Retrieval-Augmented Generation)
================================================

Vektorbasierte Dokumentensuche für BACH.

VERWENDUNG
----------

  bach --tools rag ingest <pfad>     Dokumente indexieren
  bach --tools rag search <query>    Semantische Suche

INGEST
------

Liest Dokumente ein und erstellt Vektoren:
  - Unterstützte Formate: .txt, .md, .pdf, .py
  - Speicherung in document_vectors Tabelle

SEARCH
------

Semantische Ähnlichkeitssuche über indexierte Dokumente.
Gibt relevante Textabschnitte mit Score zurück.

MODUL
-----

  tools/rag/ (ingest.py, search.py)
  DB-Tabelle: document_vectors (Migration 020)
