pycutter.py - Python-Klassen-Extractor

Zweck: Zerlegt Python-Dateien in separate Textdateien für jede Klasse,
       plus eine Hilfsfunktionen.txt für Imports, Funktionen und globalen Code.
       Ideal für Code-Review, Dokumentation oder LLM-Kontextmanagement.

Autor: Claude (adaptiert von pyCuttertxt.py)
Abhängigkeiten: ast, os, datetime (stdlib)

Usage:
    python pycutter.py <python_file> [--output-dir <dir>] [--json]
    
Beispiele:
    python pycutter.py main.py                    # Ausgabe im aktuellen Verzeichnis
    python pycutter.py main.py --output-dir ./out # Ausgabe in ./out
    python pycutter.py main.py --json             # JSON-Output für Weiterverarbeitung
