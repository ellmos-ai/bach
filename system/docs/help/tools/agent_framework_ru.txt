ОПИСАНИЕ
----------------------------------------
Agent Framework v1.0.0

Центральная платформа для агентов RecludOS.
Подключает агентов к сервисам, внешним инструментам и соединениям.

Особенности:
- Загрузчик агентов и управление реестром
- Интеграция сервисов (расписание, медиа, почта и т.д.)
- Рекомендации по внешним инструментам искусственного интеллекта
- Управление соединениями (MCP, API, CLI)

Использование:
  python Agent_framework.py list # Все агенты
  python Agent_framework.py info <агент> # Сведения об агенте
  python Agent_framework.py инструменты <агент> # Рекомендуемые инструменты
  python Agent_framework.py Services <агент> # Связанные сервисы
  python Agent_framework.py active <agent> # активировать агент

USE
----------------------------------------
инструменты Python bach.py запускают агент_framework [args]
или напрямую: python Tools/agent_framework.py [args]
