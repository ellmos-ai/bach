Управление подпиской (управление подпиской)
---------------------------------------

ОПИСАНИЕ
Обнаруживает регулярные платежи (подписки) по статьям налога,
управляет подтверждениями и создает обзоры затрат.

КОМАНДЫ
-------
bach abo scan              Анализ налоговых статей, распознавание подписок
bach abo list              Показать все распознанные подписки
bach abo confirm ID        Подтвердить распознавание подписки
bach abo dismiss ID        Удалить обнаружение ошибок
bach abo costs             Ежемесячный отчет о расходах
bach abo export            Экспорт для планирования бюджета
bach abo patterns          Показать известные шаблоны подписок
bach abo init              Инициализировать таблицы базы данных
bach abo sync-mail         Синхронизировать подписки по электронной почте

ОБНАРУЖЕНИЕ
---------
Анализируемый налог_posten и идентифицирует подписки на основе:
  - Повторные платежи одному и тому же провайдеру
  - Постоянные суммы (небольшое отклонение)
  - Известные шаблоны поставщиков подписок (поддерживается БД)

Порог оценки: 50 баллов (настраиваемый)

ОПЦИИ
--------
  --year YYYY фильтровать налоговый год (по умолчанию: текущий год)
  --dry-run Только предварительный просмотр, ничего не сохранять

ПРИМЕРЫ
---------
  bach abo scan
  bach abo scan --jahr 2025 --dry-run
  bach abo list
  bach abo costs
  bach abo confirm 42
  bach abo export
