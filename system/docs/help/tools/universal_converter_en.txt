Universal Data Converter
------------------------
Converts between JSON, YAML, TOML, XML and TOON formats.

Usage:
  GUI: python universal_converter.py
  CLI: python universal_converter.py file1.json file2.yaml --to yaml

Supported formats:
  - JSON (.json)
  - YAML (.yaml, .yml)
  - TOML (.toml)
  - XML (.xml)
  - TOON (.toon) - Token-Oriented Object Notation (Spec Compliant)

Dependencies:
  pip install pyyaml toml xmltodict tkinterdnd2

TOON specification: https://github.com/toon-format/toon
