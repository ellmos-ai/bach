Инструмент BACH: Миграция
--------------------

Миграция баз данных и структур для BACH.

ДОСТУПНЫЕ ИНСТРУМЕНТЫ
-----------------

  Миграция_skills_hierarchy Перенести иерархию навыков в новый формат

ПАПКА МИГРАЦИИ
-----------------

Миграции SQL находятся в data/schema/migrations/:
  001-035 Нумерованные миграции (хронологические)
  doc_* Миграции, специфичные для документа
  fin_* Финансовая миграция
  налог_* Налоговая миграция

ИСПОЛЬЗОВАТЬ
----------

  bach upgrade                  Запустить все ожидающие миграции
  bach --tools migration skills Skills-Hierarchie migrieren

МОДУЛЬ
-----

  инструменты/миграция/ (1 инструмент)
  данные/схема/миграции/ (более 35 миграций SQL/Python)
