BACH 工具：RAG（检索增强生成）
------------------------------------------------

BACH 基于向量的文档搜索。

使用
----------

  bach --tools rag ingest <pfad>     索引文档
  bach --tools rag search <query>    语义搜索

INGEST
------

读取文档并创建向量：
  - 支持的格式：.txt、.md、.pdf、.py
  - 存储在 document_vectors 表中

搜索
------

通过索引文档进行语义相似性搜索。
返回带有分数的相关文本部分。

模块
-----

  工具/抹布/（摄取.py，搜索.py）
  数据库表：document_vectors（迁移020）
