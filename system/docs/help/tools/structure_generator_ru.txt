ОПИСАНИЕ
----------------------------------------
structure_generator.py
----------------------
Генерирует структуры навыков и агентов по спектру.

Версия: 1.0.0
Создано: 14 января 2026 г.
Комбинировано:kill_generator_v3.py + Agent_generator_v1.py

КОНЦЕПЦИЯ:
  Навык и агент — это спектр, а не жесткие категории.
  От простейших частичных возможностей до полного оркестратора.

ПРОФИЛИ (по возрастанию):
  MICRO = Только файл(ы), без системы папок (возможность абсолютного совместного использования)
  LIGHT = Минимальная структура (SKILL.md + _config + _data)
  СТАНДАРТ = Навык с простой памятью
  РАСШИРЕННЫЙ = Навык с микронавыками
  АГЕНТ = Организует навыки в рабочих процессах
  AGENT_FULL = Полный агент (ближе к ОС)

MODI:
  --embedded = Для использования в ОС (облегченный)
  --standalone = Для внешнего использования (полная версия, по умолчанию)

Использование:
    python Structure_generator.py <имя> <профиль> [папка назначения] [--embedded|--standalone]

Примеры:
    python Structure_generator.py анализ МИКРО
    поиск python Structure_generator.py СТАНДАРТНЫЙ
    python Structure_generator.py помощник по записи АГЕНТ
    менеджер проекта python Structure_generator.py AGENT_FULL

Для ОС → os_generator.py
Для экспорта → Exporter.py

USE
----------------------------------------
инструменты Python bach.py запустите Structure_generator [args]
или напрямую: python Tools/structure_generator.py [args]
