Herramienta de diagnóstico de importación para proyectos Python
-----------------------------------------
Análisis sistemático de problemas de importación e violaciones de acceso.

Realiza las siguientes pruebas:
1. Importar módulos individuales de forma aislada
2. El orden de importación varía
3. Detección de importaciones circulares
4. Análisis __init__.py
5. Pruebas de cronometraje con retrasos
6. Localizar el punto de colisión

Uso:
    python c_import_diagnose.py <project_src_path> [--json] [--modules module1:Class1,module2:Class2]

Ejemplo:
    python c_import_diagnose.py C:\MiProyecto\src --json
    pitón c_import_diagnose.py. --modules core.app:App,gui.main:MainWindow
