BACH Tool: Converters
=====================

Datei-Konvertierung zwischen verschiedenen Formaten.

VERFÜGBARE KONVERTER
---------------------

  md_to_pdf            Markdown zu PDF (Dual-Engine: Edge Headless + ReportLab)
  universal_converter  Universeller Dateiformat-Konverter
  universal_compiler   Kompiliert Projekte (LaTeX, Markdown, etc.)
  youtube_extractor    YouTube-Transkripte und Metadaten extrahieren

VERWENDUNG
----------

  bach --tools converters md_to_pdf <input.md> [-o output.pdf]
  bach --tools converters convert <input> <format>
  bach --tools converters youtube <url>

MD_TO_PDF
---------

Konvertiert Markdown zu PDF über zwei Engines:
  1. Edge Headless (primaer) - hohe Qualität
  2. ReportLab (Fallback) - ohne Browser
