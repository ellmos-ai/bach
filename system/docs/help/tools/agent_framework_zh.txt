代理框架 v1.0.0

RecludOS 代理的中央框架。
将代理连接到服务、外部工具和连接。

功能：
- 代理加载器和注册表管理
- 服务集成（日程安排、媒体、邮件等）
- 外部AI工具推荐
- 连接管理（MCP、API、CLI）

用法：
  python agent_framework.py list # 所有代理
  python agent_framework.py info <agent> # 代理详细信息
  python agent_framework.py tools <agent> # 推荐工具
  python agent_framework.py services <agent> # 链接服务
  python agent_framework.py activate <agent> # 激活代理
