Инструмент BACH: doc_update_checker
--------------------------------------------------
Создано: 23 января 2026 г., 10:36.
Источник: инструменты/doc_update_checker.py

ОПИСАНИЕ
----------------------------------------
Проверка обновлений документации BACH v1.0.1

Автоматическое обнаружение и обновление устаревшей документации.
Перенесено из RecludOS, интегрировано с системой памяти BACH.

Особенности:
- Обнаруживает устаревшие документы (> 60 дней, неверные пути)
- Генерирует предложения по обновлению
- Создает отчеты об обновлениях
- Может автоматически выполнять простые обновления

Использование:
  python doc_update_checker.py check # Проверить
  python doc_update_checker.py report # Создать отчет
  python doc_update_checker.py автоматическое обновление # автоматическое обновление (безопасно)
  python doc_update_checker.py Schedule # Для микропрограмм

USE
----------------------------------------
инструменты Python bach.py запускают doc_update_checker [args]
или напрямую: инструменты Python/doc_update_checker.py [args]

ПРИМЕЧАНИЯ
----------------------------------------
- автоматически генерируется из строки документации.
- Если у вас есть вопросы: инструменты bach показывают doc_update_checker.
