DESCRIPCIÓN
----------------------------------------
c_json_repair.py - Sistema de reparación JSON completamente automático

Utiliza `pip install emoji` para obtener mejores resultados (varios idiomas, actual).
Recurra al gemoji.json local si el paquete emoji no está instalado.

Flujo de trabajo:
1. Emoji encontrado -> Búsqueda mediante paquete emoji o gemoji.json
2. Encontrado -> Auto-ASCII desde el nombre (por ejemplo, "llave inglesa" -> "[LLAVE]")
3. No encontrado -> Quarantaene [Q:XXXX] (muy raro)

Uso:
    python c_json_repair.py <archivo.json> # Reparar
    python c_json_repair.py <file.json> --dry-run # Verificar solo
    python c_json_repair.py --update-gemoji # Actualizar Gemoji
    python c_json_repair.py --stats # Estadísticas
