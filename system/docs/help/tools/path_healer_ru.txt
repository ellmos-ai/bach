УПРАВЛЕНИЕ ПУТЯМИ В BACH
======================

ВАЖНО: Пути управляются АВТОМАТИЧЕСКИ в BACH!
-------------------------------------------------------
bach_paths.py является "единым источником истины" для всех путей.
Все пути рассчитываются динамически — при перемещении BACH
все работает автоматически. Ручной ремонт пути
Обычно НЕ требуется.

  from bach_paths import get_path, BACH_ROOT, TOOLS_DIR
  tools = get_path("tools") # Всегда правильно, независимо от того, где находится BACH

См.: bach --help bach_paths (полная документация)


КОГДА НЕОБХОДИМО ОБНОВЛЕНИЕ ПУТЕЙ ВРУЧНУЮ?
----------------------------------------------
Только если пути указаны в ДОКУМЕНТАЦИИ и КОММЕНТАРИЯХ
(не в коде, использующем get_path()). Тема:
  - Файлы справки (.txt)
  - Статья в Вики (.txt)
  - Документация по уценке (.md)
  - Строки документации в файлах Python

Для этой цели существует средство обновления пути к документу:

  bach --maintain docs-paths             # Dry-Run (только просмотр)
  bach --maintain docs-paths --apply     # Фактически исправьте это

Инструмент: system/tools/maintenance/doc_path_updater.py


ЧТО БЫЛО СДЕЛАНО НЕПРАВИЛЬНО РАНЬШЕ?
----------------------------------
Старый "path_healer.py" (реликт RecludOS) пробовал ВСЕ файлы
для лечения, включая код Python. Это было:
1. Лишнее (bach_paths.py решает это динамически)
2. Опасно (неидемпотентные правила повредили 101 файл)
3. Никогда не интегрировался правильно (неверное имя файла в обработчике CLI)

Начиная с версии 2.1.0 инструмент ограничен обновлениями документации.
и идемпотентный (может запускаться сколь угодно часто).


СМОТРИ ТАКЖЕ
----------
- bach --help bach_paths Центральное управление путями (РЕКОМЕНДУЕТСЯ)
- bach --help path Показать и проверить пути
- bach --help dirscan Истина в каталоге (управление состоянием)
