-----------------

ZUSAMMENSPIEL
-------------

BACH unterstützt Multi-Agent-Kommunikation zwischen:
  - Claude (claude-code / claude-desktop)
  - Gemini (antigravity)
  - GPT (codex)

Nachrichten werden über CLAUDE.md / GEMINI.md / GPT.md ausgetauscht.
Sync über OneDrive/.SYNC/ (Laptop <-> Workstation).
