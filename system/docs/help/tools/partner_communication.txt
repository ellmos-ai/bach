-----------------

ZUSAMMENSPIEL
-------------

BACH unterstuetzt Multi-Agent-Kommunikation zwischen:
  - Claude (claude-code / claude-desktop)
  - Gemini (antigravity)

Nachrichten werden ueber CLAUDE.md / GEMINI.md / GPT.md ausgetauscht.
Sync ueber OneDrive/.SYNC/ (Laptop <-> Workstation).
