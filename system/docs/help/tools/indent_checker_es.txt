DESCRIPCIÓN

indent_checker.py - Comprobador de sangría de Python

Propósito: Comprueba los archivos de Python en busca de errores de sangría comunes:
       - Faltan dos puntos después de las estructuras (def, if, class, etc.)
       - retorno/rendimiento fuera de los bloques
       - Mezcla de tabulaciones y espacios

Autor: Claude (adaptado de indent_gui_checker.py)
Dependencias: os, re, json (stdlib)

Uso:
    python indent_checker.py <archivo_o_carpeta> [--recursivo] [--log] [--json]

Ejemplos:
    python indent_checker.py script.py # Archivo único
    python indent_checker.py ./src --recursive # Carpeta completa
    python indent_checker.py ./src --log # Crear archivo de registro
    python indent_checker.py script.py --json # salida JSON
