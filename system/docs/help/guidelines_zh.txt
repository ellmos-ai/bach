指南 - 文档标准
=====================================

状态：2026-02-08

三级系统
-------------------
1。操作（文档/帮助/*.txt）
   - 我如何使用巴赫？
   - 焦点：CLI 命令、指南、参考。
   - 格式：TXT（ASCII 兼容，最多 250 行）。

2。知识 (wiki/*.txt)
   - X 是什么？
   - 重点：背景知识、领域知识、AI理论。
   - 格式：TXT（ASCII 兼容）。

3。概念（技能/**/*.md，文档/*.md）
   - 为什么以及如何建造它？
   - 重点：架构、工作流程、更深入的分析。
   - 格式：MarkDown（插图丰富/结构化）。

元数据强制（2026-01 新）
-------------------------------
每个文档文件必须具有以下标头：

  # 便携性：通用|系统|用户
  # 最后验证：YYYY-MM-DD
  # 下一个测试：YYYY-MM-DD
  # 来源：[可选]

检查间隔：
  系统：+3个月（代码链接，经常更改）
  UNIVERSAL：+6个月（普遍有效，稳定）
  用户：+12 个月（用户特定，持久）

TX/TXT 结构（经典）
---------------------------
  大写字母标题
  =======================
  [元数据标头]

  描述
  【这个功能有什么作用】

  命令
  bach [befehl] [argumente]

  例子
  [具体用例]

  另请参阅
  [链接到其他文档/帮助/或维基/文件]

生命周期分析
---------------------
1。创建：用户/ANALYSE_Thema.md
2. 评估：调查结果 → docs/help/ OR wiki/。任务→任务系统。
3. 归档：完成后移至 user/_archive/。

命名约定
------------------
docs/help/<topic>.txt 简单主题
docs/help/<command>.txt CLI 命令文档
wiki/<special>.txt 外部知识

SKILL_<n>.md 技能文档
CONCEPT_<n>.md 概念文档
<n>_ANALYSE.md 分析报告
<主题>_Proposal.md 建议（等待批准）

质量标准
-------------------
docs/help/*.txt 文件：
- 最大。 250行（建议150以下）
- 无 Markdown 语法（兼容 ASCII）
- 所有命令均记录在案
- 至少1个例子
- 另请参见参考
