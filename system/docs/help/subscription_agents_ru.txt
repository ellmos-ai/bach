================================================================================
subscription_agents - Версионированный предпросмотр onboarding-промпта
================================================================================

ОПИСАНИЕ
--------------------------------------------------------------------------------
Обработчик `subscription_agents` создаёт версионированный предпросмотр
onboarding-промпта на основе текущих исходников BACH (Subscription-Agents-Compose).
Для этого обработчик считывает файл запроса в формате JSON, передаёт содержимое
Composer'у (`hub/_services/subscription_agents_composer.py`) и выводит результат
в виде канонически отсортированного JSON в stdout.

Обработчик работает с файлом запроса только на чтение: он не изменяет ни файл
запроса, ни файлы конфигурации или системные файлы. Вывод подходит в качестве
основы для версионированных состояний промптов/onboarding'а и для передачи
последующим инструментам.

Обработчик предоставляет ровно одну операцию: `compose`.

Имя регистрации:     subscription_agents
Модуль:              system/hub/subscription_agents.py
Связанный сервис:    system/hub/_services/subscription_agents_composer.py
Операция(и):         compose

ОПЕРАЦИИ
--------------------------------------------------------------------------------
compose <файл-запроса-json>
    Создаёт версионированный предпросмотр onboarding-промпта из текущих
    исходников BACH.

    Аргументы:
      <файл-запроса-json>   Путь к JSON-файлу, содержащему JSON-объект.
                            Ведущий символ `~` раскрывается в домашний
                            каталог пользователя, выполняющего команду.

    Правила передачи аргументов:
      - Требуется ровно один аргумент.
      - Аргумент должен быть непустой строкой.
      - Аргумент не должен начинаться с `-` (разбор опций не производится).

    Обработка ошибок файла запроса:
      - Файл не читается (OSError/PermissionError)
        -> "Файл запроса не читается"
      - Файл больше MAX_REQUEST_BYTES (256 KB)
        -> "Файл запроса превышает 256 KB"
      - Содержимое не является допустимым UTF-8 JSON, не является JSON-объектом
        или содержит повторяющиеся имена полей
        -> "Файл запроса должен содержать допустимый UTF-8 JSON с уникальными полями"
        -> "Файл запроса должен содержать JSON-объект"

    Если операция или аргумент не приняты, обработчик возвращает следующую
    строку использования:

      bach subscription_agents compose <файл-запроса-json>

ПРИМЕРЫ
--------------------------------------------------------------------------------
1) Стандартный вызов с использованием короткого имени обработчика:

     python bach.py subscription_agents compose ./request.json

2) Вызов с использованием опциональной формы (привязка к обработчику):

     python bach.py --subscription_agents compose ./request.json

3) Файл запроса в домашнем каталоге (раскрытие тильды):

     python bach.py subscription_agents compose ~/requests/onboarding.json

4) Перенаправление вывода в файл (сортировка/ключи сохраняются):

     python bach.py subscription_agents compose ./request.json > preview.json

5) Минимальный файл запроса (JSON-объект, UTF-8, без повторяющихся полей):

     {"topic": "onboarding", "audience": "new_agent"}

ФОРМАТ ВЫВОДА
--------------------------------------------------------------------------------
- Успешный случай: ровно один JSON-объект в stdout, сериализованный с помощью
  `json.dumps(result, ensure_ascii=False, sort_keys=True)`. Ключи сортируются
  по алфавиту, не-ASCII символы остаются немаскированными (UTF-8).
- Ошибочный случай: возврат текста (сообщение об ошибке или строка использования)
  через обычный возврат обработчика; код завершения зависит от вызывающего CLI.
- Вывод не содержит завершающего перевода строки, добавленного самим обработчиком.

ФАЙЛЫ
--------------------------------------------------------------------------------
system/hub/subscription_agents.py
    Обработчик: проверка аргументов, чтение запроса, вызов Composer'а, вывод.

system/hub/_services/subscription_agents_composer.py
    Сервис Composer с `SubscriptionAgentsComposer` и константой
    `MAX_REQUEST_BYTES` (верхний предел 256 KB для файла запроса).

<файл-запроса-json>
    Входной файл, предоставляемый вызывающей стороной (JSON-объект, UTF-8,
    макс. 256 KB, без повторяющихся имён полей). Используется только для чтения.

system/docs/help/subscription_agents.txt
    Этот файл справки. Разрешается через `--help subscription_agents`
    (поиск справки использует `docs/help/<тема>.txt`; имя регистрации и
    имя модуля идентичны) и автоматически появляется в `--help list`.
