エージェントカラー
=========

ブループリントカラーは任意です。null または # で始まる 6 桁の 16 進数 (例:
#12abef) が許可されます。大文字は小文字に変換されます。その他の CSS 値は無効です。

色フィールドなしで保存した場合、従来の色が保持されます。null を指定すると削除
されます。変更には現在のブループリントバージョンが必要です。

インスタンス化 (マテリアライズ) 時、インスタンスはブループリントカラーを継承
します。明示的に設定されたインスタンスオーバーライドが優先されます。インスタンス
オーバーライドに null を指定すると再び継承します。再インスタンス化するとブルー
プリントカラーは更新されますが、インスタンスオーバーライドは保持されます。どちら
の手順もそれぞれの現在の設定バージョンが必要です。インスタンスリセットはオーバー
ライドを削除し、既存のブループリントカラーが継承されます。

保存された色がない場合、API は color=null および color_source=default を報告
します。UI はその場合デフォルトテーマを使用します。古いプロファイルの読み取り
では新しい色フィールドは保存されません。色は権限を付与せず、ワーカー、プロバイダ、
モデル呼び出しのいずれも起動しません。
