Manejador BACH: Secretos
========================

Los valores secretos se guardan exclusivamente en el llavero del sistema
operativo. `bach.db` y `bach_secrets.json` solo contienen metadatos.

USO
---

  bach secrets list
  bach secrets get <key>
  bach secrets set <key> [--desc=TEXT] [--category=CAT]
  bach secrets set <key> --stdin [--desc=TEXT] [--category=CAT]
  bach secrets delete <key>
  bach secrets sync

SEGURIDAD
---------

  - `get` nunca escribe el valor secreto en stdout.
  - Se rechazan los valores pasados como argumentos del proceso.
  - La migración se interrumpe si el llavero no puede verificarse.
