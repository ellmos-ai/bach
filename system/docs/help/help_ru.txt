ПОМОЩЬ - Справочная система BACH
=============================

ОПИСАНИЕ
Справочная система предоставляет контекстную документацию для всех компонентов BACH.
Каждая тема имеет свой собственный файл .txt в каталоге docs/help/.

КОМАНДЫ CLI
-----------
bach --help                 Показать все доступные темы
bach --help [thema]         Справка по определенной теме
bach --help tasks           Пример: справка по системе задач
bach --help steuer          Пример: справка по налоговому агенту
bach --help tools/name      Пример: справка из подпапки
bach --help tool_name       Пример: информация об инструменте из базы данных

ДОСТУПНЫЕ ТЕМЫ
------------------
Система: запуск, завершение работы, архитектура, функции
Задачи: задачи, между задачами, планирование, рабочий процесс.
Память: память, уроки, логи, источники
Агенты: агенты, актеры, общение, партнеры.
Инструменты: инструменты, обслуживание, резервное копирование, распространение.
Данные: dirscan, мусор
Графический интерфейс: графический интерфейс, обслуживание, генератор подсказок, повторяющиеся действия.
Специальное: налог, кодирование, исправление ошибок, форсунки
Внешние: поставщик, кулинарные книги.
Прочее: идентичность, наименование, практика, форматы, смайлы

СТРУКТУРА ФАЙЛА ПОМОЩИ
-------------------------
1. НАЗВАНИЕ – Имя заглавными буквами.
2. ОПИСАНИЕ. Что делает этот компонент?
3. КОМАНДЫ CLI. Какие команды существуют?
4. ДРУГИЕ РАЗДЕЛЫ: понятия, примеры, советы

СОЗДАТЬ НОВЫЙ ФАЙЛ ПОМОЩИ
-------------------------
1. Создайте файл в папке docs/help/[topic].txt.
2. Принять формат существующего файла.
3. Как минимум: заголовок, описание, команды CLI.
4. Регистрация в bach --help автоматически

ФАЙЛЫ СПРАВКИ И ДРУГИЕ ДОКУМЕНТЫ
---------------------------
docs/help/*.txt Справочник по CLI, быстрый поиск
навыки/*.md Профили агентов, сложные концепции
docs/*.md Документация разработчика, концепции
SKILL.md Основная точка входа

ЛУЧШИЕ ПРАКТИКИ
--------------
- Будьте краткими и по существу (до 100 строк)
- Всегда сначала документируйте команды CLI.
- Примеры более полезны, чем теория.
- В случае изменений: обновите файл справки

WIKI & РАСШИРЕНИЯ
--------------------
Подкаталог wiki/ содержит расширенную документацию:
wiki/*.txt

Доступ к подпапке:
  bach --help tools/python_cli_editor
  bach --help wiki/antigravity

Доступ к базе данных инструментов (НОВАЯ версия 1.1.38):
  bach --help path_healer     Информация об инструменте из bach.db
  bach --help tool_scanner    Показывает тип, путь, возможности

Псевдонимы навыков (НОВАЯ версия 1.1.85):
  bach --help agent/ati       Показывает агенты/ati/ATI.md
  bach --help workflow/bugfix Zeigt skills/workflows/bugfix-protokoll.md
  bach --help expert/steuer   Показывает агенты/_experts/steuer/TAUER.md
