BACH RESTORE - TEMPLATE RESTORE
------------------------------------------

Восстанавливает файлы TEMPLATE (dist_type=1) и файлы CORE (dist_type=2)
из манифеста распространения.


USE
----------

  # Восстановить один файл
  bach restore <datei-pfad>

  # Восстановить все файлы ШАБЛОНА
  bach restore --all

  # Восстановить файлы CORE (с предупреждением)
  bach restore --core

  # Пробный прогон (только просмотр, не выполнение)
  bach restore --dry-run <datei-pfad>


DIST_TYPE SYSTEM
----------------

  0 = USER_DATA Личные файлы, НЕ подлежат восстановлению
  1 = ШАБЛОН Настраиваемые системные шаблоны, ВОССТАНОВЛЕННЫЕ
  2 = CORE Ядро системы, восстанавливаемое (с предупреждением)


ВАЖНО
-------

- USER_DATA (dist_type=0) НИКОГДА не перезаписывается
- CORE-Restore показывает предупреждение, потому что изменения будут потеряны.
- Перед восстановлением CORE рекомендуется выполнить резервное копирование


ПРИМЕЧЫ
---------

  # Восстановить SKILL.md (ШАБЛОН)
  bach restore SKILL.md

  # Восстановить все шаблоны соединителей
  bach restore system/connectors/templates/

  # Проверьте, какие файлы будут восстановлены
  bach restore --dry-run --all


СМОТРИТЕ ТАКЖЕ
----------

  bach --help upgrade       Обновление до более новой версии BACH
  bach --help downgrade     Откат до более старой версии
  bach --help seal          Проверка целостности
