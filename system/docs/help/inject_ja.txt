ハンドラ名
============
inject -- インジェクタ制御およびタスク割り当て

説明
============
インジェクト ハンドラは、自動化されたインジェクタ システムを管理します。
コンテキストのインジェクションとタスクの割り当て。インジェクターは次のプラグインです。
特定のトリガー (単語、時間、タスクの完了) に対して自動的に実行されます。
役立つヒントやアクションを提供します。

OPERATIONS
===========
ステータス
  すべてのインジェクターのステータス (アクティブ/非アクティブ) を表示します。
  構文: --inject status

toggle <名前>
  インジェクターをオンまたはオフにします。
  構文: --inject toggle <名前>

  利用可能なインジェクター:
    戦略 トリガーワードに関する役立つ考え
    コンテキスト キーワードのコンテキストの手掛かり
    time 定期的な時刻更新 (タイムビート)
    タスク完了後の自動リマインダーの間

タスク <分>
  指定された期間の新しいタスクを割り当てます。
  構文: --inject task <分>
  デフォルト: 5 分

<id> を分解
  既存のタスクをサブ目標に分割します。
  構文: --inject decompose <タスク ID>

例
=========
# すべてのインジェクターのステータスを確認する
--inject status

# 戦略インジェクターを有効にする
--inject トグル戦略

# 15 分のタスクを割り当てます
--inject task 15

# ID 'abc123' のタスクを逆アセンブルします
--inject decompose abc123
