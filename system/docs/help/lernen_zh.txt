学习 - 记忆作为一个学习过程
================================

描述
将学习视为记忆过程的哲学观点。
源自对 BACH 智能体如何学习的分析。

核心论文
----------
“学习实际上是记忆的一种形式。”

流程
------------------
1。当前状况（现状）
   系统/知识的初始情况。

2。活动/体验（活动）
   互动、新输入、成功或失败。

3.保存（存储）
   记录原始事件数据。

4.合并（合并）
   实际学习步骤：
   - 得出见解
   - 推导规则（抽象）
   - 总结经验（压缩）

结论
-----
学习不是数据的积累，而是
将经验整合到新结构中
（规则/知识）在内存中。

BACH 中的实现
-----------------
内存系统映射此过程：

  输入-->工作记忆-->巩固-->事实/教训
                    |                                     |
                    | （会议结束）| （永久）
                    伏
              会话报告注入器/上下文
              （情景）（语义）

实际应用
--------------------
1。获得经验
   bach memory write "Beobachtung: XYZ funktioniert nicht"

2。衍生知识
   核心是什么？规则是什么？

3.另存为课程
   bach lesson add "Titel: Erkenntnis/Loesung"

4。在上下文中可用
   当上下文相关时注入课程

另请参阅
----------
bach memory status         内存系统概述
