РЕШЕНИЕ ПРОБЛЕМ - Структурированное мышление
--------------------------------------

ОПИСАНИЕ
------------
Стратегии решения проблем и анализа сложных задач.
Структурированные мыслительные процессы для сложных ситуаций.

ПОДХОДЫ К РЕШЕНИЮ ПРОБЛЕМ
------------------------

1. РАЗДЕЛЯЙ И Властвуй
   Задача -> Подзадачи -> Решить индивидуально -> Объединить

   Когда использовать: Большие, сложные проблемы, которые можно разбить на части.

2. АНАЛИЗ ПРИЧИН (5 «Почему»)
   Симптом -> Почему? -> Почему? -> Почему? -> Причина -> Решение

   Когда использовать: Когда неясно, в чем заключается реальная проблема.

3. ОГРАНИЧЕНИЕ РАССЛАБЛЕНИЕ
   Неразрешимо -> ослабить ограничения -> решить -> ужесточить ограничения

   Когда использовать: Когда требования слишком строгие.

4. ПОИСК АНАЛОГИИ
   Новая проблема -> Аналогичная известная проблема -> Адаптировать решение

   Когда использовать: Для новых задач без очевидного решения.

МЕТОДЫ АНАЛИЗА
----------------

  Применение метода
  ---------- ----------------------------------------
  SWOT сильные/слабые стороны/возможности/риски
  Принятие решений за/против
  Расстановка приоритетов по Парето 80/20 (найдите самые важные 20%)
  Анализ первопричин «рыбий кости» (диаграмма Исикавы)

ЭВРИСТИКА ПРИНЯТИЯ РЕШЕНИЙ
-------------------------

При неопределенности:
  1. Каков наихудший сценарий?
  2. Это обратимо?
  3. Какова цена бездействия?

Со сложностью:
  1. Какой самый простой первый шаг?
  2. Что бы сделал эксперт?
  3. Каким будет решение 80%?

ПРАКТИЧЕСКИЕ СОВЕТЫ
----------------
- Всегда начинайте с самого простого шага.
- Документировать мыслительные процессы для дальнейшего использования.
- Если есть засор: сделайте перерыв, переформулируйте проблему
- 80% решений часто лучше, чем 100% планов
