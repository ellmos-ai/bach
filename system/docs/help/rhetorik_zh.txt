修辞
--------
修辞运算符和模式作为应用思维策略。

核心陈述：修辞是认知策略+语言包装。


1。修辞运算符（基本构件）
------------------------------------------

1.1 强化运算符
-----------------------------
增加影响力、强度或重要性。
  - 放大 -> 让事情变得更大
  - 强调 -> 通过重复/结构强调
  - 增加（高潮）->A->B->C，各自更强
  - 超拉化 ->“最重要的一点...”

1.2 衰减算子
-----------------------------
衰减、相对化、消除。
  - Litotes ->“不错”
  - 对冲 ->“这可能是……”
  - 相对化 ->“与...相比”

1.3 结构运算符
------------------------
排序思想和直接注意力。
  - 三元组 -> 3 点结构
  - 框架 -> 设置上下文
  - 路标 ->“首先……其次……”
  - 对比 -> A 与 B

1.4 意义运算符
--------------------------
改变事物的理解方式。
  - 隐喻 -> 转移意义
  - 类比->比较结构
  - 定义 -> 设定术语
  - 重新构建 -> 重新解释含义

1.5 说服操作员
----------------------------
争取批准。
  - 徽标 -> 逻辑论证
  - 精神 -> 信誉
  - 悲伤 -> 情感
  - 参考权威->“研究显示...”

1.6 感知操作者
----------------------------
控制观众关注的内容。
  - 聚焦 -> “重要的是……”
  - 分散注意力 -> 转移话题
  - 选择性显示->仅显示相关方面

1.7 交互操作者
----------------------------
包括其他人。
  - 反问句
  - 直接方法
  - 社区框架 -> “我们都知道......”
  - 反对预期 -> “您可能想知道...”

1.8 可信度运营商
--------------------------------
增加信任。
  - 自我披露
  - 透明度
  - 承认错误
  - 显示一致性


2。修辞模式（组合）
----------------------------------------

2.1 问题-原因-解决方案模式
------------------------------------
操作符：框架、因果关系、结构
形式：提出问题 -> 解释原因 -> 提出解决方案

2.2 反对预期模式
--------------------------------
操作者：改变视角、重新构建、标识
形式：“你现在可能会想……但实际上……”

2.3 故事框架模式
------------------------
操作符：隐喻、排序、悲情
形式：情境->冲突->转折点->解决方案

2.4 三明治模式
---------------------
算子：强化、弱化
形式：正面->批评->正面

2.5对比模式
---------------------
操作者：对比、聚焦
形式：“不是X，而是Y。”

2.6 三元组模式
--------------------
操作符：结构化、强化
形式：“快速、清晰、有效。”

2.7 权威模式
------------------------
运营者：精神、标志
形式：“研究显示...专家确认...”

2.8 最小阻力模式
-------------------------------
操作者：弱化、对冲
形式：“也许有意义......”

2.9 重构模式
----------------------
运算符：意义转变
形式：“这不是问题——这是机会。”

2.10 苏格拉底模式
--------------------------
操作者：问题、观点改变
形式：“如果……会怎样？”

2.11 动量模式
----------------------
操作符：高潮、排序
形式：“首先...然后...最后...”

2.12 归约模式
-----------------------
运算符：分块、聚焦
形式：“实际上只是关于两件事......”

2.13 镜像模式
-------------------------
操作者：换位思考
形式：“我听说这对你很重要......”

2.14 简化模式
----------------------------
运算符：规范化、隐喻
形式：“想象一下，就像……”

2.15 惊喜模式
----------------------------
操作者：对比、重构
形式：“大多数人认为 X——但事实恰恰相反。”

2.16 一致性模式
------------------------
操作符：精神、重复
形式：“正如我所说...”

2.17 精确模式
-------------------------
运算符：定义、聚焦
形式：“我所说的‘效率’具体是指……”

2.18 情感触发模式
-------------------------------
操作者：悲伤、讲故事
形式：“想象一下早上起床……”

2.19 反证模式
-------------------------
操作者：测试、比较
形式：“如果这是真的，那么...”

2.20 最小参数模式
------------------------------
运算符：优先级、减少
形式：“只有一个原因说明这一点很重要......”


3。修辞技巧（精确技巧）
-------------------------------------------

冷开->直接以强硬的声明开始
钩子->3秒内注意
回调 -> 稍后返回上一点
回显->重复关键词
对比钩子 ->“坏消息...好消息...”
错误的开始 -> 故意打断以制造紧张气氛
微破->增加效果
标签 -> 命名情绪（“这似乎令人沮丧......”）
启动->设定期望
锚定->设置比较点


4.修辞与元认知
------------------------------
元认知策略作为修辞自我控制：

  自我监控 -> 控制肢体语言、语气、节奏
  错误分析->语音分析、反馈循环
  元问题 -> “我的核心信息是什么”
  策略选择 -> 精神/情感/标志平衡
  反思 -> 演讲后续
  元规划->言语结构、戏剧

修辞=不仅仅是说话，而是思考说话。


5.与技术模式相关
---------------------------------
许多运算符模式都有修辞双胞胎：

  分类流程->目标群体分析
  评分和排名 -> 论据权重
  基于规则的过滤 -> 内容的相关性过滤器
  异常检测 -> 检测矛盾
  渐进细化 -> 逐步构建论证
  人在环 -> 包括观众反应
  后备解决方案 -> 处理异议

这并非巧合：修辞是一个信息处理过程。


6。修辞学的三大支柱
---------------------------------

标志（逻辑论证）
  -> 演绎、归纳、比较、检验、反证
  -> 思维策略：假设形成、因果思维

精神（可信度）
  -> 自我监控、错误分析、一致性
  -> 元认知：反思、元问题

Pathos（情感影响）
  -> 模式识别、讲故事、类比
  -> 思维策略：换个角度、情景思维


7.巴赫的应用
--------------------

修辞运算符可以改进人工智能系统：
  - 更好的可解释性（简化模式）
  - 更好的错误消息（问题-原因-解决方案）
  - 更好的用户指导（标志张贴、结构化）
  - 更好的沟通（伙伴系统）

思维策略=内部操作员（处理）
修辞=外部操作员（沟通）
