CLOUD - Провайдеро-независимое управление облачной синхронизацией
==================================================================
Сервис Cloud-Control предотвращает блокировки файлов, конфликты синхронизации
и коллизии SQLite-WAL при операциях с интенсивной записью, резервном
копировании и массовом обслуживании.

ПОДДЕРЖИВАЕМЫЕ ПРОВАЙДЕРЫ
-------------------------
- Microsoft OneDrive (Windows / macOS / Linux)
- Google Drive (Windows / macOS)
- Apple iCloud Drive (macOS bird / CloudDocs, Windows iCloud.exe)
- Dropbox (Windows / macOS / Linux)
- Nextcloud / ownCloud (Windows / macOS / Linux)

КЛЮЧЕВЫЕ КОНЦЕПЦИИ
------------------
1. AUTO-DETECTION: Автоматически обнаруживает установленные и запущенные
   клиенты при старте.
2. ОПЕРАТИВНАЯ ЗАЩИТА: Облачная синхронизация приостанавливается только
   точечно во время задач с интенсивной записью и сразу после этого
   возобновляется (без постоянной остановки в простое).
3. FAIL-SAFE WATCHDOG: Таймер безопасности гарантированно возобновляет
   приостановленные клиенты по истечении таймаута (по умолчанию: 300s), даже
   при сбоях программы.
4. АРХИТЕКТУРА И ДИАГРАММЫ: См. docs/ARCHITECTURE_CLOUD_CONTROL.md

CLI-КОМАНДЫ (bach cloud)
------------------------
  bach cloud status                     Обзор всех обнаруженных облачных сервисов
  bach cloud status --json              Статус в формате JSON
  bach cloud pause [provider] [-t SEC]  Приостанавливает синхронизацию с таймаутом безопасности (по умолчанию: 300s)
  bach cloud resume [provider]          Возобновляет приостановленные сервисы
  bach cloud toggle [provider]          Переключает между паузой и возобновлением

PYTHON CONTEXT-MANAGER
----------------------
  from hub._services.cloud import cloud_pause

  with cloud_pause(timeout=180):
      # Файловые операции с интенсивной записью
      schreibe_daten()
  # Облачная синхронизация автоматически возобновляется в фоне
