PROMPT - Prompt-Template-Verwaltung
=====================================

STAND: 2026-08-14

Das Prompt-System verwaltet wiederverwendbare Prompt-Templates mit
Versionierung und Organisationsmöglichkeit via Boards. CLI, Library-API und
Web-GUI arbeiten auf denselben Tabellen der kanonischen BACH-Datenbank.

Ref: B42

KERNKONZEPTE
------------
- TEMPLATES: Wiederverwendbare Prompt-Texte mit Name, Kategorie, Tags
- VERSIONEN: Jede Änderung erzeugt eine neue Version (Historie)
- BOARDS: Sammlungen von Templates (thematische Gruppen)

CLI-BEFEHLE (bach prompt)
--------------------------

  list [--category CAT]           Alle Templates auflisten
  add <name> <text>               Neues Template erstellen
  get <id_oder_name>              Template + Versionshistorie anzeigen
  update <id_oder_name> <text>    Neue Version erstellen
  delete <id_oder_name>           Template löschen
  search <query>                  Templates durchsuchen
  boards                          Alle Boards anzeigen
  board <titel>                   Board anzeigen/erstellen/verwalten

OPTIONEN FÜR ADD
-----------------
  --category CAT    Kategorie (z.B. "analyse", "schreiben")
  --tags t1,t2      Tags (kommagetrennt)
  --purpose TEXT    Verwendungszweck

OPTIONEN FÜR BOARD
-------------------
  --add-prompt ID         Prompt zu Board hinzufügen
  --remove-prompt ID      Prompt aus Board entfernen
  --description TEXT      Board-Beschreibung setzen/aktualisieren

BEISPIELE
---------

  # Templates auflisten
  bach prompt list
  bach prompt list --category analyse

  # Template erstellen
  bach prompt add "Zusammenfassung" "Fasse den folgenden Text zusammen:" --category schreiben
  bach prompt add "Code-Review" "Prüfe diesen Code auf Fehler:" --tags "dev,review" --purpose "Code-Qualität"

  # Template anzeigen (mit Versionshistorie)
  bach prompt get 42
  bach prompt get "Zusammenfassung"

  # Template aktualisieren (erstellt Version)
  bach prompt update 42 "Fasse den folgenden Text praegnant zusammen:"
  bach prompt update "Zusammenfassung" "Neue Version des Textes..."

  # Template löschen
  bach prompt delete 42

  # Suchen (in Name, Text, Tags)
  bach prompt search "zusammenfass"
  bach prompt search "code"

  # Boards verwalten
  bach prompt boards                                      # Alle Boards
  bach prompt board "Schreiben"                           # Board erstellen/anzeigen
  bach prompt board "Schreiben" --add-prompt 42           # Prompt hinzufügen
  bach prompt board "Schreiben" --remove-prompt 42        # Prompt entfernen
  bach prompt board "Schreiben" --description "Schreib-Prompts für den Alltag"

LIBRARY-API
-----------

Der Handler ist auch über `bach_api.prompt` erreichbar. Die Operationen und
Argumente entsprechen der CLI:

  from bach_api import prompt

  prompt.list()
  prompt.get(42)
  prompt.search("code")
  prompt.add("Code-Review", "Prüfe diesen Code auf Fehler:",
             "--category", "analyse", "--tags", "dev,review")

WEB-GUI UND REST-API
--------------------

Die Seite `/prompt-library` (Navigation: Wissen -> Prompts) bietet Suche,
Kategorie-Filter, Anlegen, Bearbeiten, Löschen und Versionshistorie. Speichern
archiviert den vorherigen Text wie `bach prompt update`.

REST-Endpunkte:

  GET    /api/prompt-library                     Liste, optional `q`/`category`
  GET    /api/prompt-library/{id}                Eintrag + Versionshistorie
  POST   /api/prompt-library                     Eintrag anlegen
  PUT    /api/prompt-library/{id}                Text/Tags versioniert ändern
  DELETE /api/prompt-library/{id}                Eintrag inkl. Verknüpfungen löschen
  POST   /api/prompt-library/import-promptboard  PromptBoard idempotent importieren

Die alte Seite `/prompt-generator` leitet auf `/prompt-library` um. Die noch
vorhandenen `/api/prompt-generator/*`-Endpunkte gehören zum separaten
Legacy-Prompt-Generator und nicht zum DB-Handler `bach prompt`.

PROMPTBOARD-IMPORT
------------------

Die GUI importiert `library.json` per Name idempotent in `prompt_templates`:
bestehende Namen werden übersprungen. Die Quelle wird in dieser Reihenfolge
gesucht:

  1. `BACH_PROMPTBOARD_LIBRARY`
  2. `~/.promptboard/library.json`
  3. `%APPDATA%/PromptBoard/library.json`
  4. Legacy-Projektpfade unter `REL-PUB_PromptBoard`

Der System-Tray verwendet dieselbe bevorzugte PromptBoard-Speicherreihenfolge
und kann PromptBoard als App-Menüeintrag starten.

VERSIONIERUNG
-------------

Beim `update` wird der alte Text automatisch als Version gespeichert.
Versionshistorie ist bei `bach prompt get <id>` sichtbar:

  VERSIONEN (2):
    Nr    Erstellt                   Text (Vorschau)
    1     2026-01-15T10:30:00        Alter Text...
    2     2026-02-01T14:00:00        Nächste Version...

ABGRENZUNG ZU MEMORY / SHARED MEMORY
-------------------------------------
`bach prompt` verwaltet Prompt-Templates und Boards. Der Handler kennt keine
`--confidence`-Option und führt keine Shared-Memory-Konfliktauflösung durch.

Konfidenzwerte gehören zu Memory- und Shared-Memory-Befehlen, z.B.:
  bach --memory fact "key:value" --conf=0.8

DATENBANK
---------

  prompt_templates:
    id, name, purpose, text, tags, category,
    created_at, updated_at, dist_type

  prompt_versions:
    id, prompt_id, version_number, text, tags, created_at

  prompt_boards:
    id, title, description, created_at

  prompt_board_items:
    id, board_id, prompt_id, added_at
