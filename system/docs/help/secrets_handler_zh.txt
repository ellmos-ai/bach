BACH 处理器：机密
================

机密值仅存储在操作系统凭据库中。`bach.db` 和 `bach_secrets.json` 只包含元数据。

用法
----

  bach secrets list
  bach secrets get <key>
  bach secrets set <key> [--desc=TEXT] [--category=CAT]
  bach secrets set <key> --stdin [--desc=TEXT] [--category=CAT]
  bach secrets delete <key>
  bach secrets sync

安全
----

  - `get` 不会把机密值写入 stdout。
  - 作为进程参数传入的值会被拒绝。
  - 无法验证凭据库时，迁移会中止。
