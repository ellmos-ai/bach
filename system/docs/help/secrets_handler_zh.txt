BACH 处理程序：秘密
---------------------

API 密钥、令牌和访问数据的安全管理。

使用
----------

  bach --secrets list                显示所有秘密（仅密钥）
  bach --secrets get <key>           检索秘密的值
  bach --secrets set <key> <value>   设置/更新秘密
  bach --secrets delete <key>        删除秘密

选项
--------

  --category <cat> 类别（通用、api、电报等）
  --description <文本> 秘密的描述

位置
-----------

  ~/.bach/bach_secrets.json（使用 Fernet 加密）
  在system_config中配置：secrets_file_path

安全
----------

  - 秘密使用 Fernet (AES-128-CBC) 加密。
  - Salt：固定 16 个字节（不是换行符分隔！）
  - 切勿将秘密提交给 Git
  - .gitignore 中的秘密文件

MODULE
-----

  hub/secrets_handler.py (SecretsHandler)
