ОБРАБОТЧИК ГАЗЕТ
-----------------

ОПИСАНИЕ
------------

Ежедневная газета в формате PDF с новостями. Собирает предметы из разных
Источники, создает газету в формате HTML/PDF и представляет ее.
через настраиваемые каналы (Telegram, электронная почта, рабочий стол).

В зависимости от: NewsHandler (hub/news.py)
Источники данных:hub/_services/newspaper/config.json, user/newspaper/

OPERATIONS
-----------

generate [--date ГГГГ-ММ-ДД]
  Создать газету. Использует собранные новости из базы данных.
  Создает HTML и PDF в каталоге user/newspaper/.
  Стандарт на сегодня; --date устанавливает явную дату.
  Пример: газета Баха сгенерировать --date 2026-02-18

доставить [--channel телеграмма|электронная почта|рабочий стол]
  Доставить газету. Найдите последнюю газету и отправьте ее.
  Без --channel используются все настроенные каналы.
  Пример: доставка газеты Баха --channel telegram

config
  Показать конфигурацию. Читает Hub/_services/newspaper/config.json
  и отображает все параметры в структурированном виде.

история
  Перечислите предыдущие расходы. Показывает до 20 последних газет.
  с отметкой даты и размером файла в КБ.

справка
  Покажите эту справку.

ПРИМЕРЫ
---------

Создать ежедневную газету:
  bach newspaper generate

С определенной датой:
  bach newspaper generate --date 2026-02-25

Доставить газету (все каналы):
  bach newspaper deliver

Доставка только через Telegram:
  bach newspaper deliver --channel telegram

Завершить рабочий процесс:
  bach news fetch              [Собрать сообщения]
  bach newspaper generate      [Создать газету]
  bach newspaper deliver       [Отправить газету]

ФАЙЛЫ
-------

Относительные пути к системе/:

  Hub/newspaper.py реализация обработчика
  Hub/_services/newspaper/newspaper_generator Генератор газет (с отложенной загрузкой)
  Hub/_services/newspaper/config.json Конфигурация (каналы, источники)

  пользователь/газета/ Каталог вывода
  user/newspaper/newspaper_*.html Газеты, созданные в формате HTML
  user/newspaper/newspaper_*.pdf Газеты, созданные в формате PDF

  база данных data/bach.db (news_items, news_sources)

СМОТРИ ТАКЖЕ
----------

  news.py NewsHandler (исходная система для новостей)
  base.py BaseHandler (базовый класс)
  notify.py система уведомлений (доставка)
