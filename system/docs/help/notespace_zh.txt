NOTE-SPACE（BACH 自有的 NoteSpaceLLM）
==================================

bach notespace   - 用于文档分析的私有 NotebookLM 克隆（内置）


说明
==

固定随附的 BACH 模块：用于文档分析和报告生成的私有 NotebookLM 克隆。独立
的 BACH 版本，不依赖于内部源项目（Vendoring 证明：
tools/notespace/PROVENANCE.md）。

绑定：
- LLM/Embeddings：BACH 的全局 Ollama 配置（data/ollama_config.json）
- 数据（项目/向量数据库/输出）：data/notespace/（gitignored）


命令
==

bach notespace status        模块状态、Ollama 绑定、数据路径、依赖项
bach notespace gui           启动桌面 GUI（PySide6，本地系统）
bach notespace cli "问题"     无头 RAG 查询（第 2 阶段，尚未实现）


来源
==

处理器：hub/notespace.py (NoteSpaceHandler)
