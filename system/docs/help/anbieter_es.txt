TEMU
====

Contexto:
Las facturas de TEMU se importan desde confirmaciones de pedidos por correo electrónico,
no de recibos originales. Esta es una solución, hay
Recuperar automáticamente los recibos originales lleva mucho tiempo.

Reglas de entrada:

1. PRECIOS
   Extraiga siempre los archivos PDF del correo electrónico
   (Los precios son volátiles en el sitio web)

2. NOMBRES DE PRODUCTOS
   Si falta texto o está incompleto:
   - Derivar lógicamente del contexto.
   - Mejor: busque el producto en temu.com para obtener el nombre correcto

3. TIPO DE DOCUMENTO
   Marcar como “Confirmación de pedido (alternativamente factura)”

4. VALIDACIÓN POSTERIOR
   Si los recibos originales se cargan más tarde,
   Comparar y actualizar datos

Nota para Hacienda:
Los recibos originales solo se proporcionarán a pedido.
Las confirmaciones de pedido sirven como prueba inicial.
