Цвета агентов
=============

Цвет blueprint является необязательным. Допускаются null или шесть
шестнадцатеричных цифр с предшествующим #, например #12abef. Заглавные буквы
преобразуются в строчные. Другие значения CSS недопустимы.

При сохранении без поля цвета прежний цвет сохраняется. null удаляет его.
Изменения требуют текущей версии blueprint.

При материализации экземпляр наследует цвет blueprint. Явно заданное
переопределение экземпляра имеет приоритет. null для переопределения
экземпляра означает повторное наследование. Повторная материализация обновляет
цвет blueprint, но сохраняет переопределение экземпляра. Оба шага требуют
соответствующей текущей версии конфигурации. Сброс экземпляра удаляет
переопределение; существующий цвет blueprint наследуется.

Без сохранённого цвета API возвращает color=null и color_source=default.
Интерфейс в этом случае использует тему по умолчанию. Чтение старых профилей
не сохраняет новые поля цвета. Цвет не даёт никаких прав и не запускает
никакого воркера, провайдера или вызов модели.
