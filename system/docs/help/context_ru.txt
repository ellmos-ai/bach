КОНТЕКСТ - Контекстный поиск и долговременная память
=============================================

ОПИСАНИЕ
------------
Обработчик контекста обеспечивает комплексный поиск и управление контекстными
информация. Он ищет архивы памяти, историю чатов, описания задач.
и системные файлы. Идеально подходит для автоматической загрузки контекста перед новыми сеансами.

ОПЕРАЦИИ
-----------
  bach context auto                    Автоматическая загрузка соответствующего контекста
                                       (последние записи в памяти, приоритетные задачи,
                                        Извлеченные уроки, предупреждения)

  bach context search BEGRIFF          Искать во всех источниках по поисковому запросу
  [--от ТАННЫХ] [--к ТАННЫХ] Поддерживает логику И/ИЛИ/НЕ
  [--scope AREA] Область: 'all'|'longterm'|'system'

  bach context longterm                Показать архив памяти, отсортированный по времени
  [--от ДАТЫ] [--до ДАТЫ] Фильтр даты в формате ГГГГ-ММ-ДД
                                       Показывает макс. 20 записей + счетчик

  bach context recent [N]              Показать последние N записей памяти
                                       По умолчанию: 5, если N не указано

ПРИМЕРЫ
---------
  # Загрузка автоматического контекста (начало сеанса)
  bach context auto

  # Поиск терминов
  bach context search "deployment pipeline"
  bach context search "FEHLER regression" --from 2026-02-01 --to 2026-03-01
  bach context search "Python unittest" --scope system

  # Поиск в памяти
  bach context longterm
  bach context longterm --from 2026-02-15

  # Последние записи
  bach context recent
  bach context recent 10

ФАЙЛЫ
-------
  Обработчик:hub/context.py
  Архив памяти: Memory/*.md
  Управление задачами: память/tasks.json
  Уроки: docs/help/lessons.txt.
  Каталог журналов: data/logs/

СМОТРИТЕ ТАКЖЕ
----------
  bach search     - Поиск файлов в рабочей области
  bach memory     - Создание записей в памяти и управление ими
  bach status     - Информация о текущем сеансе
