BACH UPGRADE - SYSTEM UPDATE
-------------------------------------

Updates versioned BACH components selectively by file or category.


USE
----------

  # View upgrade status
  bach upgrade status
  bach upgrade status --json

  # Show available versions of a file
  bach upgrade list hub/backup.py
  bach upgrade list hub/backup.py --json

  # Check available updates
  bach upgrade check
  bach upgrade check --json

  # Selective category upgrades
  bach upgrade core
  bach upgrade templates
  bach upgrade agents
  bach upgrade skills
  bach upgrade hub
  bach upgrade tools
  bach upgrade connectors
  bach upgrade partners
  bach upgrade docs
  bach upgrade gui

  # Dry-Run (view only, do not execute)
  bach upgrade agents --dry-run

  # Inspect and repair upgrade metadata
  bach upgrade repair --dry-run
  bach upgrade repair --version v3.13.0-bluesky


CATEGORIES
----------

  core         System core (dist_type=2)
  templates    Templates and resettable defaults (dist_type=1)
  agents       Boss agents and experts
  skills       Skills and protocols
  hub          Hub handlers
  tools        Tools
  connectors   Connector system
  partners     Partner files
  docs         Documentation
  gui          GUI files


IMPORTANT
-------

- Upgrade only overwrites versioned files from distribution/manifest.
- USER_DATA remains untouched.
- Backup is recommended before major upgrades.
- Versions are tracked in `dist_file_versions`.
- `status/check --json` also return `manifest_entries`, `release_entries`, `repair_recommended`, `current_version`, and `current_release_registered`.
- `bach upgrade repair` rebuilds missing `distribution_manifest`/`dist_file_versions` rows from the live distribution tree and bootstraps the current release entry when `distribution_releases` is empty.
- Full historical release lists are not reconstructed automatically; the repair path only restores the current release entry.
- `--json` is supported for `list`, `status`, `check`, and `repair`.


EXAMPLES
---------

  # Update core files only
  bach upgrade core

  # Only update templates
  bach upgrade templates

  # Preview agent files only
  bach upgrade agents --dry-run

  # Restore/upgrade documentation
  bach upgrade docs

  # View available versions of a file
  bach upgrade list hub/backup.py

  # Query upgrade drift as JSON for automation
  bach upgrade check --json

  # Diagnose metadata first, then repair
  bach upgrade repair --dry-run
  bach upgrade repair --version v3.13.0-bluesky


VERSIONING
-------------

- Hash + Auto-Increment System (ENT-09)
- Only versioned distribution files can be moved via `bach upgrade`
- USER_DATA is from the user and is not versioned
