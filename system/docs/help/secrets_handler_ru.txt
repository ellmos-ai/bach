Обработчик BACH: секреты
---------------------

Безопасное управление ключами API, токенами и данными доступа.

ИСПОЛЬЗОВАНИЕ
----------

  bach --secrets list                Показать все секреты (только ключи)
  bach --secrets get <key>           Получить значение секрета
  bach --secrets set <key> <value>   Установить/обновить секрет
  bach --secrets delete <key>        Удалить секрет

ОПЦИИ
--------

  --category <cat> Категория (общая, API, Telegram и т. д.)
  --description <текст> Описание секрета

РАСПОЛОЖЕНИЕ
-----------

  ~/.bach/bach_secrets.json (зашифровано с помощью Fernet)
  Настраивается в system_config: путь_секретного_файла

БЕЗОПАСНОСТЬ
----------

  - Секреты зашифрованы с помощью Fernet (AES-128-CBC).
  - Соль: фиксированные 16 байт (без разделения на новую строку!)
  - Никогда не передавайте секреты в Git.
  — Файл секретов в .gitignore

MODULE
-----

  хаб/secrets_handler.py (SecretsHandler)
