Обработчик BACH: секреты
=======================

Значения секретов хранятся только в системном хранилище учётных данных.
`bach.db` и `bach_secrets.json` содержат только метаданные.

ИСПОЛЬЗОВАНИЕ
-------------

  bach secrets list
  bach secrets get <key>
  bach secrets set <key> [--desc=TEXT] [--category=CAT]
  bach secrets set <key> --stdin [--desc=TEXT] [--category=CAT]
  bach secrets delete <key>
  bach secrets sync

БЕЗОПАСНОСТЬ
------------

  - `get` никогда не выводит значение секрета в stdout.
  - Значения в аргументах процесса отклоняются.
  - Если хранилище нельзя проверить, миграция прерывается.
