TELEMETRY (OPS-TELEM-001)
=========================

bach telemetry    - Low-cardinality, privacy-first counters


DESCRIPTION
===========

Captures aggregated counters with validated labels.
Counter: agent_starts / model_calls / tool_calls
Outcome: ok / error / dummy / timeout

Privacy: ONLY aggregated counters are stored --
no payloads, prompts, paths or user data.
Opt-out: BACH_TELEMETRY_DISABLED=1


COMMANDS
=======

bach telemetry report [days]      Counters of the last N days (default 7)
bach telemetry status             Capture/schema status
bach telemetry reset --confirm    Delete all counters
