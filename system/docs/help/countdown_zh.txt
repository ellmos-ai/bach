COUNTDOWN - 带触发器的倒计时
==================================

倒计时计时器，可选择在到期时执行命令。

CLI 命令
-----------

  bach countdown start <name> <duration>              开始倒计时
  bach countdown start <name> <duration> --after "cmd" 带触发命令
  bach countdown <duration>                           简写形式：以 "timer" 启动 (v1.1.84)
  bach countdown stop <name>                          取消倒计时
  bach countdown list                                 活动倒计时
  bach countdown pause <name>                         暂停
  bach countdown resume <name>                       恢复

时长格式
-------------

  HH:MM:SS   例如 01:00:00 = 1小时
  MM:SS      例如 25:00 = 25分钟
  Xs/Xm/Xh   例如 90s, 25m, 2h (简写形式)

输出格式
--------------

  启动:       [COUNTDOWN] 'name' 已启动: 01:00:00
  暂停:       [COUNTDOWN] 'name' 已暂停 (剩余 45:12)
  恢复:       [COUNTDOWN] 'name' 已恢复 (剩余 45:12)
  停止:       [COUNTDOWN] 'name' 已取消

  列表:       [COUNTDOWN] 活动倒计时:
                name: 45:12                 (正常)
                name: 04:58 [!]             (警告，剩余 < 5 分钟)
                name: 已过期!
                name: 19:45 (已暂停)

持久性
----------

  文件: data/.countdown_state

  内容:
  {
    "countdowns": {
      "session": {
        "end_time": "2026-01-30T15:00:00",
        "after_command": "shutdown '时间到'",
        "paused": false,
        "remaining_on_pause": null
      }
    }
  }

示例
---------

  #1小时会话倒计时
  bach countdown start session 01:00:00
  -> 倒计时 'session' 已开始: 01:00:00

  # 具有自动关闭功能
  bach countdown start session 01:00:00 --after "shutdown 'Session beendet'"
  -> 当它到期时，执行 "bach --shutdown '会话结束'"

  # 番茄计时器（25 分钟）
  bach countdown start focus 00:25:00
  -> 倒计时 'focus' 已开始: 00:25:00

  # 暂停和恢复
  bach countdown pause focus
  bach countdown resume focus

  # 检查状态
  bach countdown list
  -> [COUNTDOWN] 活动倒计时:
  ->   session: 45:12
  ->   focus:   19:45 (已暂停)

TRIGGER (--after)
-----------------

--after 命令到期时执行：

  --after "shutdown '时间到'"          结束会话
  --after "msg send user '休息!'"      发送消息
  --after "task done 123"             将任务标记为已完成

执行时，命令将写入队列。
下一个 CLI 调用将执行它（或守护进程）。

用例
--------

  1. 会话限制
     bach countdown start session 02:00:00 --after "shutdown 'Limit erreicht'"
     -> 2 小时后会话自动结束

  2. 番茄工作法
     bach countdown start focus 00:25:00 --after "msg send user 'Pause machen!'"
     -> 25 分钟后提醒暂停

  3. 截止日期提醒
     bach countdown start deadline 04:00:00
     -> 在 < 5 分钟时发出警告，然后手动采取行动

互动
-------------

倒计时是时间系统的一部分：
  --help clock    时间显示
  --help timer    秒表
  --help between  between 检查
  --help beat     统一时间显示
