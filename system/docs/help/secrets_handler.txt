BACH Handler: Secrets
=====================

Sichere Verwaltung von API-Keys, Tokens und Zugangsdaten über den
OS-Schlüsselbund.

VERWENDUNG
----------

  bach secrets list
  bach secrets get <key>
  bach secrets set <key> [--desc=TEXT] [--category=CAT]
  bach secrets set <key> --stdin [--desc=TEXT] [--category=CAT]
  bach secrets delete <key>
  bach secrets sync

SICHERHEIT
----------

  - Werte liegen ausschließlich im OS-Schlüsselbund.
  - `get` gibt keinen Secret-Wert auf stdout aus.
  - Werte als Prozessargumente werden abgewiesen.
  - `bach.db` und `bach_secrets.json` enthalten nur Metadaten.
