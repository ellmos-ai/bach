BUDDHA CHAT И ПРОТОКОЛЫ СЕССИЙ
==============================

ОПИСАНИЕ
--------
Buddha Chat — это интерактивный интерфейс ассистента BACH, доступный через
Web-GUI (http://localhost:8000/chat), а также как Telegram-бот. Buddha
отвечает на вопросы, планирует работы, выполняет инструменты BACH и управляет
своим контекстом через канонические снимки в bach.db.

СПОСОБЫ ДОСТУПА
---------------
1. Web-Chat:     http://localhost:8000/chat
                 Использует фиксированный ID сессии "gui-web". Сообщения
                 сохраняются даже при перезагрузке страницы (автоматическое
                 восстановление).
2. Telegram-бот: @BachBuddhaBot (или настроенный токен)
                 Каждый чат Telegram имеет собственный числовой ID чата.
3. Системный трей: Панель состояния с выбором модели/режима и быстрым
                 доступом.

ЖИЗНЕННЫЙ ЦИКЛ СЕССИИ И АВТОМАТИЧЕСКИЙ СБРОС
--------------------------------------------
Чтобы старые, давно завершённые темы не оставались постоянно в контексте
мышления, каждая чат-сессия подчиняется следующему жизненному циклу:
1. Сброс после 24 часов неактивности (TTL):
- Если чат не использовался более 24 часов (last_active > 86400s), при
  получении следующего сообщения он автоматически архивируется и сбрасывается
  в пустое состояние.
- На следующий день пользователь автоматически начинает со свежей головой.

2. Ручной сброс:
- Telegram:  Команда /clear
- Web-GUI:   Кнопка [ ➕ Neuer Chat ] в панели состояния
- Оба способа полностью архивируют прежнюю историю перед очисткой.

3. Гарантия Zero-Data-Loss:
- Никакая история сообщений не удаляется безвозвратно.
- Все сессии сохраняются как постоянный транскрипт (тип: chat-transcript.v1)
  в таблице session_snapshots центральной bach.db.

ПРОТОКОЛЫ И ФОРКИНГ (ВОЗОБНОВЛЕНИЕ)
-----------------------------------
В Web-GUI (http://localhost:8000/chat) находится кнопка [ 📉 Protokolle ]:
1. Обзор архива:
- Показывает в хронологическом порядке все записанные сессии из Web, Telegram
  и Worker.
- Фильтруется по "Alle", "Web", "Telegram" и "Archiv".

2. Инспекция транскрипта:
- Клик по записи открывает полный транскрипт, включая все сообщения
  пользователя и ассистента с временными метками и форматированием.

3. Продолжить в Web-Chat (Fork):
- Через кнопку [ 🔑 Im Web-Chat fortsetzen (Fork) ] любую историческую сессию
  (из Telegram или более ранней Web-сессии) можно загрузить в текущий Web-Chat
  и сразу продолжить обсуждение.
- Существующая Web-сессия при этом предварительно автоматически сохраняется.

РЕЖИМЫ БЕЗОПАСНОСТИ
-------------------
  - safe:  Только запросы на чтение (ls, cat, grep, git status и т.д.).
  - full:  Также инструменты записи (создание файлов, выполнение команд).
           В Telegram: подтверждается через /mode full
           В Web-GUI:  Через Control-Dashboard / API
