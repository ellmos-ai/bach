SECURITY
========

bach security    - Static security scan for BACH


DESCRIPTION
===========

Scans BACH-specific code paths for dangerous patterns and produces
a categorized report. Uses the capability system
(core.capabilities) for the actual pattern detection.

Default paths: tools, skills, hub, core, scripts, bin
Latest report: security_scan_latest.json


COMMANDS
========

bach security scan                Scans default paths
bach security scan tools/         Scans a specific directory
bach security scan --json         JSON report
bach security scan --dry-run      Shows what would be scanned
bach security status              Display the latest report
