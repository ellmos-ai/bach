AGENT - Agent launcher and administration
======================================

DATE: 2026-05-21

The agent system allows you to start and manage BACH agents
as separate Claude code processes. Each agent comes with their own
SKILL.md started as an identity.

STRUCTURE
--------

  [Boss Agent] -- Coordinates and delegates
       |
       +-- [Expert 1] -- Specialized execution
       +-- [Expert 2]

Agent directories:
  agents/ Boss agents (with SKILL.md)
  agents/_experts/ Experts (with SKILL.md)

CLI COMMANDS (bach agent)
------------------------

  list List all available agents
  start <name> Start agent (new terminal window)
  stop <name> Stop running agent
  pause <name> [reason] Request a cooperative pause for a running agent
  resume <name> Clear an active pause request for an agent
  steer <name> "..." Save an operator hint for a running agent or its next start
  clear-steer <name> Clear queued operator hints for an agent
  rename <name> <new> Change the display name of an agent/expert
  status Show all running agents
  doctor [name] Agent preflight and recovery notes
  list --json agents including runtime metadata as JSON
  start <name> --json Start response machine-readable as JSON
  stop <name> --json Stop response machine-readable as JSON
  pause <name> --json Pause response including operator_control as JSON
  resume <name> --json Resume response including operator_control as JSON
  steer <name> --json Steer response including queue status as JSON
  clear-steer <name> --json Clear-steer response including queue status as JSON
  status --json Running/registered agents as JSON
  doctor [name] --json Diagnosis machine-readable as JSON

OPTIONS FOR START
-------------------

  --mode plan|default mode (default: default)
  --model sonnet|opus|haiku AI model (default: sonnet)
  --permission-mode restricted|full Claude Code permission profile (default: restricted)
  --allowed-tools "Read,Grep,..." Tool allowlist for restricted mode
  --max-turns N Hard cap for Claude turns
  --dry-run Just check, don't start
  --json Machine-readable output for list/start/stop/pause/resume/steer/clear-steer/status/doctor

EXAMPLES
---------

  # List all agents (including running status)
  bach agent list

  # Start agent
  bach agent start ati
  bach agent start research --model opus
  bach agent start entwickler --mode plan
  bach agent start ati --permission-mode restricted --allowed-tools "Read,Grep,Glob,Bash"
  bach agent start production --max-turns 12
  bach agent start ati --dry-run
  bach agent start ati --dry-run --json

  # Show and control running agents
  bach agent status
  bach agent status --json
  bach agent pause ati "Pause after the next checkpoint." --json
  bach agent resume ati --json
  bach agent steer ati "Bitte nur Statusflächen anfassen." --json
  bach agent clear-steer ati --json

  # Queue guidance before the next launch
  bach agent steer ati "Please start with diagnostics only." --json

  # Check start requirements and recovery
  bach agent doctor ati
  bach agent doctor Theodor --json

  # Stop agent (by name)
  bach agent stop ati
  bach agent stop ati --json

HOW IT WORKS
-------------------

1. `bach agent start <name>` finds the agent's SKILL.md
2. A temporary CLAUDE.md is created (data/temp/agent_<name>/)
3. A new terminal window opens with Claude Code
4. Runtime policy (`permission_mode`, `allowed_tools`, `max_turns`) is applied at launch time
5. PID is stored in data/agent_pids/<name>.pid
6. `bach agent pause <name> [reason]` writes a cooperative pause request to `operator_pause.json` and mirrors it into `OPERATOR_NOTES.md`
7. `bach agent resume <name>` clears that pause request explicitly
8. `bach agent steer <name> "..."` writes operator notes to `OPERATOR_NOTES.md`, even if the agent is currently stopped
9. The next `bach agent start <name>` preserves queued hints, injects them into the generated `CLAUDE.md`, and does not silently drop them
10. `bach agent list --json` and `bach agent status --json` expose the run state plus a nested `operator_control` snapshot with `pause_requested`, `pause_reason`, `pending_steer_count`, `latest_steer_message`, file paths, and available actions
11. `bach agent clear-steer <name>` clears stale or completed queued hints
12. `bach agent stop <name>` ends the process, clears active pause requests, and can keep queued guidance for the next start

REQUIREMENTS
---------------
- Claude Code CLI must be installed (command: `claude`)
- Agent must have a SKILL.md (agents/<name>/SKILL.md)

RECOVERY / TROUBLESHOOTING
--------------------------

If `bach agent start ...` fails or an agent window immediately returns
closes, run the diagnostics first:

  bach agent doctor ati
  bach agent doctor ati --json

`doctor` checks:
- whether the Claude Code CLI is found in the PATH
- whether `data/agent_pids/` and `data/temp/` are writable
- whether the requested agent and its `SKILL.md` are readable
- whether outdated PID files need to be cleaned up

Typical next steps after the report:
- `bach agent start <name> --dry-run` for a safe preliminary test
- `bach agent list --json` or `bach agent status --json` for running, hanging, or pre-queued sessions
- `bach agent pause <name> "..." --json` if a running agent should pause cooperatively at the next safe point
- `bach agent resume <name> --json` if a pause request should be removed again
- `bach agent steer <name> "..." --json` to stage guardrails before the next launch
- `bach agent clear-steer <name> --json` when completed hints still remain queued
- Install Claude Code CLI or check login/setup locally
