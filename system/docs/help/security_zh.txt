安全
==

bach security   - BACH 静态安全扫描


说明
==

扫描 BACH 自有代码路径中的危险模式并生成分类报告。使用能力系统
（core.capabilities）进行实际的模式识别。

默认路径：tools, skills, hub, core, scripts, bin
最新报告：security_scan_latest.json


命令
==

bach security scan                扫描默认路径
bach security scan tools/         扫描指定目录
bach security scan --json         JSON 报告
bach security scan --dry-run      显示将要扫描的内容
bach security status              显示最新报告


来源
==

处理器：hub/security.py (SecurityHandler)
