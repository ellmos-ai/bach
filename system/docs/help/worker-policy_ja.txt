ワーカールール: 設定とリース表示
================

前提条件
共通の Task-Master 契約 taskplan.worker_policy がインストールされている必要があ
ります: worker-review-policy.v1alpha1。これが欠落しているかバージョンが不明な
場合、ワーカールールは利用できません。第 2 の BACH ポリシーフォールバックはあ
りません。

BACH ルートからオプションパッケージを明示的にインストールします:
python -m pip install -e ".[worker-policy]"

この Extra は共通コアを検証済みの Task-Master コミット
5924b71b2a93e59e625b5c9afaa6e84966bf49d3 に固定します。一般的なバージョン番号
taskplan==0.7.0 だけではこの状態を特定できません。このインストール経路は古い
setup.py --extras から分離されています。インストール後、独立して status を読
み取ってください。インストールはワーカーを起動せず、ユーザー受け入れを代替しま
せん。

CLI およびライブラリ経由のアクセス
bach worker-policy status
bach worker-policy task_show 41

from bach_api import worker_policy
ok, text = worker_policy.raw("status")
ok, text = worker_policy.raw("task_show", 41)

set は configuration_version、policy、および selection を持つ JSON オブジェク
トを受け付けます。task_set はタスク ID と task_id、task_version、
configuration_version、override を持つ JSON を受け付けます。書き込みアクション
なしの例:

import json
ok, text = worker_policy.raw("status")
snapshot = json.loads(text) if ok else None

バージョン値は常に新しく読み取ってください。競合が発生した場合は再読み込みし、
変更を意図的に調整してください。拒否されたミューテーションは自動的に再試行され
ません。

GUI-API
GET/PUT /api/system/worker-policy
GET/PUT /api/tasks/{id}/worker-policy

4 つのアクセスすべてにアクティブな登録済みデバイスが必要です。トークンは既存の
Authorization ヘッダまたはデバイスクッキーに含めるべきであり、URL には含めませ
ん。ローカル/ネイティブのライブラリ使用も同じ設定サービスを使用します。

ルールと保存
グローバルポリシーとタスクに紐づくオーバーライドは、正規 BACH データベースの既
存の system_config ストアに保存されます。リビジョンと CAS はタスク内容およびス
テータスから分離されています。リセットは設定リビジョンを増加させます。同じ値に
戻す変更であっても古い書き込み状態は無効になります。読み取りはスキーマも設定も
変更しません。ストアの欠落は空の有効なデフォルトと同義ではありません。

mode=null はモードを継承します。ブール値オーバーライドは null、false、true を
区別します。設定されたユーザーレビュー義務は false やリセットによって削除でき
ません。保存されたルールはレビュー権限を付与しません。

保存確認はワーカーを起動せず、結果も受け入れません。タスクビューは検証済み結果
整合性がない場合、明示的に not_evaluated を報告します。結果サービス、選択、およ
び実際の実行はルールを別途適用する必要があります。この設定射影は本番またはユー
ザー受け入れではありません。

リース表示
既存の Worker/Core-Agent ステータス経路は、確認済みコントローラバインディング
と正規タスクバインディングからアクティブなタスクリースを射影できます。世代、タ
スクバージョン、保持者、フェンス、ハートビート、および有効期限が一致する必要が
あります。保存されたタスク ID やプロファイルステータスだけではアクティブなリー
スは証明されません。

このステータス射影における lease_id は公開観測参照 sha256:<digest> であり、
lease_id_kind=observation_sha256 および source=native_task_db によって識別さ
れます。プライベート Claim-ID はリースクライアントに留まります。観測参照は
Claim、Renew、または Release 権限を付与しません。

カウントダウンとソートはオプションの表示です。タスクリースもターン予算も変更せ
ず、実行時間を延長せず、作業も開始しません。
