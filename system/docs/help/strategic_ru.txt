СТРАТЕГИЧЕСКИЕ ДОКУМЕНТЫ - МЕТАПОЗНАНИЕ
---------------------------------------

Статус: 2026-02-08

ОБЗОР
----------
BACH использует три основных документа для долгосрочного контроля и метапознания:

  system/ROADMAP.md Видение, этапы, долгосрочные цели
  system/CHANGELOG.md История изменений (версии, дата, подробности)

Дополнительно:
- Уроки и стратегические идеи сохраняются в памяти/MEMORY.md.
- Ошибки также отслеживаются через систему задач (категория: обслуживание/ошибка).

КЛАССИФИКАЦИЯ В СИСТЕМЕ ПАМЯТИ
---------------------------

  +------------------------------------------------------------------+
  |                    МЕТАКОГНИЦИЯ (стратегия) |
  |  +-----------------------------------------------------------------+|
  |  | система/ROADMAP.md | система/CHANGELOG.md | память/MEMORY.md||
  |  | документы/con3_*.md | Анализы |                 ||
  |  +-----------------------------------------------------------------+|
  |                          |                                    |
  |                          | Вывод |
  |                          в |
  |  +-----------------------------------------------------------------+|
  |  |                    СИСТЕМА ЗАДАЧ (планирование) ||
  |  |  Конкретные, выполнимые задачи ||
  |  |  список задач Баха / добавить / выполнено ||
  |  +-----------------------------------------------------------------+|
  |                          |                                    |
  |                          | Исполнение |
  |                          в |
  |  +-----------------------------------------------------------------+|
  |  |              СИСТЕМА ПАМЯТИ (Оперативная) ||
  |  |  память_сессии | уроки_памяти | память_работает ||
  |  +-----------------------------------------------------------------+|
  +------------------------------------------------------------------+

Цепь:
  1. Стратегия определяет цели (system/ROADMAP.md)
  2. Цели становятся задачами (система задач)
  3. Задачи генерируют активности (сессии/журнал)
  4. События консолидируются (бах консолидируются)
  5. Стратегия обновления результатов (memory/MEMORY.md)

СТИЛИ ДОКУМЕНТА
--------------

system/ROADMAP.md:
  - Фокус: видение, этапы, этапы.
  - Степень детализации: грубые блоки (например, «Фаза 12: Налоги»).
  - Цель: Ориентация для агентов-партнеров (Где мы?).

memory/MEMORY.md:
  - Фокус: критические идеи и извлеченные уроки.
  - Стиль: Структурированная документация проблем и решений.
  - Категории: организованы по функциям/модулям.

КОНСОЛИДАЦИЯ В СТРАТЕГИИ
---------------------------
Этот процесс преобразует оперативные данные в стратегические документы:

  Необработанные данные ---[окончание сеанса bach] ---> Сеансы (БД)
  Сессии ---[сжатие консолидации bach]---> Контекст (БД)
  Задачи (выполнено) ---[Ручное обслуживание]---> память/MEMORY.md

КОМАНДЫ ДЛЯ ПОДДЕРЖКИ:
  bach consolidate status                    Показывает статус консолидации
  bach consolidate compress --batch          Группирует сеансы (простые)
  bach consolidate compress --run            Сжимает с набором правил
  bach consolidate review                    Создает задачи проверки для вики/документов
  bach consolidate run                       Выполняет все процессы
