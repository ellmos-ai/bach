# СЕКРЕТЫ

BACH хранит значения секретов только в системном хранилище учётных данных.
`bach.db` и `~/.bach/bach_secrets.json` содержат только метаданные и маркер
бэкенда. Отсутствие индекса метаданных не удаляет учётные данные.

Операции
--------

- `bach secrets list`: показывает только метаданные и состояние бэкенда.
- `bach secrets get <key>`: проверяет доступность, не выводя значение.
- `bach secrets set <key>`: запрашивает значение в скрытом интерактивном вводе.
- `bach secrets set <key> --stdin`: читает значение из stdin без журналирования.
- `bach secrets delete <key>`: удаляет значение и метаданные.
- `bach secrets sync`: переносит старый открытый текст после проверки хранилища.

Значения, переданные в аргументах процесса, отклоняются.
