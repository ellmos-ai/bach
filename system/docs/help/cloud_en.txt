CLOUD - Provider-Neutral Cloud Sync Control
==========================================
The Cloud-Control service prevents file locks, sync conflicts and
SQLite-WAL collisions during write-intensive operations, backups and
bulk maintenance runs.

SUPPORTED PROVIDERS
-------------------
- Microsoft OneDrive (Windows / macOS / Linux)
- Google Drive (Windows / macOS)
- Apple iCloud Drive (macOS bird / CloudDocs, Windows iCloud.exe)
- Dropbox (Windows / macOS / Linux)
- Nextcloud / ownCloud (Windows / macOS / Linux)

CORE CONCEPTS
-------------
1. AUTO DETECTION: Automatically detects installed and running clients on startup.
2. OPERATIONAL PROTECTION: Cloud sync is paused only briefly during write-intensive
   jobs and reactivated immediately afterwards (no permanent stop when idle).
3. FAIL-SAFE WATCHDOG: A safety timer reliably reactivates paused clients
   once the timeout expires (default: 300s), even in the event of program crashes.
4. ARCHITECTURE & DIAGRAMS: See docs/ARCHITECTURE_CLOUD_CONTROL.md

CLI COMMANDS (bach cloud)
-------------------------
  bach cloud status                     Overview of all detected cloud services
  bach cloud status --json              Status in JSON format
  bach cloud pause [provider] [-t SEC]  Pauses sync with safety timeout (default: 300s)
  bach cloud resume [provider]          Resumes paused services
  bach cloud toggle [provider]          Switches between pause and resume

PYTHON CONTEXT MANAGER
----------------------
  from hub._services.cloud import cloud_pause

  with cloud_pause(timeout=180):
       # Write-intensive file operations
      write_data()
   # Cloud sync resumes automatically in the background
