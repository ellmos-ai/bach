问题解决 - 结构化思维
--------------------------------------

描述
------------
复杂任务的问题解决和分析策略。
针对困难情况的结构化思维过程。

解决问题的方法
------------------------

1。分而治之
   问题 -> 子问题 -> 单独解决 -> 组合

   何时使用：可以分解的大型、复杂问题。

2。根本原因分析（5 个为什么）
   症状 -> 为什么？ -> 为什么？ -> 为什么？ -> 原因 -> 解决方案

   何时使用：当不清楚实际问题是什么时。

3。约束松弛
   无法解决 -> 放松约束 -> 解决 -> 收紧约束

   何时使用：当要求过于严格时。

4。类比搜索
   新问题 -> 类似的已知问题 -> 适应解决方案

   何时使用：对于没有明显解决方案的新问题。

分析方法
----------------

  方法应用
  ---------- ----------------------------------------
  SWOT 优势/劣势/机会/风险
  赞成/反对决策
  Pareto 80/20 优先级（找到最重要的 20%）
  鱼骨根本原因分析（石川图）

决策启发式
-------------------------

当不确定时：
  1. 最坏的情况是什么？
  2. 是否可逆？
  3. 不作为的代价是什么？

复杂性：
  1. 最简单的第一步是什么？
  2. 专家会做什么？
  3. 80% 的解决方案是什么？

实用技巧
----------------
- 始终从最简单的步骤开始
- 记录思维过程以供将来参考
- 如果出现阻塞：休息一下，重新表述问题
- 80% 的解决方案通常比 100% 的计划更好
