思维策略
==============
信息处理的认知和元认知策略。

参考：学习系统分析，docs/help/operators.txt，docs/help/rhetorik.txt


1。认知策略（信息处理）
===================================================
控制如何处理信息。

1.1 分块
-----------------------
将复杂的信息分解为更小的单元。
  - 将大任务分为5个步骤
  - 将文本分为几个部分
BACH：任务分解、工作流程阶段

1.2 模式识别
-------------------
识别重复结构。
  - 日志中出现类似错误
  - 经常性文档类型
巴赫：经验教训模式匹配

1.3 进行类比
-------------------
通过将新事物与已知事物进行比较来理解新事物。
  - “邮件路由就像网络路由”
  - “操作员就像乐高积木”

1.4 假设形成
---------------------
在测试之前制定假设。
  - “如果分数低，则可能缺少必填字段”

1.5 演绎思维
---------------------
从一般情况推断到个别情况。
  -》所有发票都有发票号码->本文件
     没有 -> 可能没有计算”

1.6 归纳思维
---------------------
从个案中推导出规则。
  - “90% 的情况下主题包含‘发票’
     真实的账单”
巴赫：经验教训推导

1.7 因果思维
-------------------
认识因果关系。
  - “错误增加 -> CPU 负载增加 -> 可能是瓶颈”

1.8 视角的改变
---------------------
从不同的角度看问题。
  - 用户视角与开发者视角

1.9 场景思维
------------------
尝试“假设”变体。
  - “如果 API 失败会发生什么”
  - “如果分类错误怎么办”
巴赫：模式（2）思考

1.10 优先考虑
-----------------
首先处理重要信息。
  - 警告之前的严重错误
  - 新闻通讯之前的发票
BACH：任务优先级（P1 > P2 > P3）


2。元认知策略（思考思考）
==================================================
控制你如何控制自己的思考。

2.1 自我监控
-----------------------------------
观察你自己的思考。
  - “我真的理解这个问题吗”
  - “我现在做出什么假设？”

2.2 自我调节
--------------------
积极调整思维过程。
  - 降低速度
  - 改变策略（例如从假设 -> 检验）

2.3 错误分析
-----------------
找出自己的思维错误。
  - 确认错误
  - 仓促的结论
巴赫：经验教训（Bug 类别）

2.4 提出元问题
-----------------------
有关思维过程本身的问题。
  - “我缺少什么信息？”
  - “我需要哪些算子？”

2.5 策略选择
-----------------
有意识地决定哪种思维策略是正确的。
  - “我需要模式识别或假设形成吗？”

2.6 反思
-------------
对思维过程的后续评估。
  - “为什么这个解决方案有效”
  - “下次我会采取什么不同的做法？”
BACH：会议总结，巩固

2.7 元建模
--------------------
将问题转化为更抽象的模型。
  - “这是一个分类问题”
  - 《这是一个路由问题》

2.8 元抽象
--------------------
通过看本质来降低复杂度。
  - “实际上只涉及三个变量”

2.9 元比较
-------------------
思维策略之间的比较。
  - “假设形成无效 -> 更好的数据驱动”

2.10 元规划
-----------------
在思考之前规划如何思考。
巴赫：模式（2）思考=有意识地激发注射器


3。与巴赫模式相关
=====================

模式 (1) 节能：
  - 模式识别（自动）
  - 确定优先级（获取规则）
  - 演绎（快速结论）

方式（2）反思：
  - 情景思维
  - 改变观点
  - 假设的形成
  - 询问元问题
  - 策略选择

模式（3）整合：
  - 归纳思维（推导规则）
  - 反思
  - 错误分析
  - 元抽象


4。与修辞相关
====================
思维策略有直接的修辞对应物：

  分块 -> 提纲，三点规则
  模式识别 -> Topoi（论证模式）、故事原型
  类比->隐喻、比较
  形成假设 -> 准备论证，预测反驳
  演绎/归纳->逻辑推理
  情景思维 -> “假设”论证
  优先级 -> 核心信息、电梯推介

修辞 = 认知策略 + 语言包装

请参阅：--help 修辞
