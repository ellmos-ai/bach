МЕЖДУ - Промежуточные проверки профилей
======================================

Напоминания между задачами. Настраивается через профили.

КОМАНДЫ CLI
-----------

  Вкл/Выкл:
  bach between on                  Включить между проверками
  bach between off                 Отключить
  bach between status              Показать статус

  Управление профилями:
  bach between profile add "Name"     Создать новый профиль
  bach between profile edit "Name"    Редактировать профиль
  bach between profile delete "Name"  Удалить профиль
  bach between profile list           Просмотреть все профили
  bach between profile show "Name"    Детали профиля

  Активировать профиль:
  bach between use "Name"          Активировать профиль для сеанса
  bach between use default         Вернуться к стандартному профилю (в качестве имени используется «по умолчанию»)

СТРУКТУРА ПРОФИЛЯ
---------------

  {
    "name": "Алгебра",
    "description": "Задачи по математике с проверкой",
    "message": "ВРЕМЕННАЯ ПРОВЕРКА:\n1. Проверка результата\n2. Проверка метода расчета\n3. Документ",
    "trigger_on": ["задача выполнена", "задача выполнена"],
    «is_default»: ложь
  }

СТАНДАРТНЫЕ ПРОФИЛИ
----------------

  1. ПО УМОЛЧАНИЮ
     Общий между проверками (текущее поведение)
     «1. Проверка времени 2. Память в порядке? 3. Следующее задание?»

  2. ФОКУС
     Минимальная проверка для целенаправленной работы
     «Продолжить или сделать перерыв?»

  3. ОБЗОР
     Подробная проверка с примечаниями к проверке кода
     «1. Проверить код 2. Запустить тесты? 3. Задокументировать?»

  4. ОБУЧЕНИЕ
     Проверьте с помощью вопросов для размышления
     «1. Что узнал? 2. Создал урок? 3. Понял?»

  5. АВТОМОБИЛЬНАЯ СЕССИЯ
     Автоматический рабочий процесс с контролем времени
     «1. Проверка времени 2. Продолжительность последнего задания? 3. Продолжение или завершение сеанса?»

ПРИМЕРЫ
---------

  # Новый профиль для математических задач
  bach between profile add "Mathe"
  -> Профиль «Математика» создан (редактировать с помощью: между редактированием профиля)

  # Посмотреть профиль
  bach between profile show "Mathe"
  -> Показывает детали профиля (редактирование еще не реализовано)

  # Активировать профиль
  bach between use "Mathe"
  -> Профиль «Математика» активирован для этого сеанса 

  # Вернуться к стандартному формату
  bach between use default

ФОРМАТ ВЫХОДА
--------------

  [МЕЖДУ ЗАДАЧАМИ]
  1. Проверьте результат последнего задания
  2. Проверьте методику расчета на наличие ошибок
  3. Задокументируйте промежуточные этапы

  Совет: --status для обзора

PERSISTENCY
----------

  Таблица: между_профилями (bach.db)
  Активный профиль: data/.between_state

ПРИМЕЧАНИЕ
-------

  Добавление/редактирование/удаление профиля еще не реализовано.
  Используйте БД напрямую или дождитесь следующей версии.

USECASES
--------

  1. КОНКРЕТНОСТЬ ПРОЕКТА
     Каждый проект имеет свой межпрофильный
     -> Переключение при смене проектов

  2. ОБУЧАЮЩИЕ ЗАНЯТИЯ
     Профиль «Обучение» с вопросами для размышления
     -> Способствует сознательному обучению

  3. ПРОВЕРКА КОДА
     Профиль «Обзор» с контрольным списком проверки
     -> Гарантия качества

  4. РЕЖИМ ФОКУСИРОВКИ
     Профиль «Фокус» с минимальной проверкой
     -> Меньше прерываний

INTERPLAY
-------------

Between является частью системы времени:
  --help clock Отображение времени
  --help таймер секундомер
  --help обратный отсчет Обратный отсчет с триггером
  --help победить Единое отображение времени
