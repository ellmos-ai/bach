問題解決 - 構造化思考
--------------------------------------

説明
------------
複雑なタスクの問題解決と分析戦略。
困難な状況に対する構造化された思考プロセス。

問題解決のアプローチ
------------------------

1。分割して征服する
   問題 -> サブ問題 -> 個別に解決 -> 結合

   使用する場合: 分解できる大規模で複雑な問題。

2.根本原因分析 (5 つのなぜ)
   症状 -> なぜですか? -> なぜですか? -> なぜですか? -> 原因 -> 解決策

   使用する場合: 実際の問題が何か不明な場合。

3.制約の緩和
   解決不可能 -> 制約を緩和 -> 解決 -> 制約を強化

   使用する場合: 要件が制限されすぎる場合。

4.アナロジー検索
   新しい問題 -> 同様の既知の問題 -> 解決策を適応する

   使用する場合: 明らかな解決策のない新しい問題の場合。

分析方法
----------------

  メソッドの適用
  ---------- --------------------------------------
  SWOTの強み/弱み/機会/リスク
  賛成/反対の意思決定
  パレート 80/20 の優先順位付け (最も重要な 20% を見つける)
  フィッシュボーン根本原因分析 (石川図)

意思決定ヒューリスティック
-------------------------

不確実性がある場合:
  1. 最悪のシナリオは何ですか?
  2. リバーシブルですか?
  3. 何もしないことの代償は何ですか?

複雑さ:
  1. 最も簡単な最初のステップは何ですか?
  2. 専門家なら何をするでしょうか?
  3. 80% の解決策は何でしょうか?

実践的なヒント
----------------
- 常に最も簡単なステップから始めてください
- 将来の参考のために思考プロセスを文書化する
- 障害がある場合: 休憩を取り、問題を再定式化します。
- 80% の解決策は 100% の計画より優れていることがよくあります
