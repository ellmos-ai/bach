РЕЖИМЫ ПОЛЬЗОВАТЕЛЯ BACH (v1.1.37)
-------------------------

BACH поддерживает 4 различных режима запуска, которые определяют
какие компоненты запускаются автоматически при запуске.

ДОСТУПНЫЕ РЕЖИМЫ
----------------
  режим графического интерфейса пользователя (по умолчанию)
           - Запускает панель графического интерфейса в браузере.
           - Открывается http://127.0.0.1:8000
           - Идеально подходит для интерактивного использования

  текстовый текстовый режим
           - Консоль запускается только с bach.py
           - Ни один браузер не открывается
           - Идеально подходит для работы с терминалами

  двойной двойной режим
           - Запускает графический интерфейс + отдельную консоль
           - Оба интерфейса могут использоваться параллельно
           - Идеально подходит для опытных пользователей

  тихий тихий режим
           - Ничего не запускается автоматически
           - Вывод только отчета о запуске
           - Идеально подходит для сценариев и автоматизации

ИЗМЕНЕНИЕ РЕЖИМА
-------------
Постоянный (сохранить в конфигурации):
  bach --startup mode gui
  bach --startup mode text
  bach --startup mode dual
  bach --startup mode silent

Одноразовый (только при этой загрузке):
  bach --startup --mode=gui
  bach --startup --mode=text

КОНФИГУРАЦИЯ
-------------
Текущий режим сохраняется в system/data/user_config.json:

  {
    "startup_mode": "графический интерфейс",
    "startup_modes": {
      "gui": {"gui": true, "console": false},
      "текст": {"gui": false, "консоль": true},
      "dual": {"gui": true, "console": true},
      "тихий": {"gui": ложь, "консоль": ложь}
    }
  }

ПРИМЕРЫ
---------
# Запустить в обычном режиме (использует сохраненный режим)
bach --startup

# Постоянно менять режим на текстовый
bach --startup mode text

# Запустить один раз в тихом режиме
bach --startup --mode=silent

# Быстрый запуск без сканирования каталогов в графическом режиме
bach --startup quick --mode=gui

ПРИМЕЧАНИЯ
--------
- Режим автоматически отображается при --startup
- Сервер графического интерфейса остается активным в фоновом режиме до выключения.
- В текстовом режиме открывается новое окно консоли.
- Тихий режим подходит для задач cron и автоматизации

СМОТРИ ТАКЖЕ
----------
  Помощь при запуске - Подробности журнала запуска
  help gui — документация по панели управления графическим интерфейсом пользователя
  помощь завершение работы - завершение сеанса
