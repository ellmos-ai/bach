BACH Handler: Secrets
=====================

Secret values are stored exclusively in the operating-system keyring.

USAGE
-----

  bach secrets list
  bach secrets get <key>
  bach secrets set <key> [--desc=TEXT] [--category=CAT]
  bach secrets set <key> --stdin [--desc=TEXT] [--category=CAT]
  bach secrets delete <key>
  bach secrets sync

SECURITY
--------

  - `get` never writes a secret value to stdout.
  - Values passed as process arguments are rejected.
  - `bach.db` and `bach_secrets.json` contain metadata only.

MODULE
------

  hub/secrets_handler.py (SecretsHandler)
