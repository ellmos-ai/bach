CLOUD - Control de sincronización en la nube neutral al proveedor
================================================================
El servicio Cloud-Control evita bloqueos de archivos, conflictos de
sincronización y colisiones de SQLite-WAL durante operaciones intensivas de
escritura, copias de seguridad y ejecuciones masivas de mantenimiento.

PROVEEDORES COMPATIBLES
-----------------------
- Microsoft OneDrive (Windows / macOS / Linux)
- Google Drive (Windows / macOS)
- Apple iCloud Drive (macOS bird / CloudDocs, Windows iCloud.exe)
- Dropbox (Windows / macOS / Linux)
- Nextcloud / ownCloud (Windows / macOS / Linux)

CONCEPTOS CLAVE
---------------
1. AUTO-DETECTION: Detecta automáticamente al iniciar los clientes instalados
   y en ejecución.
2. PROTECCIÓN OPERATIVA: La sincronización en la nube se pausa solo
   puntualmente durante trabajos intensivos de escritura y se reactiva de
   inmediato después (sin detención permanente en inactividad).
3. FAIL-SAFE WATCHDOG: Un temporizador de seguridad reactiva de forma
   garantizada los clientes pausados tras expirar el tiempo de espera
   (predeterminado: 300s), incluso ante fallos del programa.
4. ARQUITECTURA Y DIAGRAMAS: Véase docs/ARCHITECTURE_CLOUD_CONTROL.md

COMANDOS CLI (bach cloud)
-------------------------
  bach cloud status                     Resumen de todos los servicios en la nube detectados
  bach cloud status --json              Estado en formato JSON
  bach cloud pause [provider] [-t SEC]  Pausa la sincronización con tiempo de espera de seguridad (predeterminado: 300s)
  bach cloud resume [provider]          Reanuda los servicios pausados
  bach cloud toggle [provider]          Alterna entre pausa y reanudación

CONTEXT-MANAGER DE PYTHON
-------------------------
  from hub._services.cloud import cloud_pause

  with cloud_pause(timeout=180):
      # Operaciones de archivo intensivas en escritura
      schreibe_daten()
  # La sincronización en la nube se reanuda automáticamente en segundo plano
