CUENTA REGRESIVA - Cuenta regresiva con disparador
==================================

Temporizador de cuenta regresiva que opcionalmente ejecuta un comando cuando expira.

COMANDOS CLI
-----------

  bach countdown start <name> <duración>                Iniciar cuenta regresiva
  bach countdown start <name> <duración> --after "cmd"   Con comando de disparo
  bach countdown <duración>                             Forma corta: se inicia como "timer" (v1.1.84)
  bach countdown stop <name>                            Cancelar cuenta regresiva
  bach countdown list                                   Cuenta regresiva activa
  bach countdown pause <name>                           Pausa
  bach countdown resume <name>                          Reanudar

FORMATOS DE DURACIÓN
-------------

  HH:MM:SS   p. ej. 01:00:00 = 1 hora
  MM:SS      p. ej. 25:00 = 25 minutos
  Xs/Xm/Xh   p. ej. 90s, 25m, 2h (forma corta)

FORMATO DE SALIDA
--------------

  Iniciar:    [COUNTDOWN] 'name' iniciado: 01:00:00
  Pausar:     [COUNTDOWN] 'name' en pausa (45:12 restantes)
  Reanudar:   [COUNTDOWN] 'name' reanudado (45:12 restantes)
  Detener:    [COUNTDOWN] 'name' cancelado

  Lista:      [COUNTDOWN] Cuentas regresivas activas:
                name: 45:12                 (normal)
                name: 04:58 [!]             (advertencia, si quedan < 5 minutos)
                name: ¡EXPIRADO!
                name: 19:45 (PAUSADO)

PERSISTENCIA
----------

  Archivo: data/.countdown_state

  Contenido:
  {
    "countdowns": {
      "session": {
        "end_time": "2026-01-30T15:00:00",
        "after_command": "shutdown 'Se acabó el tiempo'",
        "paused": false,
        "remaining_on_pause": null
      }
    }
  }

EJEMPLOS
---------

  # Cuenta regresiva de sesión de 1 hora
  bach countdown start session 01:00:00
  -> Cuenta regresiva 'session' iniciada: 01:00:00

  # Con apagado automático
  bach countdown start session 01:00:00 --after "shutdown 'Session beendet'"
  -> Cuando expira, se ejecuta "bach --shutdown 'Sesión finalizada'"

  # Temporizador Pomodoro (25 min)
  bach countdown start focus 00:25:00
  -> Cuenta regresiva 'focus' iniciada: 00:25:00

  # Pausar y reanudar
  bach countdown pause focus
  bach countdown resume focus

  # Verificar estado
  bach countdown list
  -> [COUNTDOWN] Cuentas regresivas activas:
  ->   session: 45:12
  ->   focus:   19:45 (PAUSADO)

TRIGGER (--after)
-----------------

El comando --after se ejecuta cuando expira:

  --after "shutdown 'Se acabó el tiempo'"  Finalizar sesión
  --after "msg send user '¡Pausa!'"         Enviar mensaje
  --after "task done 123"                   Marcar tarea como completada

Cuando expira, el comando se escribe en una cola.
La siguiente llamada CLI lo ejecuta (o el demonio).

USECASES
--------

  1. LÍMITE DE SESIÓN
     bach countdown start session 02:00:00 --after "shutdown 'Limit erreicht'"
     -> Finalización automática de la sesión después de 2 horas

  2. TÉCNICA POMODORO
     bach countdown start focus 00:25:00 --after "msg send user 'Pause machen!'"
     -> Recordatorio para hacer una pausa después de 25 minutos

  3. RECORDATORIO DE PLAZO
     bach countdown start deadline 04:00:00
     -> Aviso a < 5 minutos, luego actuar manualmente

-------------
