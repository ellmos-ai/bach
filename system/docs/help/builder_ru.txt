BUILDER - Создание и экспорт навыков/агентов
==========================================

BACH COMMAND (предпочтительно)
-------------------------
bach skills export <name>               Экспорт навыков (v2.0)
bach skills list                        Перечислить все навыки
bach skills version <name>              Проверка версий


ИНСТРУМЕНТЫ В system/tools/
---------------------------
c_structure_generator.py <n> <profile> Создать навык/агента
c_structure_generator.py <n> --embedded Для BACH (облегченный)

generators/os_generator.py <n> [цель] Создать новую ОС
генераторы/exporter.py навык <n> Экспорт навыка
генераторы/distribution_system.py Система распространения


ПРОФИЛЬ СПЕКТР
----------------
MICRO Только SKILL.md (1 файл)
LIGHT Минимальная структура (~5 файлов)
СТАНДАРТ С памятью (~12 файлов)
РАСШИРЕНО с микронавыками (~20 файлов)
АГЕНТ с рабочими процессами (~30 файлов)
AGENT_FULL Полный (~50 файлов)


DIST_TYPE SYSTEM
----------------
2 = CORE Всегда пакет
1 = ШАБЛОН Возврат к исходному состоянию
0 = ПОЛЬЗОВАТЕЛЬ Не экспортировать


БЫСТРЫЕ КОМАНДЫ
--------------
Экспорт навыков: анализ экспорта навыков Баха
Список навыков: список навыков Баха
Проверка версии: анализ версии навыков Баха
