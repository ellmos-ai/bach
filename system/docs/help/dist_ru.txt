ИМЯ ОБРАБОТЧИКА
============
dist - Обработчик системы распространения (на основе типа_распространения)


ОПИСАНИЕ
============
Управляет снимками, выпусками и пакетами распространения системы BACH.
Постоянное резервное копирование через классификацию dist_type (CORE=2, TMPL=1, USER=0).
Поддерживает управление версиями, целостность печати и переносимость.


OPERATIONS
===========
status Статус системы (печать, статистика dist_type)
проверить целостность пломбы
classify dist_type Показать распределение (CORE/TMPL/USER)
снимок Создать снимок (вручную или автоматически)
Release Создать выпуск с номером версии
восстановить Восстановить из дистрибутива в папке dist/
установить Установить дистрибутив в новую папку
list Список снимков/релизов/ZIP-архивов


ПРИМЕРЫ
=========
Основные команды:
  bach --dist status                  -> Состояние системы с печатью и статистикой
  bach --dist verify                  -> Проверка целостности печати
  bach --dist classify                -> распределение dist_type (таблица на таблицу)

Снимки:
  bach --dist snapshot NAME           -> Создать вручную снимок с именем
  bach --dist snapshot TEST "Desc"    -> С необязательным описанием
  bach --dist snapshot --list         -> Список последних 20 снимков

Релизы:
  bach --dist release v1.0.0          -> Создать релиз с номер версии
  bach --dist release v1.0.0 "Notes"  -> С примечаниями к выпуску
  bach --dist list releases           -> Показать последние 20 выпусков

Распространение (восстановление и установка):
  bach --dist restore --list          -> Показать доступные ZIP-файлы в dist/
  bach --dist restore NAME.zip        -> Восстановить из dist/NAME.zip
  bach --dist restore NAME.zip --no-backup  -> Без резервного снимка
  bach --dist restore NAME.zip --target /x  -> В другой каталог. извлечения
  bach --dist install NAME.zip D:\\Path  -> Установить в новую папку
  bach --dist install --list          -> Показать доступные ZIP-файлы

=======
