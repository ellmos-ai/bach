ANTIGRAVITY – КРАТКАЯ СПРАВКА
=============================

Google Antigravity — это платформа разработки, ориентированная на агентов.
Подробная документация: wiki/antigravity.txt

КРАТКИЙ ОБЗОР
--------------
  Что: Форк VS Code с автономными ИИ-агентами
  Скачать: https://antigravity.google/download.
  Путь: C:\Users\User\AppData\Local\Programs\Antigradity\

КОМАНДЫ CLI
-----------
  антигравитация [путь] Открыть редактор
  антигравитационный чат Запустить «Подсказочный» чат (GUI!)
  антигравитационный чат -m агент Режим агента
  антигравитация --add-mcp {...} Добавить сервер MCP

КЛАВИАТУРА
-------------
  Cmd+L переключить панель агента
  Cmd+I встроенное завершение
  Cmd+E Переключить редактор/менеджер

РЕЖИМЫ РАЗРАБОТКИ
----------------
  Автопилот, управляемый агентом (автономный)
  На основе отзывов С разрешения (рекомендуется)
  Пользователь с помощью агента в управлении

ВАЖНЫЕ ПУТИ
--------------
  .gemini\antigravity\brain\ списки задач (ВОЗМОЖНО!)
  .gemini\antigravity\skills\ Глобальные навыки
  .agent\skills\ Навыки рабочего пространства
  .agent\workflows\ Рабочие процессы (/slash-commands)

ИНТЕГРАЦИЯ С BACH
----------------
  Запуск: start/start_gemini.bat (Интерактивный)
  Скрипт: инструменты Python/partner_communication/gemini_start.py
  Входящие: система/партнеры/gemini/inbox/
  Исходящие: system/partners/gemini/outbox/
