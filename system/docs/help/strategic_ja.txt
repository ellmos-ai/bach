戦略文書 - メタ認知
---------------------------------------

ステータス: 2026-02-08

概要
----------
BACH は、長期的な管理とメタ認知のために 3 つの中心的な文書を使用します。

  system/ROADMAP.md ビジョン、フェーズ、長期目標
  system/CHANGELOG.md 変更履歴 (バージョン、日付、詳細)

さらに:
- 教訓と戦略的洞察は最終的にメモリ/MEMORY.md に保存されます。
- バグはタスク システム経由でも追跡されます (カテゴリ: メンテナンス/バグ)。

メモリ システムの分類
---------------------------

  +----------------------------------------------------------------+
  |                    メタ認知（戦略） |
  |  +----------------------------------------------------------------+|
  |  |システム/ロードマップ.md |システム/CHANGELOG.md |メモリ/MEMORY.md||
  |  | docs/con3_*.md |分析 |                 ||
  |  +----------------------------------------------------------------+|
  |                          |                                    |
  |                          |導出 |
  |                          v |
  |  +----------------------------------------------------------------+|
  |  |                    タスクシステム（企画中） ||
  |  |  具体的な実行可能なタスク ||
  |  |  Bach タスク リスト / 追加 / 完了 ||
  |  +----------------------------------------------------------------+|
  |                          |                                    |
  |                          |実行 |
  |                          v |
  |  +----------------------------------------------------------------+|
  |  |              メモリ システム (動作中) ||
  |  |  メモリセッション |思い出のレッスン |メモリワーキング ||
  |  +----------------------------------------------------------------+|
  +--------------------------------------------------------------+

回路:
  1. 戦略は目標を定義します (system/ROADMAP.md)
  2. 目標がタスクになる（タスクシステム）
  3. タスクはアクティビティ (セッション/ログ) を生成します
  4. イベントが統合されます (bach consolidate)
  5. 結果戦略を更新します (memory/MEMORY.md)

DOCUMENT STYLES
--------------

system/ROADMAP.md:
  - 焦点: ビジョン、フェーズ、マイルストーン。
  - 粒度: 粗いブロック (例: 「フェーズ 12: 税金」)。
  - 目標: パートナー エージェント向けのオリエンテーション (ここはどこですか?)。

memory/MEMORY.md:
  - 焦点: 重要な洞察と学んだ教訓。
  - スタイル: 問題と解決策の構造化された文書。
  - カテゴリ: 機能/モジュールごとに整理されています。

戦略への統合
---------------------------
このプロセスでは、運用データが戦略文書に変換されます。

  生データ ---[バッチセッション終了]---> セッション (DB)
  セッション ---[バッチ統合圧縮]---> コンテキスト (DB)
  タスク (完了) ---[手動メンテナンス]--->memory/MEMORY.md

サポート用コマンド:
  bach consolidate status                    統合ステータスを表示
  bach consolidate compress --batch          セッションをグループ化 (単純)
  bach consolidate compress --run            ルール セットで圧縮
  bach consolidate review                    wiki/ドキュメントのレビュー タスクを作成
  bach consolidate run                       すべてのプロセスを実行
