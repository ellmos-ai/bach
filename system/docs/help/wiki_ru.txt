ВИКИ-ОБРАБОТЧИК
------------

ИМЯ ОБРАБОТЧИКА
------------
wiki - Управление и поиск вики-статей

ОПИСАНИЕ
------------
Вики-обработчик управляет местными базами данных знаний (вики/каталог).
Поддержка статей в основной папке и подпапках по конкретным темам.
Статьи сохраняются в виде текстовых файлов UTF-8. Обработчик поддерживает
Индексирование базы данных (синхронизация) для высокопроизводительного полнотекстового поиска через FTS5.

ОПЕРАЦИИ
-----------
список Список всех статей вики (с подпапками)
папки Список всех папок тем с количеством статей
<тема> Показать статью (например, bach wiki linux)
<папка>/<тема> Статья из подпапки (например, bach wiki Tax/elster)
поиск Поиск статей (FTS5 или резервное сканирование)
Показывать метаданные происхождения, тип доказательства, личную информацию и информацию о конфиденциальности.
синхронизировать вики-файлы зеркала и файлы справки в базе данных (индекс обновлений)

ПРИМЕРЫ
---------
Список вики Баха
  Показать все доступные статьи и папки тем

Вики-папки Баха
  Список всех папок тем с количеством статей

Bach wiki docker
  Показать статьи wiki/docker.txt

Bach wikifunding/icf
  Показать статьи из подпапки: wiki/foerderung/icf.txt

Bach wiki Tax/elster
  Показать статьи из подпапки: wiki/steuer/elster.txt

Bach wiki search "kubernetes"
  Искать по всем статьям с помощью FTS5 или резервного сканирования

Вики-поиск Баха «конвейер развертывания»
  Поиск по нескольким словам (в кавычках)

Бах вики-происхождение
  Показать последние проиндексированные статьи с оценкой происхождения и конфиденциальности

Налог на происхождение вики-сайта Баха/Эльстер
  Показать происхождение ровно одной статьи

Бах вики-синхронизация
  Обновить индекс базы данных (после изменения файлов вручную)

FILES
-------
wiki/Основная папка Wiki со статьями
wiki/*.txt Статьи в основной папке (например, wiki/docker.txt)
wiki/<папка>/ папка темы (например, wiki/tax/)
wiki/<folder>/*.txt Статьи в подпапке (например, wiki/steuer/elster.txt)
wiki/<folder>/_index.txt Дополнительное описание папки
wiki/_index.txt Необязательное описание основного списка
База данных data/bach.db с индексом синхронизации (таблица wiki_articles)
docs/help/ Файлы справки (дополнительная индексация посредством синхронизации)

СМОТРИ ТАКЖЕ
----------
bach help config     Свойства обработчика
bach help base       Основная документация обработчика
bach list handlers   Все доступные обработчики
bach wiki sync       Индексация базы данных

ПРИМЕЧАНИЯ
--------
- Статьи без префиксов пути или специальных команд для папок: автоматически в
  Основная папка найдена
- Синтаксис подпапки (/) нормализует обратную косую черту на косую черту (совместимо с Windows)
- Поиск FTS5 имеет приоритет над резервным сканированием файловой системы, если база данных существует.
- Нечеткое сопоставление не найденных элементов показывает схожие имена файлов.
- «синхронизация» должна вызываться вручную после прямого изменения файла
