ИМЯ ОБРАБОТЧИКА
============
денкариум -- журнал + сборник мыслей


ОПИСАНИЕ
============
Обработчик Омута мысли управляет двумя режимами для заметок и размышлений:

  денкарий Свободные мысли, идеи и размышления (можно гибко классифицировать)
  logbuch Хронологический дневник с отметкой звездного времени 

Все записи хранятся в sqlite3 (таблица denkarium_entries) и
можно искать, классифицировать, оценивать и повышать до задач/вики.


ОПЕРАЦИИ
===========
bach denkarium write TEXT [--type=logbuch] [--cat=KATEGORIE] [--title=TITEL] [--mood=1-5]
    Напишите новую запись. По умолчанию: тип=денкарий, кот=нота.
    Пример: bach denkarium напишите «Идеи для автоматизации» --type=denkarium --cat=idee

bach denkarium read [--type=logbuch|denkarium] [--cat=KATEGORIE] [--limit=N]
    Список последних N записей (ограничение по умолчанию = 10)
    Пример: денкарий Баха read --type=logbuch --limit=5

bach denkarium search SUCHBEGRIFF
    Поиск по контенту, заголовкам и категориям (максимум 20 совпадений)
    Пример: поиск по денкарию Баха «Автоматизация»

bach denkarium brainstorm THEMA
    Создайте новую запись мозгового штурма с помощью шаблона
    Пример: мозговой штурм в Денкариуме Баха «Архитектура искусственного интеллекта»

bach denkarium promote ENTRY-ID task|wiki
    Продвигайте запись об омуте памяти в задаче или вики
    Пример: денкарий Баха продвигает 42 задания 

bach denkarium categories
    Список всех использованных категорий с указанием количества записей

bach denkarium stats
    Общая статистика: количество, период времени, рекламные акции


ПРИМЕРЫ
=========
1. Краткое примечание (стандартное мысленное омут):
   bach denkarium write "Morgen Backend-Refactoring planen"

2. Запись в бортжурнале с оценкой:
   bach denkarium write "Produktive Session, viel erreicht" --type=logbuch --mood=5

3. Начать мозговой штурм:
   bach denkarium brainstorm "Neue Feature-Ideen"
   bach denkarium write "Caching-Layer hinzufuegen" --cat=idee

4. Ищите мысли и продвигайте их к задаче:
   bach denkarium search "wichtig"
   bach denkarium promote 15 task

5. Просмотрите записи бортового журнала за прошлую неделю:
   bach denkarium read --type=logbuch --limit=20


ФАЙЛЫ
=======
  data/bach.db База данных SQLite (таблица: denkarium_entries)
  docs/help/denkarium.txt Этот файл справки


СМОТРИТЕ ТАКЖЕ
==========
  задачи — управление задачами (цель для операций по продвижению)
  wiki – система Wiki (необязательное место для продвижения)
  base -- API BaseHandler (hub/base.py)


ПРИМЕЧАНИЯ
=======
- Время начала: записи журнала без явного --title получают "Время начала ГГГГ-ММ-ДД ЧЧ:ММ"
- Категории: свободно выбираемые (заметка, идея, мозговой штурм и т. д.)
- Рейтинг настроения: опционально, шкала от 1 до 5 для отслеживания отражений.
- Повысить задачу: создает новую задачу со стандартным приоритетом = 3, статусом = в ожидании.
- Продвижение в Wiki: запись помечается, сложная интеграция с Wiki через отдельный обработчик.
