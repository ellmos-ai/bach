# SECRETOS

BACH guarda los valores secretos exclusivamente en el llavero del sistema
operativo. `bach.db` y `~/.bach/bach_secrets.json` solo contienen metadatos y
el marcador del backend. Si falta el índice de metadatos, no se elimina ninguna
credencial.

Operaciones
-----------

- `bach secrets list`: muestra solo metadatos y el estado del backend.
- `bach secrets get <key>`: comprueba la disponibilidad sin mostrar el valor.
- `bach secrets set <key>`: solicita el valor de forma interactiva y oculta.
- `bach secrets set <key> --stdin`: lee el valor desde stdin sin registrarlo.
- `bach secrets delete <key>`: elimina el valor y sus metadatos.
- `bach secrets sync`: migra texto plano heredado después de verificar el llavero.

Los valores pasados como argumentos del proceso se rechazan.
