バッハ情報
=========

定義
BACH (Best-of BATCH + CHIAH) は、ローカルでポータブルな「エージェント オペレーティング システム」です。 
LLM ベースの AI アシスタントの作業環境。エージェント フレームワークを組み合わせます。 
RAG システムと認知心理学を AI の個人的な「神経システム」に組み込みます。

コア機能 (7 つの柱)
1. 認知記憶モデル：人間の記憶に類似した5種類
   (作業的、エピソード的、意味論的、手続き的、連想的)。
2. アクティブな統合: システムは情報を学習し、忘れ、重み付けします。
   ディケイ、ブースト、夜間のコンプレッションを介して。
3. マルチパートナーの代表団: クロード、ジェミニ、オラマのオーケストレーション。
4. CLI-First + GUI: ターミナルまたは Web ダッシュボード (8 個以上の専用ボード) を介して完全に制御します。
5. ポータブルかつローカル: SQLite ベース、クラウド要件なし、完全なデータ主権。
6. ドメインエージェント: 20 名以上の専門家 (ATI、税務、財務アシスタント、健康など)。
7. 自己修復: 自動メンテナンス、パス修復、および文書フォレンジック。

使用
システムは主にこの CLI (`bach.py`) または Web ダッシュボードを介して制御されます。

コマンド
bach --help             すべてのトピックの概要
bach status             現在のシステム ステータス
bach task list          オープン タスクの表示
bach mem read           現在のメモリの取得

アーキテクチャ
CLI/GUI/MCP --> ハブ ハンドラー --> スキル/ツール --> データベース/ファイル システム/パートナー
