系统检查
-------------

注意：计划的 --selfcheck 命令尚未实施。
该功能分布在现有的处理程序中。

系统检查的替代方案：

1。启动检查（自动）
   bach startup run

   执行：
   - 目录扫描（新的/更改的文件）
   - 路径修复器检查（路径问题）
   - 注册表观察程序（DB/JSON 一致性）
   - 技能健康监控（技能/特工验证）
   - NUL 清理器（Windows NUL 文件）
   - 问题第一（24小时错误分析）

2.维护工具
   bach maintain list

   可用检查：
   - 维持治疗 - 路径修正
   - 维护注册表 - 数据库一致性
   - 保持技能 - 技能健康
   - 维护 json - JSON 修复
   - 维护nul - 删除NUL 文件

3。工作流程质量
   bach tuev run

   检查工作流程的结构和一致性

4。备份状态
   bach backup status

   显示最新备份和期限

定期检查：
  每次“巴赫启动运行”时都会运行自动检查。
  无需单独间隔 30 天。

日志：
  启动日志：系统/数据/日志/
  维护日志：输出到控制台

建议：
  会话开始时：bach 启动运行
  如果出现问题：bach 维护 [操作]
