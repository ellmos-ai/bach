РИТОРИКА
--------
Риторические операторы и шаблоны как прикладные стратегии мышления.

Основное утверждение: риторика – это когнитивная стратегия + языковая упаковка.


1. РИТОРИЧЕСКИЕ ОПЕРАТОРЫ (основные строительные блоки)
------------------------------------------

1.1 Операторы подкрепления
-----------------------------
Увеличение воздействия, интенсивности или важности.
  - Усиление -> сделать что-то большее
  - Акцент -> акцент посредством повторения/структуры
  - Нарастание (кульминация) -> А -> Б -> С, каждый сильнее
  - Суперлативизация -> "самый важный момент..."

1.2 Операторы ослабления
-----------------------------
Ослабить, релятивизировать, разрядить.
  - Литота -> "неплохо"
  - Хеджирование -> «может быть и так...»
  - Релятивизация -> «по сравнению с...»

1.3 Операторы структуры
------------------------
Упорядочить мысли и направить внимание.
  - Триада -> 3-точечная структура
  - Кадрирование -> Установить контекст
  - Указатели -> «во-первых... во-вторых...»
  - Контраст -> A против B

1.4 Операторы значения
--------------------------
Изменить понимание чего-либо.
  - Метафора -> передача смысла
  - Аналогия -> структура сравнения
  - Определение -> Установить термин
  - Рефрейминг -> Переосмысление смысла

1.5 Операторы убеждения
----------------------------
Нацеленность на одобрение.
  - Логотипы -> логические аргументы
  - Этос -> доверие
  - Пафос -> Эмоция
  - Ссылка на авторитет -> «Исследования показывают...»

1.6 Операторы восприятия
----------------------------
Контролируют то, на что обращает внимание аудитория.
  - Фокусировка -> «Важно то...»
  - Отвлечение -> переместить тему
  - Выборочное отображение -> показывать только важные аспекты

1.7 Операторы взаимодействия
----------------------------
Включить другого человека.
  - Риторический вопрос
  - Прямой подход
  - Фрейм сообщества -> «мы все это знаем...»
  - Ожидание возражений -> «Вам может быть интересно...»

1.8 Операторы достоверности
--------------------------------
Повышение доверия.
  - Самораскрытие
  - Прозрачность
  - признавать ошибки
  - Проявите последовательность


2. РИТОРИЧЕСКИЕ ШАБЛОНЫ (комбинации)
----------------------------------------

2.1 Шаблон проблема-причина-решение
------------------------------------
Операторы: обрамление, причинность, структурирование
Форма: Назовите проблему -> Объясните причину -> Предложите решение

2.2 Модель ожидания возражений
--------------------------------
Операторы: изменение точки зрения, рефрейминг, логотипы
Форма: «Сейчас вы можете подумать… но на самом деле…»

2.3 Шаблон сюжетного фрейма
------------------------
Операторы: метафора, последовательность, пафос
Форма: Ситуация -> Конфликт -> Поворотный момент -> Решение

2.4 Сэндвич-паттерн
---------------------
Операторы: усиление, ослабление
Форма: Позитив -> Критика -> Позитив

2.5 Контраст
---------------------
Операторы: Контрастирование, фокусировка
Форма: «Не X, а Y».

2.6 Шаблон «Триада»
--------------------
Операторы: Структурирование, усиление
Форма: «Быстро. Ясно. Эффективно».

2.7 Модель авторитета
------------------------
Операторы: Этос, Логос
Форма: «Исследования показывают... эксперты подтверждают...»

2.8 Модель минимального сопротивления
-------------------------------
Операторы: ослабление, хеджирование
Форма: «Возможно, это имело бы смысл...»

2.9 Шаблон рефрейминга
----------------------
Операторы: Сдвиг в значении
Форма: «Это не проблема – это возможность».

2.10 Сократовский шаблон
--------------------------
Операторы: вопросы, смена точки зрения
Форма: «Что, если...?»

2.11 Модель импульса
----------------------
Операторы: кульминация, последовательность
Форма: «Сначала... потом... наконец...»

2.12 Схема сокращения
-----------------------
Операторы: фрагментирование, фокусировка
Форма: «На самом деле речь идет о двух вещах...»

2.13 Шаблон зеркального отображения
-------------------------
Операторы: Взгляд с точки зрения
Форма: «Я слышал, что для вас это важно...»

2.14 Шаблон упрощения
----------------------------
Операторы: Нормализовать, Метафора
Форма: «Представьте, что это было похоже на...»

2.15 Схема сюрприза
----------------------------
Операторы: Контраст, Рефрейминг
Форма: «Большинство людей думают X, но верно обратное».

2.16 Шаблон согласованности
------------------------
Операторы: этос, повторение.
Форма: «Как я сказал...»

2.17 Точность шаблона
-------------------------
Операторы: определение, фокусировка
Форма: «Под «эффективностью» я имею в виду конкретно...»

2.18 Модель эмоционального триггера
-------------------------------
Операторы: Пафос, рассказывание историй
Форма: «Представьте, что вы встаете утром и...»

2.19 Схема контрдоказательств
-------------------------
Операторы: тестирование, сравнение
Форма: «Если бы это было правдой, то...»

2.20 Минимальный шаблон аргументов
------------------------------
Операторы: приоритизация, сокращение
Форма: «Есть только ОДНА причина, почему это важно...»


3. РИТОРИЧЕСКИЕ ТРЮКИ (точные приемы)
-------------------------------------------

Холодное открытие -> начните прямо с сильного заявления.
Крючок -> Внимание через 3 секунды
Обратный вызов -> вернуться к предыдущему пункту позже
Эхо -> повторение ключевых слов
Контрастный крючок -> «Плохие новости... хорошие новости...»
Фальстарт -> намеренно прерывать, чтобы создать напряжение.
Микроперерыв -> усиление эффекта
Навешивание ярлыков -> называйте эмоции («Это расстраивает...»)
Прайминг -> установление ожиданий
Привязка -> Установить точку сравнения


4. РИТОРИКА И МЕТАПОЗНАНИЕ
------------------------------
Метакогнитивные стратегии как риторический самоконтроль:

  Самоконтроль -> контролировать язык тела, тон, темп.
  Анализ ошибок -> анализ речи, петли обратной связи
  Мета-вопросы -> «Каково мое основное послание»
  Выбор стратегии -> баланс этос/пафос/логос
  Рефлексия -> Продолжение выступления
  Метапланирование -> структура речи, драматургия

Риторика = не просто говорить, а думать о разговоре.


5. СВЯЗАННЫЕ С ТЕХНИЧЕСКИМИ ШАБЛОНАМИ
---------------------------------
Многие операторные шаблоны имеют риторических двойников:

  Классификация → Анализ целевой группы
  Подсчет очков и ранжирование -> Взвешивание аргументов
  Фильтрация на основе правил -> Фильтр релевантности для контента
  Обнаружение аномалий -> обнаружение противоречий
  Прогрессивное уточнение -> Стройте аргументацию шаг за шагом.
  Человек в цикле -> Включить реакцию аудитории
  Запасное решение -> Работа с возражениями

Это не совпадение: риторика – это процесс обработки информации.


6. ТРИ СТОЛПА РИТОРИКИ
---------------------------------

Логос (логическая аргументация)
  -> Дедукция, индукция, сравнения, тесты, контрдоказательства
  -> Стратегии мышления: формирование гипотез, причинное мышление

Этос (достоверность)
  -> Самоконтроль, анализ ошибок, последовательность
  -> Метапознание: рефлексия, метавопросы

Пафос (эмоциональное воздействие)
  -> Распознавание образов, рассказывание историй, аналогии
  -> Стратегии мышления: изменение точки зрения, сценарное мышление


7. ПРИМЕНЕНИЕ В БАХЕ
--------------------

Риторические операторы могут улучшить системы искусственного интеллекта:
  - Лучшая объяснимость (шаблон упрощения)
  - Улучшение сообщений об ошибках (проблема-причина-решение)
  - Лучшее руководство для пользователей (размещение знаков, структурирование)
  - Улучшение коммуникации (партнерская система)

Стратегии мышления = внутренние операторы (обработка)
Риторика = внешние операторы (коммуникация)
