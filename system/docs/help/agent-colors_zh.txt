代理颜色
====

蓝图颜色是可选的。允许的值为 null 或以 # 开头的六位十六进制数字，例如
#12abef。大写字母会转换为小写。其他 CSS 值无效。

在没有颜色字段的情况下保存时，会保留之前的颜色。null 会将其删除。更改
需要当前的蓝图版本。

实例化（物化）时，实例会继承蓝图颜色。显式设置的实例覆盖具有优先权。
实例覆盖中的 null 表示重新继承。重新实例化会更新蓝图颜色，但保留实例覆
盖。这两个步骤都需要各自当前的配置版本。实例重置会删除覆盖；现有的蓝图
颜色将被继承。

没有已保存的颜色时，API 会报告 color=null 和 color_source=default。届时
界面将使用其默认主题。读取旧配置文件不会保存新的颜色字段。颜色不授予任何
权限，也不会启动任何 Worker、Provider 或模型调用。
