# シークレット

BACH はシークレット値を OS のキーチェーンだけに保存します。`bach.db` と
`~/.bach/bach_secrets.json` にはメタデータとバックエンドマーカーだけが
保存されます。メタデータ索引がなくても認証情報は削除されません。

操作
----

- `bach secrets list`: メタデータとバックエンド状態だけを表示します。
- `bach secrets get <key>`: 値を表示せずに利用可能性を確認します。
- `bach secrets set <key>`: 値を非表示で対話入力します。
- `bach secrets set <key> --stdin`: ログに残さず stdin から値を読みます。
- `bach secrets delete <key>`: 値とメタデータを削除します。
- `bach secrets sync`: キーチェーン検証後に旧平文値を移行します。

プロセス引数として渡されたシークレット値は拒否されます。
