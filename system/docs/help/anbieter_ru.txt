TEMU
====

Контекст:
Счета-фактуры TEMU импортируются из подтверждений заказов по электронной почте,
не из оригинальных квитанций. Это обходной путь, вот
Автоматическое получение оригиналов квитанций занимает очень много времени.

Правила ввода:

1. ЦЕНЫ
   Всегда извлекайте PDF-файлы из электронной почты
   (Цены на сайте нестабильные)

2. НАЗВАНИЯ ПРОДУКТОВ
   Если текст отсутствует или неполный:
   - Логически выводить из контекста
   - Лучше: найдите правильное название продукта на temu.com

3. ТИП ДОКУМЕНТА
   Пометить как «Подтверждение заказа (альтернативно счет)»

4. ПОСЛЕДУЮЩАЯ ВАЛИДАЦИЯ
   Если оригиналы квитанций будут загружены позже,
   Сравнить и обновить данные

Примечание для налоговой инспекции:
Оригиналы чеков предоставляются только по запросу.
Подтверждения заказов служат первоначальным подтверждением.
