ТЕСТ - тест BACH и система контроля качества
--------------------------------

ОБЗОР
----------
Систематическое тестирование BACH и сравнение с другими системами.
Использует B-тесты (автоматические), O-тесты (функциональные) и E-тесты (субъективные).

КОМАНДЫ
-------
  bach --test self [PROFIL]     Протестируйте BACH самостоятельно (по умолчанию: БЫСТРО)
  bach --test run <path>        Протестируйте другую систему
  bach --test compare <path>    Сравнить систему с BACH
  bach --test profiles          Показать доступные профили
  bach --test results [system]  Показать результаты тестирования

ТЕСТОВЫЕ ПРОФИЛИ
-----------
  БЫСТРЫЙ экспресс-тест (~5 мин) - B001, O001
  СТАНДАРТ Стандарт (~20 мин) - B001-B005, O001-O003
  ПОЛНОЕ завершение (~40 минут) — Все тесты.
  НАБЛЮДЕНИЕ Только тесты B (~15 мин)
  Только тесты OUTPUT O (~20 мин)
  MEMORY_FOCUS Фокус памяти (~10 минут)
  TASK_FOCUS Фокус на задаче (~10 мин)

ТРИ ТЕСТОВЫХ ПЕРСПЕКТИВЫ
---------------------
  B-тесты (наблюдение) Внешние автоматизированные скрипты Python
                          «Что существует?»

  O-тесты (выход) Функционал, ввод->вывод, скрипты Python
                          «Это работает?»

  Электронные тесты (опыт) Внутренние, субъективные, под руководством Клода
                          «Каково это?»

РЕЙТИНГОВАЯ ШКАЛА
---------------
  5 = Отлично
  4 = Хорошо
  3 = приемлемо
  2 = Плохо
  1 = Критический

ПРИМЕРЫ
---------
  bach --test self              Быстрая самопроверка
  bach --test self STANDARD     Стандартная самопроверка
  bach --test compare "C:\X"    Сравнить BACH с другой системой
  bach --test results           Показать все результаты
