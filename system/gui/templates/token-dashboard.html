➕ Neues Gerät registrieren

Nach der Anmeldung kannst du weitere Clients registrieren (z. B. Handy, Workstation, Tray).

Erstes Gerät auf einer neuen Installation

Öffne lokal im Verzeichnis system/ eine Python-Konsole und führe aus:

from gui.device_auth import create_device
token = create_device("first-device")
print(token)

Übertrage den einmaligen Token privat in das Anmeldefeld oben. Speichere ihn nicht in URLs, Protokollen oder Quelltexten.
