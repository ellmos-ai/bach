# Ticket-Master-Symbole

Die 16 SVG-Dateien stammen unverändert aus der vorhandenen Ticket-Master-/Lock-Watcher-Oberfläche (`static/icons`). Ihre stabilen Dateinamen dienen als IDs. Die Oberfläche lädt ausschließlich diese gebündelten Assets; URLs aus Konfigurationsdaten werden nicht als Symbolquellen verwendet.

Die Agentenporträts im benachbarten PNG-Atlas sind neue, für diese Oberfläche generierte Rasterbilder. Eine Auswahl speichert nur die Vorlagen-ID, ein eigener Upload weiterhin das begrenzte PNG-, JPEG- oder WebP-Bild.
