SKILLS BOARD - GUI HIERARCHIE MANAGER
=====================================

Stand: 2026-09-16

WAS IST DAS SKILLS BOARD?
-------------------------
Das Skills Board ist die grafische Oberflaeche im BACH-Dashboard zur
Verwaltung der Kompetenz-Hierarchie. Es visualisiert und steuert die
Beziehungen zwischen Agenten, Experten und deren Faehigkeiten.

Erreichbar unter den Routes `/skills-board` und `/agents-board`
(festen Nav-Eintrag im Dashboard, Teil der Default-Favoriten).

STRUKTUR & HIERARCHIE
---------------------
Das Board kennt 5 Entity-Typen (Taxonomie, Farbcodes via CSS-Klassen
in agents-board.html):

1. [ROT]    AGENT     (Boss/Kopf)
   Verantwortlich fuer einen Bereich (z.B. "Bueroassistent"). Hat ein
   Dashboard und koordiniert Experten. (CSS: .type-agent -> --error)

2. [GRUEN]  EXPERT    (Spezialist)
   Fachexperte unter einem Agenten (z.B. "Steuer-Agent").
   (CSS: .type-expert -> --success)

3. [BLAU]   SKILL     (Faehigkeit)
   Aktion, die ausgefuehrt werden kann (z.B. "Recherche").
   (CSS: .type-skill -> --accent-blue)

4. [BLAU]   SERVICE   (Dienst)
   Hintergrund-Dienst/Tool (z.B. Scanner, Daemon, Mail-Sync).
   (CSS: .type-service -> --accent-blue - gleiche Farbe wie SKILL)

5. [AKZENT] WORKFLOW  (Ablauf)
   Definierte Kette von Aufgaben oder Standard-Prozedur.
   (CSS: .type-workflow -> --accent)

Die Zuordnungen (welcher Expert/Skill/Service/Workflow gehoert zu
welchem Agent) stehen im Abschnitt "assignments" der JSON.

DATENHALTUNG
------------
**1. data/skills_hierarchy.json - Datenquelle des GUI (Source of Truth
fuer das Board):**
   - `items`: 5 Kategorien (agents, experts, skills, services,
     workflows), je Item: id, name, description, dashboard, status,
     path_hint
   - `assignments`: Zuweisungen pro Agent
   - `_meta.last_updated`: Zeitstempel (wird bei jedem PUT erneuert)
   - GET `/api/skills-board/hierarchy` liest, PUT schreibt diese Datei.
     Die GUI liest NICHT aus der Datenbank.

**2. bach.db - Tabellen bach_agents / bach_experts:**
   - Werden von anderen Tools genutzt (tools/agents/agent_cli.py,
     agents_export.py, schwarm/specialist.py, maintenance/
     registry_watcher.py, rezeptbuch.py, mcp_server.py).
   - NICHT Bestandteil des Board-Renderings; eine automatische
     Synchronisierung mit der JSON besteht nicht.

**3. Migration (vorbereitet, Stand 2026-01-29):**
   - tools/migration/migrate_skills_hierarchy.py migriert die JSON
     nach bach.db in die Tabellen hierarchy_types, hierarchy_items,
     hierarchy_assignments.
   - Diese Tabellen werden vom GUI-Server bislang NICHT gelesen
     (DB-Backend vorbereitet, JSON bleibt aktiv).

**4. Quelldateien (textbasierte Definitionen):**
   Aufloesung ueber path_hint bzw. resolve_skill_file() (server.py):
   - Agent    -> agents/            (z.B. agents/bueroassistent.txt)
   - Expert   -> agents/_experts/
   - Service  -> hub/_services/
   - Workflow -> skills/workflows/
   - Skill    -> skills/
   - Template -> skills/_templates/

FUNKTIONEN
----------
- **Drag & Drop**: Skills, Experten, Services und Workflows koennen
  Agenten per Drag & Drop zugewiesen werden.
- **Team Flow**: Visueller Builder pro Agent, um Agenten und Skills
  zu einer Arbeitskette zu verknuepfen (BOARD_005, Save-Button).
- **Task Delegation**: "+ Task erstellen" pro Agent - Formular mit
  Beschreibung, Prioritaet und Vorlagen-Chips; legt einen Task an mit
  Titel "[AgentName] <Kurzfassung>" und Feld delegated_to=<agent-id>.
- **Filter**: Ansicht nach Typ filtern (setupFilters).
- **Edit**: Namen/Beschreibungen direkt im UI aendern; ZUSATZLICH
  direktes Datei-Editing: GET/PUT /api/skills-board/item-file liefert
  bzw. speichert die Quelldatei (.md/.txt/.py) eines Items.
- **Vollbild**: Vollbild-Modus des Boards (toggleFullscreen).

SYSTEM-INTEGRATION
------------------
- **Frontend**: gui/static/js/skills-board.js
- **Templates**: gui/templates/agents-board.html (primaer),
  skills-board.html (Fallback)
- **Routes**: GET /skills-board, GET /agents-board (beide dienen
  agents-board.html)
- **API**: GET/PUT /api/skills-board/hierarchy,
  GET/PUT /api/skills-board/item-file
- **Migration**: tools/migration/migrate_skills_hierarchy.py
  (JSON -> bach.db, optional --dry-run)
